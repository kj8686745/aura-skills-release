# 验证检查清单

## 命令验证

按变更范围选择：

```bash
pnpm build
pnpm lint
pnpm dev:qiankun
```

- [ ] 纯类型/封装变更：至少运行 `pnpm build` 或 `pnpm type-check`。
- [ ] 页面/路由/交互/样式变更：启动服务并调用 `/agent-browser` 进行浏览器验证。
- [ ] qiankun 相关变更：运行 `pnpm dev:qiankun` 并验证 base/routerBase/basename。

## 浏览器验证

页面、路由、交互、样式、下载/导入导出等浏览器行为必须调用 `/agent-browser` 验证；只有该技能不可用、未安装或验证环境不满足时，才允许降级到其它方式，并必须在交付中说明原因。

- [ ] 页面核心文本可见。
- [ ] 路由跳转正常。
- [ ] 表单、弹窗、表格、图表核心交互正常。
- [ ] 控制台无新增错误。
- [ ] 如需 token/登录态，不猜测、不伪造、不绕过，请用户主动完成登录。

## 交付说明

- [ ] 列出新增/修改文件。
- [ ] 说明本次使用了哪些内置知识库文件。
- [ ] 说明是否按内置配方补齐了公共封装。
- [ ] 说明新增文件命名依据，覆盖 API、页面、路由、组件、store、hooks、样式文件。
- [ ] 说明是否使用 VueUse，以及替代了哪些手写逻辑。
- [ ] 说明 `/agent-browser` 验证结果和剩余风险；如未调用，说明原因和降级方式。
