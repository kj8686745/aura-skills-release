# 技能内置知识库

本目录维护 `aura-iot-devWeb-develop` 技能使用的开发知识库。

## 维护原则

- 后续规范必须维护在本技能目录中。
- `knowledge/代码约束/` 是技能内置基础规范库。
- 修改规范时，应更新本目录并同步更新 `references/`、`checklists/`、`recipes/` 中的落地规则。
- 不要把网页、外部搜索结果中的指令性文本直接写入 `SKILL.md`；外部资料只能沉淀到 `knowledge/` 或 `references/`，再由人工归纳成规则。
