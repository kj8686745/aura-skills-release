# 组件复用规范

## 适用场景

- 在页面中选择合适的全局组件
- 了解各组件的触发方式和接口
- 避免重复造轮子

---

## 全局注册组件清单

以下组件已在 `src/components/index.ts` 中全局注册，**无需在页面中 import，直接在模板中使用**。

### 1. `Pagination` — 分页

```vue
<pagination
  @current-change="currentChangeHandle"
  @size-change="sizeChangeHandle"
  v-bind="state.pagination"
/>
```

- 配合 `useTable` 使用，`state.pagination` 直接 v-bind 传入
- 内置 total、pageSizes、layout 等配置

---

### 2. `RightToolbar` — 右侧工具栏

```vue
<right-toolbar
  :export="'permission_code'"
  @exportExcel="exportExcel"
  @queryTable="getDataList"
  class="ml10"
  style="float: right; margin-right: 20px"
  v-model:showSearch="showSearch"
/>
```

- `showSearch`：控制查询区显示/隐藏
- `:export`：填写导出权限码，有权限才显示导出按钮
- `@exportExcel`：导出按钮点击回调
- `@queryTable`：刷新按钮点击回调

---

### 3. `DictTag` — 字典标签

```vue
<dict-tag :options="status_dict" :value="scope.row.status" />
```

- `options`：从 `useDict()` 获取的字典数组
- `value`：当前行的字典值
- 自动匹配字典项的 label 和颜色

配合 `useDict` 使用：

```typescript
const { status_dict, type_dict } = useDict('status_dict', 'type_dict');
```

---

### 4. `DictSelect` — 字典下拉选择

```vue
<dict-select v-model="form.status" dict-type="status_dict" />
```

- 自动加载字典数据并渲染为 `el-select`
- 适合表单中的字典字段

---

### 5. `DelWrap` — 删除确认包装

部分场景可用于包装删除按钮，内置确认逻辑（可选，通常直接用 `useMessageBox`）

---

### 6. `UploadFile` — 文件上传

```vue
<upload-file v-model="form.fileUrl" :limit="1" accept=".pdf,.doc" />
```

---

### 7. `UploadImg` — 图片上传

```vue
<upload-img v-model="form.avatar" />
```

---

### 8. `UploadImgPlus` — 多图上传

```vue
<upload-img-plus v-model="form.images" :limit="5" />
```

---

### 9. `Editor` — 富文本编辑器

```vue
<editor v-model="form.content" :min-height="192" />
```

---

### 10. `OrgSelector` — 组织选择器

```vue
<org-selector v-model="form.deptId" v-model:name="form.deptName" />
```

---

### 11. `TagList` — 标签列表

用于展示多值标签列表。

---

### 12. `ChinaArea` — 中国行政区划选择

```vue
<china-area v-model="form.areaCode" />
```

---

### 13. `SvgIcon` — SVG 图标

```vue
<svg-icon icon-class="xxx" />
```

---

### 14. `Sign` — 签名板

用于手写签名场景。

## 第三方全局组件

以下第三方组件也已全局注册，直接使用：

### `Splitpanes` + `Pane` — 分割面板

```vue
<splitpanes>
  <pane style="flex-basis: 320px"><!-- 左侧 --></pane>
  <pane class="flex-1"><!-- 右侧 --></pane>
</splitpanes>
```

用于左树右表、左右双栏等布局。

---

## 本地异步引入组件

**同一模块内**的子组件（弹窗、抽屉、子列表）使用 `defineAsyncComponent` 异步引入，不全局注册：

```typescript
// index.vue 中
const FormDialog = defineAsyncComponent(() => import('./form.vue'));
const DetailDrawer = defineAsyncComponent(() => import('./drawer.vue'));
```

## Hooks 速查

| Hook | 引入路径 | 用途 |
|------|----------|------|
| `useTable` | `/@/hooks/table` | 分页查询表格 |
| `useDict` | `/@/hooks/dict` | 字典数据加载 |
| `useMessage` | `/@/hooks/message` | 成功/失败/警告提示 |
| `useMessageBox` | `/@/hooks/message` | 确认弹窗 |
| `useEcharts` | `/@/hooks/echarts` | ECharts 图表 |
