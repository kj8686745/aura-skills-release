# 路由与菜单规范

## 适用场景

- **开发新页面时**：将页面接入本地路由，本地跑通后再由后端菜单接管
- 理解后端菜单配置如何映射到前端页面
- 原型转码时确定路由落地方式

---

## 页面结构

路由系统分三层：

```
staticRoutes     → 登录、OAuth 跳转等无需鉴权的静态路由
dynamicRoutes    → 本地补充路由（当前仅 /home）
后端菜单路由     → 绝大多数业务页面，通过 backEnd.ts 动态注册
```

所有路由最终挂载在 `baseRoutes[0].children` 下，即布局组件 `src/theme-core/layout/index.vue` 的子路由。

---

## 必须遵循

1. **开发新页面时，统一先加入 `dynamicRoutes` 本地验证**，页面完成后再由后端菜单配置接管，不要等后端配完菜单才能本地看效果
2. `componentPath` 必须对应 `src/views` 下的文件路径（不含 `src/views` 前缀，不含 `.vue` 后缀）
3. 路由 `path` 建议与目录名保持一致，便于通过浏览器地址定位文件
4. 上线后 `dynamicRoutes` 中的条目可以删除，由后端菜单配置完全接管

---

## 推荐写法

### 方式一：本地 dynamicRoutes（开发阶段主要用法）

在 `src/router/route.ts` 的 `dynamicRoutes` 数组中添加，开发期间直接访问页面：

```typescript
{
  path: '/mymodule/mypage',
  name: 'mymodule.mypage',
  component: () => import('/@/views/mymodule/mypage/index.vue'),
  meta: {
    isLink: '',
    isHide: false,
    isKeepAlive: true,
    isAffix: false,
    isIframe: false,
    icon: 'ele-Document',
    title: '我的页面',
  },
},
```

**开发完成后**，对应的后端菜单配置如下（供对齐，由后端配置，不需要前端改代码）：

```
菜单类型：菜单
路由路径：/mymodule/mypage
组件路径：/mymodule/mypage/index    ← 对应 src/views/mymodule/mypage/index.vue
```

`backEnd.ts` 会自动将 `componentPath` 转为动态导入，后端接管后可删除 `dynamicRoutes` 中的对应条目。

### 方式二：后端菜单路由（生产接管）

生产环境由后端菜单配置完全管控，前端只需保证 `src/views` 中有对应文件即可，无需修改路由文件。

### 路由 meta 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `isLink` | string | 外链地址，不为空时开启外链模式 |
| `isHide` | boolean | 是否在菜单中隐藏 |
| `isKeepAlive` | boolean | 是否缓存组件状态（标签页缓存） |
| `isAffix` | boolean | 是否固定在 tagsView 栏上 |
| `isIframe` | boolean | 是否内嵌 iframe |
| `icon` | string | 菜单图标（`ele-xxx` 或 `iconfont xxx`） |
| `isAuth` | boolean | 是否需要认证，默认 true |

---

## 常见拆分方式

### 模块联邦远程页面

如果 `componentPath` 包含 `?type=moduleFederation`，`backEnd.ts` 会自动解析并通过模块联邦加载远程组件，无需特殊处理。

### 隐藏路由（详情/编辑页）

某些详情页不需要在菜单中显示，设置 `isHide: true`：

```typescript
{
  path: '/admin/user/detail/:id',
  meta: { isHide: true },
  component: () => import('/@/views/admin/user/detail.vue'),
}
```

---

## 生成提示输入建议

生成带路由的页面时，默认使用本地 `dynamicRoutes`，需要明确：

1. 页面所在 `src/views` 路径（如 `/mymodule/mypage/index.vue`）
2. 路由 `path` 和 `name`（建议与目录路径对齐）
3. 是否需要 `isKeepAlive: true`（标签页切换后是否保留状态）
4. `meta.title`（页面标题）和 `meta.icon`（菜单图标，`ele-xxx` 格式）
