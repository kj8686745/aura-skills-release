# 页面模式：详情页与抽屉

## 适用场景

- 只读详情展示，点击列表行/按钮触发
- 抽屉：从右侧滑出，不离开当前列表页
- 详情页：独立页面，通过路由跳转
- 常带"编辑""关闭""继续处理"等动作按钮

---

## 页面结构

### 抽屉模式

```
el-drawer（v-model="visible"，size="50%"）
└── 抽屉内容容器
    ├── 基本信息区（el-descriptions）
    ├── 关联数据区（嵌套简化表格）
    └── 操作区（底部按钮组）
```

### 独立详情页模式

```
layout-padding
└── layout-padding-auto layout-padding-view
    ├── 页面头部（面包屑 + 返回按钮）
    ├── 基本信息区（el-descriptions）
    ├── Tab 分组（el-tabs，可选）
    │   ├── Tab1：关联记录表格
    │   └── Tab2：操作历史
    └── 底部操作区
```

---

## 必须遵循

- 抽屉通过 `defineExpose({ openDrawer })` 暴露给父组件调用
- 只读信息必须使用 `el-descriptions`，不使用只读 `el-input`
- 抽屉尺寸建议 `size="50%"` 或 `size="600px"`，避免遮挡全部内容
- 独立详情页通过路由参数（`useRoute().params.id`）获取记录 id
- 内嵌关联表格使用简化版（不需要 `useTable`，直接 `ref([])` + API 调用）

---

## 推荐写法

### 抽屉组件（drawer.vue）

```vue
<template>
  <el-drawer
    v-model="visible"
    :title="'详情'"
    size="50%"
    :before-close="handleClose"
  >
    <div v-loading="loading" class="drawer-content">
      <!-- 基本信息 -->
      <el-descriptions :column="2" border class="mb20">
        <el-descriptions-item label="名称">{{ detail.name }}</el-descriptions-item>
        <el-descriptions-item label="状态">
          <dict-tag :options="status_dict" :value="detail.status" />
        </el-descriptions-item>
        <el-descriptions-item label="创建时间">{{ detail.createTime }}</el-descriptions-item>
        <el-descriptions-item label="创建人">{{ detail.createBy }}</el-descriptions-item>
        <el-descriptions-item label="备注" :span="2">{{ detail.remark }}</el-descriptions-item>
      </el-descriptions>

      <!-- 关联数据（可选） -->
      <div class="section-title mb8">关联记录</div>
      <el-table :data="relatedList" border size="small"
        :cell-style="{ textAlign: 'center' }"
        :header-cell-style="{ textAlign: 'center' }">
        <el-table-column prop="name" label="名称" />
        <el-table-column prop="createTime" label="时间" />
      </el-table>
    </div>

    <template #footer>
      <div class="drawer-footer">
        <el-button v-auth="'xxx_edit'" type="primary" @click="handleEdit">编辑</el-button>
        <el-button @click="visible = false">关闭</el-button>
      </div>
    </template>
  </el-drawer>
</template>

<script lang="ts" name="ModuleDrawer" setup>
import { useDict } from '/@/hooks/dict';
import { getObj, fetchRelated } from '/@/api/module/xxx';

const emit = defineEmits(['edit']);

const { status_dict } = useDict('status_dict');
const visible = ref(false);
const loading = ref(false);
const detail = ref<any>({});
const relatedList = ref([]);

const openDrawer = async (id: string) => {
  visible.value = true;
  loading.value = true;
  try {
    const [detailRes, relatedRes] = await Promise.all([
      getObj(id),
      fetchRelated(id),
    ]);
    detail.value = detailRes.data;
    relatedList.value = relatedRes.data;
  } finally {
    loading.value = false;
  }
};

const handleEdit = () => {
  visible.value = false;
  emit('edit', detail.value.id);
};

const handleClose = () => {
  visible.value = false;
};

defineExpose({ openDrawer });
</script>

<style scoped>
.drawer-content {
  padding: 0 16px;
}
.drawer-footer {
  display: flex;
  justify-content: flex-end;
  gap: 8px;
}
.section-title {
  font-weight: bold;
  font-size: 14px;
  color: var(--el-text-color-primary);
}
</style>
```

### 父组件调用抽屉

```vue
<!-- index.vue 模板中 -->
<detail-drawer ref="drawerRef" @edit="(id) => formDialogRef.openDialog(id)" />

<!-- 触发打开 -->
drawerRef.value?.openDrawer(row.id)
```

### 独立详情页（route 跳转）

```vue
<script lang="ts" name="ModuleDetail" setup>
import { useRoute, useRouter } from 'vue-router';
import { getObj } from '/@/api/module/xxx';

const route = useRoute();
const router = useRouter();
const id = route.params.id as string;
const detail = ref<any>({});

onMounted(async () => {
  const res = await getObj(id);
  detail.value = res.data;
});

const goBack = () => router.back();
</script>
```

---

## 常见拆分方式

- `drawer.vue` — 详情抽屉（由 `index.vue` 引入）
- `detail.vue` — 独立详情页（在路由中注册，`isHide: true`）
