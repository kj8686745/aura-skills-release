# 页面模式：弹窗表单

## 适用场景

- 新增/编辑操作通过 `el-dialog` 弹窗完成
- 弹窗由父页面（通常是查询表格页）触发
- 项目中几乎所有列表页的增删改都使用此模式

---

## 页面结构

```
el-dialog（v-model="visible"）
└── el-form（ref="dataFormRef"，:rules="dataRules"）
    ├── el-row + el-col（表单字段网格布局）
    │   ├── el-form-item + el-input / el-select / el-radio-group 等
    │   └── ...
    └── el-collapse（可选，折叠高级属性）
footer 插槽
└── 取消按钮 + 确认按钮
```

---

## 必须遵循

- 弹窗通过 `defineExpose({ openDialog })` 暴露 `openDialog` 方法给父组件调用
- `openDialog(id?)` 接收可选 id：有 id 表示编辑，无 id 表示新增
- 提交成功后 `emit('refresh')` 通知父组件刷新列表
- 提交时设置 `loading` 防止重复点击，使用 `try/finally` 确保 loading 复位
- 打开弹窗时用 `nextTick(() => dataFormRef.value?.resetFields())` 重置表单
- 字段校验规则在 `dataRules` 中定义，使用 `src/utils/validate.ts` 中的 `rule` 辅助工具

---

## 推荐写法

### form.vue 完整骨架

```vue
<template>
  <el-dialog
    :close-on-click-modal="false"
    :title="form.id ? $t('common.editBtn') : $t('common.addBtn')"
    draggable
    v-model="visible"
  >
    <el-form :model="form" :rules="dataRules" label-width="120px" ref="dataFormRef" v-loading="loading">
      <el-row :gutter="20">
        <el-col :span="12" class="mb20">
          <el-form-item label="字段名" prop="fieldName">
            <el-input v-model="form.fieldName" placeholder="请输入字段名" />
          </el-form-item>
        </el-col>

        <!-- 字典下拉 -->
        <el-col :span="12" class="mb20">
          <el-form-item label="状态" prop="status">
            <el-select v-model="form.status">
              <el-option
                v-for="(item, index) in status_dict"
                :key="index"
                :label="item.label"
                :value="item.value"
              />
            </el-select>
          </el-form-item>
        </el-col>

        <!-- 单选组 -->
        <el-col :span="12" class="mb20">
          <el-form-item label="类型" prop="type">
            <el-radio-group v-model="form.type">
              <el-radio
                v-for="(item, index) in type_dict"
                :key="index"
                :label="item.value"
                border
              >{{ item.label }}</el-radio>
            </el-radio-group>
          </el-form-item>
        </el-col>
      </el-row>
    </el-form>

    <template #footer>
      <span class="dialog-footer">
        <el-button @click="visible = false">{{ $t('common.cancelButtonText') }}</el-button>
        <el-button @click="onSubmit" type="primary" :disabled="loading">{{ $t('common.confirmButtonText') }}</el-button>
      </span>
    </template>
  </el-dialog>
</template>

<script lang="ts" name="ModuleFormDialog" setup>
import { useDict } from '/@/hooks/dict';
import { useMessage } from '/@/hooks/message';
import { addObj, getObj, putObj } from '/@/api/module/xxx';
import { useI18n } from 'vue-i18n';
import { rule } from '/@/utils/validate';

const emit = defineEmits(['refresh']);
const { t } = useI18n();

const dataFormRef = ref();
const visible = ref(false);
const loading = ref(false);

// 字典
const { status_dict, type_dict } = useDict('status_dict', 'type_dict');

// 表单数据（列出所有字段，id 为空字符串）
const form = reactive({
  id: '',
  fieldName: '',
  status: '',
  type: '',
});

// 校验规则
const dataRules = ref({
  fieldName: [
    { validator: rule.overLength, trigger: 'blur' },
    { required: true, message: '字段名不能为空', trigger: 'blur' },
  ],
  status: [{ required: true, message: '状态不能为空', trigger: 'blur' }],
});

// 打开弹窗
const openDialog = (id?: string) => {
  visible.value = true;
  form.id = '';
  nextTick(() => {
    dataFormRef.value?.resetFields();
  });
  if (id) {
    form.id = id;
    loadData(id);
  }
};

// 加载数据（编辑时）
const loadData = (id: string) => {
  getObj(id).then((res: any) => {
    Object.assign(form, res.data);
  });
};

// 提交
const onSubmit = async () => {
  if (loading.value) return;
  loading.value = true;
  try {
    const valid = await dataFormRef.value.validate().catch(() => {});
    if (!valid) return;
    form.id ? await putObj(form) : await addObj(form);
    useMessage().success(t(form.id ? 'common.editSuccessText' : 'common.addSuccessText'));
    visible.value = false;
    emit('refresh');
  } catch (err: any) {
    useMessage().error(err.msg);
  } finally {
    loading.value = false;
  }
};

defineExpose({ openDialog });
</script>
```

### 父组件调用方式

```vue
<!-- index.vue 模板中 -->
<form-dialog @refresh="getDataList()" ref="formDialogRef" />

<!-- 触发 -->
formDialogRef.value.openDialog()        // 新增
formDialogRef.value.openDialog(id)      // 编辑
```

---

## 常见拆分方式

- 简单表单：`el-col :span="12"` 两列布局
- 复杂表单：使用 `el-collapse` 折叠高级属性（参考 `admin/client/form.vue`）
- 联动字段：用 `v-if="form.xxx.includes('...')"` 控制字段显示
