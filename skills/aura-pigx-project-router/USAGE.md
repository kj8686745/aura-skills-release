# PIGX 项目分流使用说明

## 适用场景

当前项目框架未知，但需求涉及 Vue/Vite 业务开发、CRUD、正式菜单与按钮权限、地图、视频或模块联邦配置时使用。本技能只读识别和分流，不实现业务、不写入项目或管理端。

非 PIGX 项目会退出；不完整候选只报告缺失证据。明确要求把候选项目建设为 PIGX 综合端时，才进入 Web 开发流程。

## 调用方式

- 自动：直接描述需求，分流器识别综合端后选择技能。
- 显式：`$aura-pigx-project-router 识别当前项目，并为本次需求选择技能。`

提供项目路径、需求目标及是否仅审计即可。地图/视频专项技能只有当前环境可用时才加载；不可用时会保留 Web 开发流程并说明原因。

## 示例提示词

- `识别当前项目是否为 PIGX 综合端；我要新增设备 CRUD 页面并创建正式菜单和按钮权限。`
- `识别当前项目；在设备地图中展示点位聚合、轨迹回放和热力图。`
- `识别当前项目；我要接入四路监控视频，支持全屏、PTZ 和拖拽换位。`
- `识别当前项目；新增 aura-order-web 运行时远程配置，先做基线检查，完成后复检。`
- `检查当前 PIGX 综合端模块联邦配置，只做审计，不修改代码。`
