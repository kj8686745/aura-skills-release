# 2D 地图开发规范

## 一、强制规则

- 2D 地图统一使用 `@fxft/ui-plus` 的 `FxftMap`。
- 禁止业务自行引入高德、百度、Mapbox、OpenLayers等 SDK绕过组件库。
- 优先使用公开 Props、Events和Exposes；不得依赖底层地图私有字段。
- 坐标渲染前统一归一化为 `{ lon, lat }` 并过滤非法范围。
- 点位使用稳定业务 `id`，图层名必须有业务语义。
- HTML Marker 聚合、PNG/HTML 动态切换、同点位坐标更新和聚合文字对齐要求 `@fxft/ui-plus >= 1.0.37`。

组件接入见[组件复用与公司 UI 规范](./组件复用与公司基础组件库规范.md)。

## 二、基础页面

```vue
<template>
	<div class="layout-padding">
		<div class="layout-padding-auto layout-padding-view map-page">
			<FxftMap
				ref="mapRef"
				:center="{ lon: 119.3052, lat: 26.07 }"
				:zoom="12"
				:show-layer-switcher="true"
				:show-map-tool="true"
				@load="onMapLoad"
				@map-click="onMapClick"
			/>
		</div>
	</div>
</template>

<script setup lang="ts">
const mapRef = ref<any>();

const onMapLoad = () => {
	// 地图已就绪后再渲染点位、轨迹或图形。
};

const onMapClick = (event: unknown) => {
	console.log('地图点击', event);
};
</script>

<style scoped>
.map-page {
	width: 100%;
	height: 100%;
	min-height: 480px;

</style>
```

地图父容器必须有明确高度。业务页位于综合端内容区时不要使用 `100vh`。

## 三、坐标归一化

```ts
const getNumberValue = (...values: unknown[]) => {
	const value = values.find((item) => Number.isFinite(Number(item)));
	return value === undefined ? undefined : Number(value);
};

const normalizeCoordinate = (item: any) => {
	const lon = getNumberValue(item.lon, item.lng, item.longitude);
	const lat = getNumberValue(item.lat, item.latitude);

	if (lon === undefined || lat === undefined) return null;
	if (lon < -180 || lon > 180 || lat < -90 || lat > 90) return null;
	return { lon, lat };
};
```

坐标顺序统一为经度、纬度。禁止把 `[lat, lon]` 直接传入地图。

## 四、地图选点

地图选点使用 `FxftMap` 的 `map-click` 获取左键点击事件，其中 `coordinate.x` 为经度、`coordinate.y` 为纬度。

```vue
<template>
	<FxftMap ref="mapRef" @map-click="handleMapClick" />
</template>

<script setup lang="ts">
type SelectedLocation = {
	longitude: number;
	latitude: number;
};

const mapRef = ref<any>();
const selectedLocation = ref<SelectedLocation>();
const locationPickerLayer = 'locationPickerMarkerLayer';

const updateSelectedLocation = (longitude: number, latitude: number) => {
	if (!Number.isFinite(longitude) || !Number.isFinite(latitude)) return;
	if (longitude < -180 || longitude > 180 || latitude < -90 || latitude > 90) return;

	selectedLocation.value = { longitude, latitude };
	mapRef.value?.addPoint?.(
		{
			id: 'selected-location',
			lon: longitude,
			lat: latitude,
		},
		{
			clear: true,
			cluster: false,
			enableClick: false,
		},
		locationPickerLayer
	);
};

const handleMapClick = (payload: any) => {
	updateSelectedLocation(
		Number(payload?.coordinate?.x),
		Number(payload?.coordinate?.y)
	);
};

// 中文地址查询得到坐标后复用同一入口，避免表单值与地图回显不一致。
const handleAddressResolved = (longitude: number, latitude: number) => {
	updateSelectedLocation(longitude, latitude);
};
</script>
```

- 地图选点使用 `@map-click`，不得使用 `startDraw('point')`、`draw-end` 或 `initDraw`。
- 使用固定点位 ID、独立语义图层和 `{ clear: true, cluster: false }`，确保只回显一个 marker。
- 未要求自定义 marker 时，不传 `icon`、`markerWidth`、`markerHeight`，使用组件默认 marker。
- 中文地址搜索与鼠标点击必须调用同一个坐标和 marker 更新方法。
- 经度必须位于 `-180~180`，纬度必须位于 `-90~90`；搜索结果和点击事件都要校验后再写入表单。
- 地址查询、正向解析和逆解析优先复用项目已有 API，不得为选点额外引入地图 SDK。
- 提交接口前核对后端真实字段：接口只接收地址时只提交地址；提供经纬度字段时按真实字段提交，禁止猜测 `longitude`、`latitude` 等字段名。

## 五、点位和聚合

```ts
import deviceIconSource from '/@/assets/images/map/device.png';
import { getStaticResourceUrl } from '/@/hooks/moduleFederation';

const deviceMarkerLayer = 'deviceMarkerLayer';
const deviceIcon = getStaticResourceUrl(deviceIconSource);

const renderDevicePoints = (rows: any[], clear = true) => {
	const points = rows
		.map((item) => {
			const coordinate = normalizeCoordinate(item);
			return coordinate
				? {
					id: item.id,
					...coordinate,
					icon: deviceIcon,
					customData: item,
				}
				: null;
		})
		.filter(Boolean);

	mapRef.value?.addPoint?.(
		points,
		{
			cluster: true,
			clear,
			enableClick: true,
			maxClusterZoom: 16,
			forceRenderOnMoving: true,
			forceRenderOnZooming: true,
			forceRenderOnRotating: true,
			animation: false,
			clusterTextAlign: 'center',
			clusterTextVerticalAlign: 'middle',
			clusterTextDx: 0,
			clusterTextDy: 0,
			markerWidth: 36,
			markerHeight: 36,
		},
		deviceMarkerLayer
	);
};

const removeDevicePoint = (id: string | number) => {
	mapRef.value?.clearPointById?.(id, deviceMarkerLayer);
};
```

- 单个或少量点位删除使用 `clearPointById`。
- 追加数据使用 `{ clear: false }`。
- 只有整体数据源或聚合配置变化时才使用 `{ clear: true }` 或 `clearLayer`。
- 不使用时间戳或随机数作为会变化的点位 ID。
- 圆形聚合背景默认使用 `center` / `middle`；`clusterTextDx`、`clusterTextDy` 仅用于不规则 PNG 的视觉中心微调。
- 聚合层启用三个 `forceRenderOn*` 选项，全部 marker 可能隐藏时设置 `animation: false`，避免缩放闪烁、贴屏漂移和空范围动画错误。

### HTML Marker 参与原聚合

`@fxft/ui-plus >= 1.0.37` 使用公开方法 `updatePointMarker(id, presentation, layerName)`，在同一稳定点位上切换图片与 HTML 表现。HTML Marker 通过底层透明普通 Marker 代理参与原聚合，不创建第二套图层。

```ts
const showSosMarker = (
	pointId: string,
	longitude: number,
	latitude: number,
	content: HTMLElement
) => {
	mapRef.value?.updatePointMarker?.(
		pointId,
		{
			type: 'html',
			coordinate: { lon: longitude, lat: latitude },
			content,
			horizontalAlignment: 'middle',
			verticalAlignment: 'middle',
			dx: 0,
			dy: 0,
		},
		deviceMarkerLayer
	);
};

const restoreDeviceMarker = (
	pointId: string,
	longitude: number,
	latitude: number,
	markerFile: string
) => {
	mapRef.value?.updatePointMarker?.(
		pointId,
		{
			type: 'image',
			coordinate: { lon: longitude, lat: latitude },
			symbol: {
				markerFile,
				markerWidth: 36,
				markerHeight: 36,
			},
		},
		deviceMarkerLayer
	);
};
```

- `pointId` 和 `layerName` 必须与原 `addPoint` 完全一致；禁止通过删除、重新添加或新建 HTML 图层模拟切换。
- 动态事件（例如 SOS）提供有效坐标时，以事件坐标更新匹配到的稳定点位；业务只传 `{ lon, lat }`，组件负责转换为底层坐标。
- HTML Marker 切回图片后必须保留原 id、显隐状态和聚合关系。
- HTML `content` 优先传可信 DOM 或静态模板，不拼接未经处理的用户输入。

## 六、轨迹回放

```ts
import movingIconSource from '/@/assets/images/map/vehicle.png';
import startIconSource from '/@/assets/images/map/track-start.png';
import endIconSource from '/@/assets/images/map/track-end.png';

const vehicleTrackLayer = 'vehicleTrackLayer';

const renderTrack = (rows: any[]) => {
	const points = rows
		.map((item) => {
			const coordinate = normalizeCoordinate(item);
			return coordinate ? { ...coordinate, time: item.time, speed: item.speed } : null;
		})
		.filter(Boolean);

	if (points.length < 2) {
		mapRef.value?.clearTrack?.();
		return;
	}

	mapRef.value?.playTrack?.(
		points,
		{
			playNow: false,
			fit: true,
			lineColor: '#409EFF',
			icon: getStaticResourceUrl(movingIconSource),
			startIcon: getStaticResourceUrl(startIconSource),
			endIcon: getStaticResourceUrl(endIconSource),
		},
		vehicleTrackLayer
	);
};

const showTrack = () => mapRef.value?.showTrackLayer?.();
const hideTrack = () => mapRef.value?.hideTrackLayer?.();
const seekTrack = (progress: number) => mapRef.value?.setTrackProgress?.(progress);
```

- 过滤后少于两个有效点时不调用 `playTrack`。
- 时间轴使用 `track-progress` 的 `currentTime`、`startTime`、`endTime`。
- 按距离控制使用 `distanceProgress` 和 `setTrackProgress(0~100)`。
- 显隐使用 `showTrackLayer`、`hideTrackLayer`，不要清空后重绘。
- 只切换采样点使用 `setTrackPointsVisible`。
- 必须显式传入业务图标，不依赖组件内部默认外部地址。

## 七、热力图

```ts
const alarmHeatLayer = 'alarmHeatLayer';

const heatPoints = rows
	.map((item) => {
		const coordinate = normalizeCoordinate(item);
		const value = getNumberValue(item.value, item.count, item.weight);
		return coordinate && value !== undefined
			? [coordinate.lon, coordinate.lat, value]
			: null;
	})
	.filter(Boolean);

if (heatPoints.length) {
	mapRef.value?.setHeat?.(heatPoints, { radius: 18, max: 100 }, alarmHeatLayer);
} else {
	mapRef.value?.clearLayer?.(alarmHeatLayer);
}
```

热力点必须同时有经度、纬度和数值权重；无有效数据时先清理并显示空态。

## 八、绘制、GeoJSON和图层定位

本节仅适用于需要编辑或保存为 GeoJSON 的点、线、圆、矩形和多边形。普通位置选择遵循“地图选点”章节，不进入绘制模式。

```ts
const fenceDrawLayer = 'fenceDrawLayer';
const districtGeoJSONLayer = 'districtGeoJSONLayer';

const startFenceDraw = () => mapRef.value?.startDraw?.('polygon', fenceDrawLayer);
const stopFenceDraw = () => mapRef.value?.stopDraw?.();
const resetFenceDraw = () => mapRef.value?.resetDraw?.();

const renderDistrict = (geojson: any) => {
	if (!geojson || typeof geojson.type !== 'string') return;
	mapRef.value?.renderGeoJSON?.(
		geojson,
		{ clear: true, fitView: true, flyTo: true },
		districtGeoJSONLayer
	);
};

const locateFence = () =>
	mapRef.value?.flyToLayer?.(fenceDrawLayer, { zoomOffset: -1, duration: 700 });

const exportMap = () => mapRef.value?.exportImage?.({ mimeType: 'image/png' });
```

- 交互绘制使用 `startDraw`，API绘制使用 `drawByType`。
- `stopDraw` 结束当前绘制；需要彻底丢弃 DrawTool状态时使用 `resetDraw`。
- 继续编辑已有 GeoJSON 使用 `initDraw`；只读展示使用 `renderGeoJSON`。
- GeoJSON 至少校验 `type`、坐标数组和 `[lon, lat]` 顺序。
- `fitLayer`、`flyToLayer` 在图层不存在或无有效范围时会返回 `false`。

## 九、故障排查

| 现象 | 优先检查 |
| --- | --- |
| 地图空白 | 父容器高度、组件库样式、地图资源请求、控制台错误 |
| 点位不显示 | 坐标范围、经纬度顺序、图标 URL、图层是否被隐藏 |
| HTML 点位不参与聚合 | `@fxft/ui-plus` 是否不低于 `1.0.37`、是否复用原稳定 ID 和图层、是否通过 `updatePointMarker` 切换 |
| HTML 点位位置异常或报 `Position is NaN` | 是否传入有限的 `{ lon, lat }`、是否误传底层坐标对象、经纬度顺序是否颠倒 |
| 聚合数字不居中 | 是否使用 `clusterTextAlign: 'center'` 与 `clusterTextVerticalAlign: 'middle'`；不规则背景再检查 `clusterTextDx/Dy` |
| 缩放或静止时 Marker 闪烁 | 是否启用三个 `forceRenderOn*`、关闭不必要的 `animation`、是否在视图事件中反复重建点位 |
| 地图选点无响应 | 是否监听 `map-click`、是否从 `coordinate.x/y` 读取经纬度、坐标是否通过范围校验 |
| 删除点位无效 | 删除 ID是否与添加时稳定 ID完全一致、图层名是否一致 |
| 轨迹无法创建 | 有效点是否不少于2个、时间和坐标是否可解析 |
| 远程页面图标404 | import 图标是否经过 `getStaticResourceUrl` |
| GeoJSON不显示 | `type`、coordinates、坐标顺序和目标图层 |
| 导出为空 | 地图是否加载完成、底图是否受跨域 Canvas限制 |

## 十、检查清单

- [ ] 已安装批准版本的 `@fxft/ui-plus` 并配置 resolver。
- [ ] 页面使用 `FxftMap`，未引入其他地图 SDK。
- [ ] 父容器高度有效，未使用 `100vh` 抢占布局。
- [ ] 坐标已归一化和过滤。
- [ ] 普通地图选点使用 `map-click` 和 `addPoint`，未误用几何绘制 API。
- [ ] 选点只回显一个默认 marker，中文地址搜索与点击选点共用更新入口。
- [ ] 经度、纬度范围和接口真实字段已校验。
- [ ] 点位 ID稳定，图层名有业务语义。
- [ ] 单点删除未通过整层重绘实现。
- [ ] HTML Marker 使用 `updatePointMarker` 复用原稳定点位和聚合图层，PNG ↔ HTML 双向切换与坐标更新正常。
- [ ] 一位数和多位数聚合数字均相对背景水平、垂直居中，不规则背景偏移配置正确。
- [ ] 缩放、拖动、旋转时普通点位、HTML 点位和聚合图标无漂移、无闪烁，控制台无 `Position is NaN`。
- [ ] 轨迹至少两个点，图标已做远程资源转换。
- [ ] 热力点包含权重。
- [ ] GeoJSON渲染前已校验。
- [ ] 独立运行和远程运行均无资源404和样式缺失。

## 十一、地图 SDK 构建维护约束

本节仅供 `fmap-2d` SDK 和地图组件库维护者使用，普通业务页面不得自行修改 SDK 构建产物。

- IIFE、CJS 和 CSS 生产构建必须开启 minify；压缩构建移除内部 legal comments，但保留对外 License Header。
- 嵌入 JavaScript 的 HTML 模板应在源代码中紧凑化，或使用只处理 HTML 语义的安全 minifier。
- 禁止对全部模板字符串执行全局空白正则替换，以免破坏 CSS、GLSL 或业务文本。
- 构建后必须验证 `fmap.min.js`、CJS 语法和 HTML Marker 聚合示例，确认 HTML 标签间无无效缩进且功能不变。
