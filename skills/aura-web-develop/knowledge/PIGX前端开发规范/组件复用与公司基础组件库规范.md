# 组件复用与公司基础组件库规范

## 大数据量选择器

候选数量较大、数量无明确上限或可能持续增长的选择器，必须使用虚拟化选择器 `el-select-v2`，或经真实公开契约核实具备等效虚拟滚动能力的公共选择组件；禁止使用普通 `el-select` 一次性渲染全部选项。候选数量明确且规模较小时可使用普通选择组件。选择依据是候选集合规模、增长特征和实际渲染方式，不绑定业务类别，也不把开发环境当前样本较少当作规模上限。

远程搜索与分页控制取数规模，不能替代大结果集的虚拟化渲染。组件迁移必须核对当前安装版本的 `options`、值类型、分组、禁用、清空、搜索、插槽及回显契约，不能只替换标签名或继续逐项创建全部 `el-option`。自定义选项内容与行高须符合虚拟列表布局，避免裁切或滚动错位；查询候选失败按该控件的空数据处理，不将可选候选失败升级为整个页面或表单主数据失败。


## 一、选型与归属

1. 公共 TS/Hook 先查 [aura-web-kit 能力清单](./aura-web-kit能力清单与接入规范.md)；公共 UI 先查 `@fxft/aura-ui` 的实际导出与类型。
2. 地图、视频等专项能力按需使用 `@fxft/ui-plus`。
3. 其余通用 UI 使用 Element Plus；读取候选组件官方文档并核对当前版本接口。
4. 页面私有组件放在业务目录；跨业务公共 TS 进入 web-kit，通用 Aura UI 进入 aura-ui，不复制框架实现。

1.2.0 验证基线：`@fxft/aura-ui@1.1.2`、`@fxft/aura-web-kit@1.6.15`、Element Plus `2.14.6`。组件名、Props、Events、Slots、Exposes 均以已安装版本为准。

**为什么需要**：大候选集合中，DOM 节点数应受可视窗口限制，以降低渲染与更新负担。

**判断要点 / 验证方式**：以代表性大数据验证滚动、搜索、清空、选择值与详情回显，确认已渲染选项随可视窗口变化，而非等于全部候选。自定义内容及行高需检查裁切和滚动错位。只看到 el-select-v2 标签或启用 remote 不能判性能通过。

**正反例补充**：无明确上限时使用 options 数据驱动的虚拟列表，保持目标版本值类型与选项契约；仅为普通 el-select 增加 filterable 或 remote 并一次性创建大量 el-option，仍不符合规则。

官方契约参考：[Element Plus Virtualized Select](https://element-plus.org/en-US/component/select-v2.html)。按目标项目已安装版本核对，不将官方新版本能力推定为旧版本可用。

#### 虚拟化选择器示例

以下为按需接收候选数据的独立组件片段，父级传入国际化后的 placeholder，不创建语言键或写死用户文案。候选集合按 `options` 交给虚拟列表，不逐项生成全部 `el-option`；非固定小规模候选采用此模式，并核对目标版本的真实公开契约。

```vue
<template>
  <el-select-v2
    v-model="selectedValue"
    :options="options"
    :placeholder="placeholder"
    filterable
    clearable
    style="width: 100%"
  />
</template>

<script setup lang="ts">
import { ref } from 'vue';

// 候选值类型由接口确定，示例保留字符串和数字，不转成文本提交。
interface ChoiceOption {
  value: string | number; // 提交值，保持原始类型。
  label: string; // 当前语言的选项显示名称。
  disabled?: boolean; // 是否禁止选择此项。
}
defineProps<{
  options: ChoiceOption[]; // 已加载的候选集合，具体取数策略由所属查询管理。
  placeholder: string; // 调用方使用既有国际化服务取得的占位文案。
}>();
const selectedValue = ref<string | number>(); // 当前选择，清空后按组件契约处理。
</script>
```

自定义多行内容时按当前组件版本设置与实际内容一致的行高并验证滚动；远程搜索、分页及接口失败状态由候选读取流程管理，不把本片段当成完整接口或任意规模的性能证明。

## 二、Aura 公共 UI

| 组件 | 场景 |
| --- | --- |
| `AuraPagination`、`AuraRightToolbar` | 分页、查询表格工具栏 |
| `AuraDictTag`、`AuraDictSelect`、`AuraDictText` | 字典展示、选择、文本 |
| `AuraQueryTree`、`AuraOrgTreeView`、`AuraOrgSelector` | 查询树与组织选择 |
| `AuraUpload`、`AuraUploadImg`、`AuraUploadImgPlus`、`AuraUploadExcel` | 上传与导入 |
| `AuraEditor`、`AuraCodeEditor`、`AuraMdRenderer` | 编辑和内容展示 |
| `AuraDelWrap`、`AuraTagList`、`AuraSvgIcon` | 删除确认、标签、图标 |
| `AuraChinaArea`、`AuraSign`、`AuraFormTable` | 区划、签名、表单表格 |
| `AuraIconSelector`、`AuraBusinessIconPicker` | 图标选择 |

公共组件使用 Aura 前缀标签，不依赖旧 `src/components/index.ts` 全局别名。迁移旧组件时核对 Props/事件，不能只改标签。`AuraButton`、`AuraTag`、`AuraDatePicker` 等不是本基线公开组件，不凭前缀虚构。

```ts
import Components from 'unplugin-vue-components/vite';
import AuraUIResolver from '@fxft/aura-ui/resolver';

Components({
  dirs: [],
  dts: './components.d.ts',
  resolvers: [AuraUIResolver()],
});
```

`AuraUIResolver` 同时注入组件 JS 与 `sideEffects` 样式。生成声明不代表运行时已正确解析；须检查远程构建产物。显式 import 时同时遵守该版本组件样式契约。

## 三、项目服务绑定与本地覆盖

公共 UI 通过 `@fxft/aura-ui/config` 的 `provideAuraUiConfig` 在 setup 边界注入并合并配置。核心布局提供其自身 UI 绑定；需要本项目请求的远程业务边界显式绑定：

```ts
import { provideAuraUiConfig } from '@fxft/aura-ui/config';
import request from '/@/config/aura/request';

provideAuraUiConfig({ request });
```

不设置模块级可变配置，不假定宿主执行提供方 `main.ts`。字典、上传等其他配置字段先核对包声明。

仅有实际本地覆盖项时使用公共 Resolver；项目只维护覆盖映射：

```ts
import { createComponentOverrideResolver } from '@fxft/aura-web-kit/vite/component-overrides';

const componentOverrides = { ElEmpty: './src/components/ElEmpty/index.vue' };
// pathResolve 必须输出正斜杠路径。
Components({
  dirs: [],
  dts: './components.d.ts',
  resolvers: [createComponentOverrideResolver(componentOverrides, pathResolve), AuraUIResolver()],
});
```

没有覆盖项时无需 `componentOverrides.ts`；不能用同名全局注册代替编译期覆盖。

## 四、地图与视频

`@fxft/ui-plus` 是业务按需依赖；实际需要时安装项目批准的固定版本并合并 `FxftUiPlusResolver`，不重复注册、不覆盖现有配置、不加入框架 shared。认证和私服配置见 [下载说明](./公司组件库下载说明/README.md)，凭据不写入源码或对外文档。

| 场景 | 组件与规范 |
| --- | --- |
| 2D 地图、轨迹、热力、绘制 | `FxftMap`；[2D 地图规范](./2D地图开发规范.md) |
| 单路直播、录像、PTZ | 按已安装版本核对播放器；[视频规范](./视频开发规范.md) |
| 多路分屏、拖拽、轮巡 | 按已安装版本核对多路播放器；[视频规范](./视频开发规范.md) |

## 五、验收

- 只调用公开接口，复杂组件的 ref 只使用公开 Exposes。
- Element Plus `2.14.6` 保持 shared singleton；Aura UI 与业务组件库按当前模板实际依赖接入，不擅自扩展 shared。
- 独立和远程加载均能解析组件及样式，控制台没有 `Failed to resolve component`。
- UI 服务来自正确的项目上下文，多个远程业务之间不串用请求或可变配置。

本轮用户授权的本地字典补充：业务枚举/字典展示必须使用 `AuraDictTag` / `AuraDictText`；依赖、实际导出/类型及显式 import 或自动导入/Resolver 需核实，不能手写映射替代。完整边界见[字典契约](../../references/ui-data-contracts.md)，来源见技能 `references/readability-source.json`。

## 字典展示组件介绍（本轮本地补充）

本轮只补充以下三个组件，依据安装包 `@fxft/aura-ui@1.1.2` 的声明与运行产物，并对照上游说明；开发与审查命中时读取 [aura-ui 组件库入口](aura-ui组件库/README.md)，入口含共用字段及精确来源，再按实际组件加载 DictTag.md / DictText.md / DictSelect.md 的 Props、匹配/空值和插槽说明。当前上游源码版本为 1.1.5，不能替代安装版证据。来源见技能 `references/readability-source.json`，不宣称已同步规范源。

| 组件 | 用途与 API 概要 |
| --- | --- |
| `AuraDictTag` | 字典标签，`options` + 单值或数组 `value`，支持自定义字段键、类型/颜色及条件图标插槽；无匹配兜底为 `emptyText`，按 options 顺序展示匹配项；无暴露方法及自定义事件 |
| `AuraDictText` | 字典纯文本，`options` + 单值 `value`，支持 type/color/size/ellipsis/maxWidth/tag；无匹配兜底为 `fallback`，不提供 `emptyText`、数组值、自定义字段键或暴露方法/自定义插槽/事件 |
| `AuraDictSelect` | 字典筛选/表单选择，options 或 dictType/request，支持单选/多选；模型类型保留，先发 update:modelValue 再发 change，无公开加载方法或自定义插槽，详见组件库目录对应页 |
