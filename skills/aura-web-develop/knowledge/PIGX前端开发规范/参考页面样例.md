# 参考页面样例

## 说明

本文档列出 PIGX 项目中已验证的页面模式，每个样例说明其页面类型和关键实现要点。

生成新页面时，找到与目标原型最相似的样例，按其关键要点对应的规范生成代码。样例的组件与 Hook 列表不是每页必备文件；按[职责决策表及正反例](文件组织与职责拆分.md)选择保留、同级私有文件或拆分，独立职责的状态和样式一起迁移。

示例描述不能替代专项规范；实际代码必须以当前模块联邦（综合端）源码、组件类型和本目录检查清单为准。

---

- 查询 API 在提交边界使用 request 显式 queryFormat，保留有效 0/false；列表和导出复用同一条件且不修改查询模型。先核对消费者实际安装的公开入口，useTable 不自动格式化。
- 普通选择器仅适用于候选数量明确且规模较小；其余按候选规模和增长特征使用虚拟化选择器，不按业务名称判定。

## 样例 1：标准查询表格页（含弹窗表单）

**页面类型：** query-table + dialog-form

**关键要点：**

- 使用 `useTable` 管理分页查询
- `AuraRightToolbar` 右侧工具栏（显示/隐藏搜索、导出）
- `AuraDictTag` 渲染字典值
- `v-auth` 按钮权限控制
- `defineAsyncComponent` 异步引入弹窗
- `form.vue` 使用 `defineExpose({ openDialog })` + `emit('refresh')` 模式
- `el-collapse` 折叠高级属性区（可选）

---

## 样例 2：只读查询表格页（无编辑，仅删除）

**页面类型：** query-table（read-heavy）

**关键要点：**

- 无新增/编辑弹窗
- 使用 `sortChangeHandle` 支持列排序
- 批量删除使用 `selectObjs` + `multiple` 控制

---

## 样例 3：左树右表页

**页面类型：** left-tree-right-table

**关键要点：**

- `Splitpanes` + `Pane` 分割布局
- `AuraQueryTree` 组件实现树形搜索
- 树节点点击通过 `@node-click` 事件通知右侧
- 右侧子组件通过 `ref` + 暴露方法接收数据
- 悬停显示操作按钮（`.do { display: none }` + `:hover .do { display: inline-block }`）

---

## 样例 4：复杂弹窗表单（含联动字段 + 折叠区）

**页面类型：** dialog-form（complex）

**关键要点：**

- `v-if` 控制联动字段显示（如 `v-if="form.authorizedGrantTypes.includes('authorization_code')"`）
- `el-collapse` 包裹高级/安全属性
- `el-input-number`、`el-radio-group`、`el-select` 多种表单控件混合使用
- `rule.overLength`、`rule.validatorLowercase` 等自定义校验器

---

## 样例 5：代码生成器页（含子组件拆分）

**页面类型：** complex-list（多子组件组合）

**关键要点：**

- 多个子组件按独立职责拆分，父页保留必要编排，避免只搬模板后传入整页 state
- `batchGenDialog.vue` 演示了复杂弹窗的分步操作

---

## 样例 6：模块联邦远程订单页

**页面类型：** module-federation-page

**关键映射：**

```text
remoteName:   aura-order-web
expose key:   ./views/order/list/index.vue
componentPath:
/aura-order-web/views/order/list/index.vue?type=moduleFederation
```

- 页面 expose、i18n、scoped Tailwind和静态资源必须形成闭环。
- 菜单第一段使用 `remoteName`，不能使用 `remoteEntryName`。
- 参考[模块联邦开发技术规范](./模块联邦开发技术规范.md)。

---

## 样例 7：设备点位和轨迹页

**页面类型：** map-page

- 使用 `FxftMap`，点位使用稳定设备ID和 `deviceMarkerLayer`。
- 坐标归一化为 `{ lon, lat }`。
- 轨迹图标经过 `getStaticResourceUrl`，显隐使用公开轨迹方法。
- 参考[2D 地图开发规范](./2D地图开发规范.md)。

---

## 样例 8：多路监控页

**页面类型：** multi-video-page

- 使用 `FxftWebMultiVideo`，每个通道提供稳定 `channel.id`。
- 视频源使用 `WebVideoSource`，协议引擎按需加载；public 视频和 import 海报分别使用对应资源工具。
- 标签页或弹窗显隐按当前组件可见性调度处理，不调用未公开的 `resize()`。
- 参考[视频开发规范](./视频开发规范.md)。

## 样例 9：前端常量定义与复用

**页面类型：** 通用业务页面（常量定义与复用）

**关键要点：**

- 归属与命名按[前端常量归属与定义](工程与代码生成规范.md#前端常量归属与定义)，仅在实际共享时提升到最小共同范围。
- 项目公共限制、业务状态/权限和页面私有参数分别归属；可变表单初值通过工厂创建，不作为共享常量对象。
- 固定状态与权限编码是教学示例，动态字典、可见文案、环境配置和运行状态仍使用各自来源。

以下数值、状态及权限编码均为教学示例，复制前必须核对真实上传契约、状态定义与权限注册；它们不代表公司接口约定。路径按所属层级调整，`/@/` 以项目别名为准。

### 项目公共上传限制

```ts
// src/constant/upload.ts
/** 示例：单文件最大 10 MiB（含上限）；须与真实上传契约一致。 */
export const UPLOAD_MAX_FILE_SIZE_BYTES = 10 * 1024 * 1024;
/** 示例：一次最多选择 5 个文件（含上限）。 */
export const UPLOAD_MAX_FILE_COUNT = 5;
```

```ts
// src/views/document/uploadValidation.ts：提交仍按后端协议校验。
import { UPLOAD_MAX_FILE_COUNT, UPLOAD_MAX_FILE_SIZE_BYTES } from '/@/constant/upload';

const canUpload = (files: File[]) =>
  files.length <= UPLOAD_MAX_FILE_COUNT &&
  files.every((file) => file.size <= UPLOAD_MAX_FILE_SIZE_BYTES);
```

上传组件的 `limit` 和提交前校验复用同一语义定义；不把相同数值的“导出行数上限”复用为上传数量上限。

### 模块固定状态、权限及默认值

```ts
// src/views/device/constant/device.ts
/** 示例状态编码；须核对真实接口，动态字典不得照搬成本地枚举。 */
export const DEVICE_STATUS = {
  OFFLINE: 'offline', // 示例：离线。
  ONLINE: 'online', // 示例：在线。
} as const;

/** 固定状态编码联合类型，不包含界面翻译文案。 */
export type DeviceStatus = (typeof DEVICE_STATUS)[keyof typeof DEVICE_STATUS];

/** 示例权限码；须以真实权限注册与后端授权契约为准。 */
export const DEVICE_PERMISSION = {
  VIEW: 'example_device_view', // 示例：查看设备。
  EDIT: 'example_device_edit', // 示例：编辑设备。
} as const;
```

```ts
// src/views/device/deviceFormDefaults.ts：可变表单模型不作为共享常量对象。
/** 创建独立的示例表单初值，避免数组在多次打开之间共享。 */
export const createDeviceFormDefaults = () => ({
  name: '', // 设备名称。
  tags: [] as string[], // 本次编辑的标签集合。
});
```

```ts
// src/views/device/deviceActions.ts（状态判断、权限编码及表单工厂消费片段）。
import { DEVICE_PERMISSION, DEVICE_STATUS } from '/@/views/device/constant/device';
import { createDeviceFormDefaults } from '/@/views/device/deviceFormDefaults';
import type { DeviceStatus } from '/@/views/device/constant/device';

const requiredPermission = DEVICE_PERMISSION.EDIT;
const isOnline = (status: DeviceStatus) => status === DEVICE_STATUS.ONLINE;
const formModel = createDeviceFormDefaults();
```

消费文件同时需要类型时使用 `import type { DeviceStatus } from '/@/views/device/constant/device'`。权限常量仅承载编码，消费端按现有 `usePermissions` 与权限指令完成真实授权判断；不能用常量存在代替权限检查。显示状态文案在组件中按真实 i18n key 翻译，不在常量模块调用 `t()`。示例 `formModel` 按实际表单状态方案接入，重置需要新对象时再次调用工厂。

### 页面私有阈值与轮询参数

```ts
// src/views/device/overview/constant/monitor.ts
/** 示例：告警比例达到 80%（含）时进入提示态；输入范围为 0～100。 */
export const WARNING_PERCENT_THRESHOLD = 80;
/** 示例：本页面轮询间隔 15 秒，以毫秒传入现有轮询能力。 */
export const POLLING_INTERVAL_MS = 15_000;
```

```ts
// src/views/device/overview/index.vue 的 script setup 内消费；不得供其他页面反向引用。
import { POLLING_INTERVAL_MS, WARNING_PERCENT_THRESHOLD } from '/@/views/device/overview/constant/monitor';

const shouldWarn = (percent: number) => percent >= WARNING_PERCENT_THRESHOLD;
const pollingIntervalMs = POLLING_INTERVAL_MS;
```

轮询启动、暂停、请求与清理仍由页面/Hook 负责，参数文件不启动定时器。若仅当前一个文件使用且提取没有收益，上述两个定义可直接留在原文件。
