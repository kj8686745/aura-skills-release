# 页面模式选择

页面模式以 `knowledge/PIGX前端开发规范/README.md` 和其 `页面模式/` 目录为唯一正式来源。

| 页面特征 | 最新版页面模式 |
|---|---|
| 查询条件 + 工具栏 + 分页表格 | 查询表格页 |
| 查询条件 + 卡片列表 | 查询卡片页 |
| 左侧树/分类 + 右侧内容 | 左树右表页 |
| 新增/编辑对话框 | 弹窗表单 |
| 只读信息、关联数据、抽屉或详情路由 | 详情页与抽屉 |
| 指标卡、图表、重点列表 | 看板页 |
| 同一路由内多层覆盖且需要保留父状态 | Teleport 嵌套页面 |

## 选择流程

1. 先按业务信息结构匹配页面模式。
2. 再读取模式引用的工程、样式、组件、路由或模块联邦专项规范。
3. 对照当前项目相邻页面确认真实组件名、Hook 签名、权限码、API 和 i18n。
4. 截图、HTML 原型、Figma 或设计工具只补充业务内容与视觉信息，不改变 PIGX 工程、路由、模块联邦和资源规则。
5. 同时命中多个模式时，确定一个页面主模式，并按区块组合其他模式；不要把多个完整骨架嵌套复制。

Teleport 只适合同路由临时覆盖层。需要独立 URL、刷新恢复、浏览器前进后退、菜单入口或模块联邦加载时，使用最新版路由方案。
