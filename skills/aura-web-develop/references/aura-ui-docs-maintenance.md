# aura-ui 组件资料维护

维护技能 UI 资料时读取本页。业务开发从 [能力清单](../knowledge/PIGX前端开发规范/aura-ui能力清单与接入规范.md) 和 [组件索引](../knowledge/PIGX前端开发规范/aura-ui组件库/README.md) 按需查阅。

## 文档组织

- 技能统一维护一套当前组件资料，全部组件页直接放在 aura-ui组件库目录，README.md 为组件索引。
- 资料依据本地 SDK 的 docs/component、组件公开声明、配置、Resolver 和运行实现整理，能力清单保留公共接入约定。
- 组件页保留基础示例、Props、事件、插槽、公开方法、数据结构及实际限制，声明从 SDK 公开入口提取。
- 文档站的交互示例容器转换为可独立阅读的内联示例，组件通过公开入口显式导入，公共接入链接指向技能内资料。

## 更新与检查

1. 依据当前 SDK 核对公开导出、声明、配置、Resolver 和 JS/CSS，更新能力清单与受影响组件页。
2. 将技能入口、规范导航、组件选型、字典规则及校验清单统一指向组件根目录，组件页按实际使用情况加载。
3. 检查组件覆盖、声明与示例、UTF-8、相对引用，运行技能结构校验。web-kit 清单使用其专用检查器。
4. 项目接入同时核对实际安装包的公开契约，按用户授权完成构建、接口和浏览器验证。

团队分发时将组件资料、技能导航和校验改动一并同步到实际维护的技能源码仓库，按仓库流程发布。
