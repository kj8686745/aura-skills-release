# 常见 BUG 开发自测清单

功能开发或修复涉及下列行为时，只执行本次需求和受影响链路命中的项目。先从需求、真实接口契约和已有行为列出应覆盖的字段、操作及预期结果，再选能区分正确与错误实现的样本。验证时机与范围沿用[检查选择表](development-review-workflow.md#检查选择表)。

复用仍有效且断言覆盖本次行为的已有测试。接口直测可验证实际提交样本的查询、校验和产物契约。前端接线发生变化时，从页面入口或已有组件、集成或端到端测试触发实际操作，核对事件、提交值和消费结果。必须观察页面渲染、交互或实际下载且已有证据不足时，按既有流程定向走查。

## 分页点击与数据正确性

新增或修改列表分页、表格绑定或分页 API 适配时，准备至少两页且各页有可区分记录的稳定数据。仅修改 API 时，直接请求两页并核对每页参数、记录 ID 和总条数。分页控件或绑定变更时，从第一页点到第二页再返回，核对当前页和提交的页码、每页条数符合预期，展示的记录 ID 和总条数与实际响应相符。涉及每页条数、筛选或排序联动时，按实际入口核对契约规定的页码重置或保留行为、参数及最终记录。列表绑定及 API 适配见 [Hooks 契约](../recipes/hooks-standards.md#usetable)。

## 需求字段的模糊与精准搜索

新增或修改查询字段、匹配方式或状态筛选时，逐一覆盖需求字段。模糊查询使用能命中多条记录的部分值及无关记录，核对实际命中集合。精准查询准备完整值和相似值，输入完整值应仅命中精确匹配项，输入只有部分相同的值应排除该项。涉及启用、禁用筛选时，准备其他条件相同的启用与禁用记录，分别查询并核对提交的状态值和最终记录。若状态编码含 `0` 或 `false`，验证有效值成功提交。涉及清空、重置或组合条件时，再核对实际提交值和结果集。参数规则见[查询与选择器契约](query-select-contract.md)。

## 导入与导出字段、校验和文件

新增或修改导入模板、字段映射、校验或导出范围时，以需求规定的字段清单逐项对照相关模板、解析结果和下载文件。例如需求规定五个字段，任一应包含全部五项的环节只出现四项即不通过。准备一份每个字段均可辨认的有效样本，导入后按接口契约核对成功结果及写入后的字段值，逐项检查映射。再试缺少一个必填值和违反一项实际规则的样本，核对实际校验反馈、约定的错误定位与导入结果。以契约约定判断整批拒绝或部分成功。

导出后打开实际生成的文件，核对列名、列数、字段值及记录范围。按真实接口契约选择可区分的筛选、选中记录或分页样本，核对请求与文件记录一致。分页导出、全量导出或选中记录导出的参数与范围按各自契约判断。参数构造见[查询与选择器契约](query-select-contract.md#查询条件在提交边界格式化)。

## 高频触发、重复提交与失败后重试

输入联动、高频事件需要防抖或节流时，使用 VueUse 的 `useDebounceFn`、`useThrottleFn` 等适用 API，在同一处理入口复用包装函数实例。按实际配置的时间窗口和首尾触发选项连续操作，核对调用次数、触发时机和生效值。按需验证快速查询时响应乱序，最终列表应对应最后有效条件。选型见 [VueUse 优先规范](vueuse-first-guidelines.md#必须优先用-vueuse-的场景)。

保存、导入、导出任务等同一操作需要防止并发重复时，从实际存在的入口触发，例如按钮、回车或表单提交。若有异步校验，在校验结束前重复触发。让首次请求保持未完成，在请求期间重复触发。已有防抖或节流窗口时，让首次请求跨过窗口再触发。核对整个操作期间只有一次提交。再让首次请求失败，确认处理中状态解除、失败反馈符合预期，重试恰好发出一次新请求并成功。

验证现有 `loading`、禁用态或处理锁是否覆盖上述实际入口和异步过程。只在下一次渲染生效的按钮状态仍要用连续触发验证。现有保护覆盖整个流程并通过验证时即可满足防重要求，防抖或节流仅在另有触发节奏需求时使用。

## 用户可见文案

新增或修改用户可见文案时，按需求、产品术语及项目同场景用词核对适用语言下的字形、译文和动态插值。仅修正资源中的错字时，已有断言或文案资源与有效绑定足以确认最终文案即可。文案绑定、显示条件或动态值变化且已有测试覆盖不足时，触发受影响的页面状态，核对实际呈现的标题、按钮、占位、校验或成功失败提示。文案能准确指向当前操作和对象、拼写及用词正确、变量值与反馈场景一致才通过。公共键复用与验收见 [i18n 契约](ui-data-contracts.md#新增文案的执行与验收)。

将命中项的输入或操作、可观察结果及证据简记到已有开发记录。检查不通过时修复本次授权范围内的问题并复查受影响项，缺少数据、环境或证据时记录具体缺口。后续补充案例沿用相应分类，保留可复现的样本和判定要点。
