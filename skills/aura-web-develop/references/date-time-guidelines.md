# 日期与时间处理强制约束

- 项目内日期与时间的解析、当前时间获取、格式化、有效性校验、比较、加减、差值、区间边界、时间戳及时区转换必须使用 `dayjs`。已有公共时间工具可以复用，但其实现也必须基于 `dayjs`；页面、组件、Hook、API 参数转换和工具函数均适用。
- 禁止用字符串 `slice/substring/split/replace` 截取或拼接日期时间、手写日期运算、原生 `Date` 运算或其它日期库替代 `dayjs`。组件或第三方 API 要求原生 `Date` 时，使用 `dayjs(...).toDate()` 转换；`setTimeout/setInterval` 等任务调度 API 不属于日期时间处理。
- 空值先按业务契约处理，解析后用 `isValid()` 检查；不得把缺失值自动转成当前时间，也不得向用户展示 `Invalid Date`。显示精度、接口格式、时间戳单位和时区遵循真实契约，例如秒级展示使用 `.format('YYYY-MM-DD HH:mm:ss')`；不因格式化擅自截断提交精度或改变时区。
- 按实际需要复用项目现有 `dayjs` 插件注册；自定义格式解析、UTC、时区和区间比较等能力使用对应插件，禁止以手写逻辑绕过。交付前检查本次修改中的时间处理，并验证相关格式、精度及空值行为。
