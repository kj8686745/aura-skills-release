# 基础能力接入检查

- [ ] 已确认项目 AURA 版本、公共模块和实际 Bean/配置状态。
- [ ] 已从能力地图选择具体入口，没有因为类名存在就推断能力已启用。
- [ ] 文件存储已确认本地或 S3 兼容实现、桶名、endpoint 和密钥来源。
- [ ] 对象键由服务端生成，业务记录保存对象键、类型、状态和归属。
- [ ] 上传、读取、删除分别经过用户、租户和业务资源权限校验。
- [ ] 输入流和对象流关闭策略、失败补偿和删除策略明确。
- [ ] 签名 URL 或 `/oss/*` 端点已有接口契约、鉴权、审计和有效期证据。
- [ ] 未在目标项目验证的入口标记为“未验证”。
