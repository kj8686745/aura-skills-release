# 基础通用支撑能力包使用技能

询问如何调用本技能时，阅读[使用说明](USAGE.md)。

本技能版本为 `1.0.2`。能力事实与接入方式以链接的同版能力包正文为准；共同研发规则以基础编码规范正文为准。能力包编号只定位接入要点，不作为项目必须选用该能力的依据。

## 任务选择

先在[能力包入口](references/standards/05-能力包/01-通用工具类/03-基础通用支撑能力包/01-总入口.md)和[能力地图](references/standards/05-能力包/01-通用工具类/03-基础通用支撑能力包/02-能力清单与边界.md)确认任务确需本包，再在[研发任务导航](references/研发任务导航.md)中检索能力名称或编号，只读取命中的接入要点和示例。不要全文加载导航或能力包正文。数据库建模、Mapper、Service 分层及事务的共同要求以基础编码规范为准；选用 AURA 数据访问等入口时，再用 `aura-cap-common-business-use` 查接入组合。本技能只补充命中的公共能力用法。
## 任务路由与执行指南

先确认任务命中基础通用支撑能力，再读取[任务路由与执行指南](references/任务路由.md)中的对应接入要点、检查清单和示例。只打开命中的能力文档；数据库建模、Mapper、Service 分层及事务要求回到基础编码规范，公共包内部实现不在本技能范围。

## 执行边界

项目版本、能力入口、关键配置或失败行为无法从规范和项目确定时，列出缺口并停止推断。本技能不制定新规范、不决定能力发布状态，也不读取内部治理资料。
