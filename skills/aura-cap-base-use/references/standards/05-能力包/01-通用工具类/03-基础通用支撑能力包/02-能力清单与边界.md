# 基础通用支撑能力包能力地图

本文件先回答“框架提供什么能力”，再说明使用边界；开发者可按命中的能力继续阅读使用规则和示例。

具体工具入口见[通用工具目录](./06-通用工具目录.md)。本文件负责能力地图，工具目录负责按业务问题查找细分工具。

## 1. 能力编号与总览

| 编号 | 能力 | 适用边界 |
| --- | --- | --- |
| 01 | 统一响应与 JSON | 所有 HTTP 接口结果处理、非 HTTP 边界的显式 JSON 转换；公开字段由 DTO 控制 |
| 02 | 当前用户、权限与内部调用 | 从认证上下文获取操作人，声明权限，限定可信内部入口 |
| 03 | 租户上下文与基础实体 | 核对身份与租户归属，复用公共实体字段，并在实际读写中落实数据边界 |
| 04 | Redis 缓存 | 按业务域和必要的租户范围读写缓存、设置有效期与失效策略 |
| 05 | 操作日志与数据审计 | 分别记录业务操作和关键数据变更；重复提交另需已验证的服务端处理 |
| 06 | 服务间调用 | 通过 API 模块和 Feign 复用内部调用契约 |
| 07 | 接口描述 | 按接口可见范围说明请求、响应和字段，不泄露内部对象 |
| 08 | 高频通用工具 | 按业务问题选用 Web、参数、消息、树形和数据范围等工具 |
| 09 | 文件存储 | 通过 `FileTemplate` 使用本地或 S3 兼容对象存储；业务自行负责权限、租户、元数据和生命周期 |

### 能力分类

| 能力分类 | 框架提供的能力 | 主要解决的问题 | 典型使用者 |
| --- | --- | --- | --- |
| 基础编码能力 | 统一 HTTP 响应、结果处理、JSON、公共常量 | 接口返回不一致、JSON 规则分散 | 所有后端业务开发者 |
| 身份与权限能力 | 当前用户、安全上下文、权限声明、内部调用边界 | 认证、授权和当前人获取不统一 | Controller、Service 开发者 |
| 数据基础能力 | 基础实体、租户上下文、数据边界 | 审计字段重复、租户数据串用 | 数据和业务模块开发者 |
| 缓存能力 | Redis 统一读写、过期、锁和扫描 | 缓存接入方式不一致、key 冲突 | 需要缓存或并发控制的业务 |
| 记录与可靠性能力 | 操作日志、数据审计；幂等注解需核实运行时拦截 | 无法追溯操作、重复提交、修改无痕 | 写操作和敏感业务开发者 |
| 服务调用能力 | Feign 客户端、统一响应、调用上下文 | 服务间调用契约和认证不一致 | 微服务 API 开发者 |
| 接口描述能力 | OpenAPI 启用、接口和模型描述 | 前后端联调缺少统一契约 | API 和联调开发者 |
| 文件存储能力 | `aura-common-oss`、`FileTemplate` | 统一访问本地或对象存储，避免业务绑定厂商客户端 | 需要上传、读取、删除或签名访问文件的业务 |

## 2. 能力入口速查

| 能力 | 主要入口 | 何时使用 | 不应做什么 |
| --- | --- | --- | --- |
| 统一响应 | `R<T>`、`RetOps<T>` | 所有 HTTP Controller 返回、远程结果处理；公开字段由 DTO 控制 | 自定义第二套响应外壳或直接暴露内部实体 |
| JSON | `JsonUtils` | 特殊对象转换、树模型处理 | 业务中反复创建 `ObjectMapper` |
| 当前用户 | `SecurityUtils` | 获取当前用户、角色、会话 | 信任请求体中的用户 ID |
| 权限 | `@HasPermission` | 保护新增、修改、删除等业务操作 | 只依赖前端按钮隐藏 |
| 内部调用 | `@Inner` 及对应可信配置 | 明确的服务内部入口 | 对外接口整体跳过认证 |
| 租户 | `TenantContextHolder`、租户边界过滤器 | 请求、任务和远程调用的数据隔离 | 把上下文非空当成用户已获租户授权 |
| 基础实体 | `BaseEntity` | 复用 id、创建/修改人、时间和逻辑删除字段 | 每个实体重复定义公共字段 |
| 缓存 | `RedisUtils` | 业务缓存、过期、锁和安全扫描 | 直接使用无业务域的全局 key |
| 操作日志 | `@SysLog` | 记录用户执行了什么操作 | 记录 token、密钥和完整敏感报文 |
| 数据审计 | `@Audit` | 记录关键数据修改前后差异 | 用普通日志替代数据审计 |
| 幂等 | `@Idempotent`（须先核实项目实际拦截） | 防止重复提交 | 仅凭注解存在就认定重复请求已被阻断 |
| 服务调用 | Feign API 接口 | 跨服务调用和契约复用 | 在业务代码拼接内部 URL |
| 接口描述 | `@EnableOpenApi`、`@Operation`、`@Schema` | 按接口可见范围提供文档和联调描述 | 暴露内部实体和敏感字段 |

## 3. 能力组合建议

| 业务类型 | 推荐组合 |
| --- | --- |
| 普通只读查询 | 统一响应 + 权限 + 接口描述 |
| 带租户的数据查询 | 统一响应 + 权限 + 租户上下文 |
| 新增或修改数据 | 统一响应 + 权限 + 当前用户 + 日志 + 审计 |
| 可重复提交的写操作 | 上述能力 + 经项目验证的服务端幂等实现 |
| 热点详情查询 | 统一响应 + 租户上下文 + 缓存 |
| 跨服务查询 | API 契约 + Feign + 统一响应 + 调用上下文 |
| 对外接口 | 统一 `R<T>` + DTO + 公开认证契约 + OpenAPI 描述 |

## 4. 能力使用顺序

```text
先查能力地图
→ 根据业务问题命中能力
→ 读取该能力的使用规则
→ 参考对应正例和综合示例
→ 再开始业务编码
```

能力地图用于选择能力，后续章节用于约束正确使用方式；两者不能倒置。

## 5. 能力与依赖对应

| 模块 | 主要入口 | 本包承载内容 |
| --- | --- | --- |
| `aura-common-core` | `R`、`RetOps`、`JsonUtils`、公共常量 | 返回体、JSON、结果处理 |
| `aura-common-security` | `SecurityUtils`、`AuthUtils`、`@HasPermission`、`@Inner` | 当前用户、认证信息、权限和内部调用边界 |
| `aura-common-data` | `RedisUtils`、`TenantContextHolder`、`BaseEntity` | 缓存基础、租户上下文、通用实体 |
| `aura-common-log` | `@SysLog`、`SysLogUtils` | 操作日志使用 |
| `aura-common-audit` | `@Audit` | 数据变更审计使用 |
| `aura-common-idempotent` | `@Idempotent` | 仅列为待验证入口，不能直接作为已生效的写接口幂等方案 |
| `aura-common-feign` | Feign 公共配置和调用约束 | API 模块的服务间调用基础 |
| `aura-common-swagger` | OpenAPI 公共配置 | 接口文档启用与描述基础 |

## 6. 其他能力的入口

以下能力按对应能力包阅读：

- 下载任务、Excel、SSE 和 WebSocket；文件存储公共入口见[文件存储能力说明](./08-文件存储能力说明.md)；
- SSE、WebSocket、消息和任务；
- 动态数据源、分布式事务、限流、灰度和网关；
- 加密 API、敏感字段、XSS；
- 向量、检索、图数据库和其他 AI/数据专项能力。

## 7. 与基础编码规范的关系

- 基础编码规范规定统一原则、分层、接口、安全、数据和交付要求；
- 本能力包规定如何调用已经提供的公共 API；
- 若本能力包与基础编码规范冲突，以基础编码规范为准；
- 本能力包不重复定义基础编码规范中的通用规则。
