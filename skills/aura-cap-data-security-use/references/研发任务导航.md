# 数据安全与内容防护研发任务导航

本表只负责选读；依赖、正反例和完成判断以[能力详细说明](standards/05-能力包/01-通用工具类/06-数据安全与内容防护能力包/能力详细说明.md)为准。

| 研发任务 | 选读章节 | 重点核对 |
| --- | --- | --- |
| VO 展示或日志、审计、导出脱敏 | 第 1、6 节 | 显式工具与 `@Sensitive` 的权限差异、豁免标识、各输出渠道 |
| 清理用户输入或富文本 | 第 2、6 节 | 启用值、缺省配置下的裁剪、路径、白名单、实际渲染结果 |
| 实体字段加密与完整性 | 第 3、6 节 | `CipherProvider`、装配开关、实体字段、写入/读取/篡改行为 |
| 前后端报文加解密 | 第 4、6 节 | 显式启用、协议、POST/单值 GET/响应、例外与错误密文 |

多能力组合按第 5 节判断，但不因组合场景默认加载四个模块。
