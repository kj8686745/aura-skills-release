# 验证清单

## 依赖验证

- [ ] `package.json` 中存在 `@fxft/ui-plus`，或已说明缺失并取得用户授权后安装。
- [ ] 未授权时没有执行安装命令。
- [ ] 包管理器与目标项目一致。

## Resolver 验证

- [ ] `vite.config.ts` 中存在 `FxftUiPlusResolver`，或目标项目已采用全量注册。
- [ ] `Components` resolver 未覆盖已有配置。
- [ ] `AutoImport` resolver 未覆盖已有配置。

## 代码验证

- [ ] 页面使用 `FxftMap`。
- [ ] 没有引入其它地图 SDK。
- [ ] TypeScript 类型检查通过，或已如实记录失败原因。
- [ ] 构建通过，或已如实记录失败原因。

## 浏览器验证

按实际业务验证：

- [ ] 地图能正常加载。
- [ ] 底图切换可用。
- [ ] 地图工具栏可用。
- [ ] 点位能渲染。
- [ ] 点位点击能触发。
- [ ] 聚合效果符合预期。
- [ ] `maxClusterRadius` 按像素语义验收，没有误当固定公里数。
- [ ] 缩放、拖动、旋转过程中聚合点始终锚定地图坐标，不贴屏幕、不漂移。
- [ ] 设备/报警等分类按钮只切换 marker 显隐或图标，不请求、不清空、不重建聚合图层。
- [ ] 隐藏 marker 不参与聚合数量；所有分类关闭时数量为 0，恢复后数量不翻倍。
- [ ] 树勾选、取消、筛选和刷新只增删或更新变化点，没有残留点与重复计数。
- [ ] 轨迹能创建、播放、暂停、停止。
- [ ] 轨迹进度事件正常。
- [ ] 热力图能渲染并清理。
- [ ] 绘制结束事件能返回结果。
- [ ] GeoJSON 能渲染并定位。
- [ ] 外部状态切换后，下一次交互绘制的点、线、面样式正确。
- [ ] 外部状态切换后，已有可编辑 GeoJSON 的样式能正确刷新。
- [ ] 已按实际业务覆盖使用到的图形类型（点、线、圆、矩形、多边形）。
- [ ] 控制台无新增错误。

## 交付回复

交付时必须包含：

1. 完成内容。
2. 使用的技能资料。
3. 依赖检查结果。
4. 组件接入方式。
5. 地图实现说明。
6. 数据适配说明。
7. 验证结果。
8. 剩余风险。
