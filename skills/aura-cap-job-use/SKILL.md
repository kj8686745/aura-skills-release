# 任务与调度能力使用

询问如何调用本技能时，阅读[使用说明](USAGE.md)。

本技能版本为 `1.0.2`。先读[任务能力包入口](references/standards/05-能力包/01-通用工具类/08-任务与调度能力包/总入口.md)和[能力清单](references/standards/05-能力包/01-通用工具类/08-任务与调度能力包/能力清单与边界.md)确认任务边界，再在[研发任务导航](references/研发任务导航.md)中检索调度、任务或能力编号，选读详细说明。同版公开规范和当前项目实际依赖是能力事实源，不全文加载导航或能力正文，不能只凭本技能推断项目已启用调度。

## 任务路由与执行指南

确认任务命中本能力包后，先在[任务路由与执行指南](references/任务路由.md)中检索能力名称或编号，再读取对应能力条目、前置条件和验证要求。只打开当前任务需要的说明，不整包加载路由或能力正文。

## 边界

项目版本、能力入口、关键配置或运行结果无法从规范和项目确定时，列出缺口并停止推断。本技能不修改公共模块内部实现，不把未验证的能力写成已启用。
