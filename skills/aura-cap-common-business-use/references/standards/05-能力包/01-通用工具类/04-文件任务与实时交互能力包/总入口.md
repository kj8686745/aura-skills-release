# 文件任务与实时交互能力包

**能力包编号**：AURA-CAP-COMMON-FILE-RT  
**版本**：0.1.0-draft  
**所属能力域**：通用工具类  
**状态**：建设中  
**源码依据**：既有能力为 `aura-core-common` `dev@4a2a1f1`；Socket.IO 入口已对照 `aura-core-common` `dev@0f94cdc` 中的 `aura-common-socketio:1.0.5-RELEASE`；业务项目仍须核对实际依赖版本和运行结果

## 1. 能力定位

本能力包说明业务应用如何使用 Excel 导入导出、SSE、原生 WebSocket 和 Socket.IO，以及这些能力如何与文件存储组合。`aura-common-oss` 的公共依赖、配置、API、对象键和权限边界统一见[基础通用支撑能力包的文件存储说明](../03-基础通用支撑能力包/08-文件存储能力说明.md)，本包不再复制一套文件存储契约。下载任务模块当前只有实现线索，没有可直接照用的完整接入契约；不能因存在 `@ExportMonitor` 就把它当作已开放的下载中心。按周期触发的后台任务和统一调度由[任务与调度能力包](../08-任务与调度能力包/总入口.md)负责。

## 2. 能力范围

| 能力 | 当前公共模块 | 适用场景 |
| --- | --- | --- |
| 文件存储 | `aura-common-oss` | 本地文件或对象存储的统一访问 |
| Excel 导入导出 | `aura-common-excel` | 表格导入、导出、校验和多 Sheet 输出 |
| SSE | `aura-common-sse` | 单向进度、通知和流式消息推送 |
| WebSocket | `aura-common-websocket` | 双向实时通信、会话和消息处理 |
| Socket.IO | `aura-common-socketio` | Socket.IO 协议认证连接和当前实例按租户广播；源码入口已核对，项目运行待验 |

`aura-common-download` 的当前状态及未满足的接入条件见[能力清单](./能力清单与边界.md#1-当前不作为可直接接入能力的下载任务模块)。

## 3. 选择方式

```text
文件长期保存 → 文件存储
需要表格导出 → Excel；按结果规模选择项目实际具备的交付方式
需要下载中心或异步文件任务 → 本包当前无可照用的完整入口，先核对项目已有实现
表格数据导入/导出 → Excel
按时间自动执行 → 任务与调度能力包
服务端单向推送进度 → SSE
需要双向会话通信 → WebSocket
客户端使用 Socket.IO 协议、需要按租户广播 → Socket.IO；不能用原生 WebSocket 客户端直接替代
```

## 4. 使用顺序

```text
判断交互类型和数据规模
→ 选择已列明的文件、Excel 或实时能力
→ 明确权限、租户、文件生命周期和失败处理
→ 阅读对应能力详细说明
→ 参考示例完成业务接入
```

## 5. 重要边界

- 文件能力不替代业务文件权限和租户校验；
- 大文件导出的规模与资源边界按基础规范处理；本包目前不提供可直接复用的下载任务闭环；
- SSE、WebSocket 和 Socket.IO 的连接、重连、超时和消息顺序必须在业务设计中明确；Socket.IO 的本地广播不等于跨实例投递或客户端确认；
- 导出和实时推送不得把认证凭据放入 URL、文件名或消息内容；
- 本能力包不承载具体物联或视频领域的文件、任务和推送业务规则。
