# 基础通用支撑能力包工具目录

本目录按业务问题列出 AURA 公共工程中的工具与支撑组件。表中“业务入口”可由业务代码按场景调用；“扩展入口”适用于接入层或框架扩展；“内部组件”用于识别现有能力，不作为业务调用 API。

## 1. 核心结果与对象工具

| 工具 | 模块 | 用途 | 入口级别与边界 |
| --- | --- | --- | --- |
| `R<T>` | `aura-common-core` | 统一接口成功、失败和数据返回 | Controller 和服务契约使用，不自行定义同类包装 |
| `RetOps<T>` | `aura-common-core` | 判断远程结果、读取 data、转换结果 | 远程调用结果处理，不替代业务异常设计 |
| `JsonUtils` | `aura-common-core` | JSON 字符串、字节、集合和树模型转换 | 特殊边界转换使用，普通 HTTP 转换交给统一配置 |
| `ParamUtil` | `aura-common-core` | 参数和请求值的基础处理 | 只做通用格式处理，业务校验放 Service |
| `MsgUtils` | `aura-common-core` | 统一消息和国际化文本读取 | 错误信息和提示使用统一消息来源 |
| `ValidGroup` | `aura-common-core` | 参数校验分组 | DTO 校验分组，不在 Service 重复模拟校验框架 |
| `ClassUtils` | `aura-common-core` | 类型和类信息判断 | 扩展入口；业务代码避免反射式编排 |
| `SpringContextHolder` | `aura-common-core` | 特殊边界获取 Spring Bean | 扩展入口；不能替代构造器注入 |
| `CommonConstants`、`SecurityConstants` | `aura-common-core` | 通用结果和安全常量 | 业务入口；复用现有公共值，不自行复制 |
| `PaginationConstants`、`CacheConstants`、`ServiceNameConstants` | `aura-common-core` | 分页、缓存和服务名常量 | 业务入口；按常量所属用途使用 |
| `ErrorCodes`、`CustomException`、`CheckedException` | `aura-common-core` | 错误语义和异常类型 | 业务入口；遵守接口错误契约 |

| `JsonLongArrayTypeHandler` | `aura-common-data` | JSON Long 数组字段映射 | 只用于已定义 JSON 字段，不作为任意字段转换器 |

## 8. 工具使用总规则

1. 先从本目录按业务问题选择工具，再读取所属能力包规范；
2. 业务代码优先使用公共工具，不复制同类工具或自行封装同名能力；
3. 自动配置、过滤器、拦截器、序列化器和 Holder 不等于业务直接调用 API；
4. 工具调用必须保留权限、租户、事务、异常和资源生命周期边界；
5. 工具目录列出入口不代表所有入口都可对外使用，具体公开入口以对应能力包版本为准。
