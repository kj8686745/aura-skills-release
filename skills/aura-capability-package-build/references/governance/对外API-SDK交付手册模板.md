本手册必须按“接入目标总述 → 模块与接口分述 → 完整调用结果总结”的总—分—总结构编写。首次调用必须能独立完成一次可观察任务；模块接口只定义一次字段和方法，跨接口流程引用模块章节；结尾必须说明完成判断、失败恢复和升级入口。不得把源码盘点、候选状态或内部发布过程写入调用方手册。
