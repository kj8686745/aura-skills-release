# PIGX 模块联邦检查使用说明

## 适用与调用

用于已识别 PIGX 综合端的模块联邦审计、评审、验收、改前基线和改后复检。默认只读，可显式调用：`$aura-pigx-module-federation-check 检查当前项目模块联邦。`

生产端、消费端和证据不足的项目只报告项目类型及证据，不给出综合端通过结论。模块联邦代码实现由 `aura-pigx-web-develop` 主导。

## 需要提供的信息

- 项目路径；
- 是否仅审计、是否作为改前基线或改后复检；
- 需要核验远程菜单时的真实 `componentPath`；
- 指定消费方接入时的消费方项目路径与接入目标。

## 示例提示词

- `检查当前 PIGX 综合端模块联邦配置，只做审计并输出问题。`
- `为新增 aura-order-web 远程配置做改前基线检查。`
- `模块联邦改完后复检，并输出提供方的对外接入说明。`
- `把当前提供方接入 E:\\code\\frontEnd\\company\\consumer，动态菜单只走运行时入口。`

## 边界

未明确要求修复时不改代码；未确认 manifest 部署地址时只输出待填环境变量，不猜测地址或发布路径。
