# AURA 工程与架构开发

询问如何调用本技能时，阅读[使用说明](USAGE.md)。

本技能版本为 `1.0.6`，按随包快照适配 `0.1.0-draft` 基础编码规范。规则、正反例和交付要求以链接的规范正文为准；按任务读取，不批量加载全部规范。

随包规范来源完整登记在 [source.json](references/source.json)。共享工程规范中的前端目录以现行框架模板为准；本技能不携带前端页面实现专项正文，需要页面、模块联邦等实现时使用对应前端技能，不从总览导航推断具体实现要求。

跨模块任务先在[AI任务触发索引](references/AI任务触发索引.md)按关键词选模块，再按规则编号或主题词定位正文；人工审阅需要完整矩阵时再打开[规范矩阵](references/standards/01-基础编码规范/规范矩阵.md)。只读取命中的规则与示例，不整篇加载规范矩阵或全部规范。

仅初始化一个尚未接入 SDK、HTTP 或数据库的隔离工程时，先在下表对应文档中搜索规则标题，再读取命中条款至下一条规则标题，包含正反例与必要上下文；不要用大范围文件头部截取代替规则定位。优先核对 `AURA-BASE-STRUCT-001/002/003/004`，配置、依赖和构建只读实际引入部分。只有实际涉及分层依赖、接口、异步、运行资源或交付变更时，才继续加载对应规范；单纯运行本地验证不要求预读整份自测或交付规范。

## 详细任务路由

先判断当前任务是否命中本技能；在[任务路由与执行指南](references/任务路由.md)中检索匹配关键词或任务行，再只打开命中的规则、正反例和必要上下文。不要把路由文件全文加载到上下文，也不整篇加载规范、模板或示例。

## 执行边界

先从需求确定实际涉及的工程、接口、数据、权限、事务、异步或交付环节，再按命中的规则实现并记录真实证据。框架公共能力的具体接入方式交给对应能力包技能；规范版本或项目事实无法确定时，列出缺口并停止推断。
