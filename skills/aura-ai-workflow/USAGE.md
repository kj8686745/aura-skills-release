# AI 研发协作技能使用说明

需要建立项目 AI 工作入口、续接会话、控制上下文或复核 AI 产物采纳边界时，说明目标项目和本次任务；也可显式调用 `$aura-ai-workflow`。

示例：`$aura-ai-workflow 根据当前项目文件与 Git 状态建立下一会话可续接的工作入口，不改业务代码。`

普通编码任务由命中的研发技能承担；建立入口时不因项目采用某个能力包就加载其全部资料。

也可以说：“根据现有任务记录和当前 diff 续接，不重读全部历史、不改业务代码。”或“刚才引用了旧契约，请先核对当前接口文档，纠正后继续同一任务。”无需填写固定任务表；一次小任务不要求创建 AGENTS.md、docs 或状态文件。

## 辅助核对

需要采集入口与工作区事实时，在技能目录使用 Python 3.9+ 执行：

```text
python -B -X utf8 scripts/inspect-ai-context.py --project <项目根> --json
python -B -X utf8 scripts/inspect-ai-context.py --project <项目根> --entry AGENTS.md --state docs/任务记录.md --baseline <原提交> --json
```

`--entry` 默认根目录 AGENTS.md；`--state` 只在已有且相关时传入，路径必须在指定项目内。`--baseline` 为已有记录中的精确提交或引用，脚本解析并比较当前 HEAD；不传就不猜基线。它只读入口及其本地 Markdown/行内 Markdown 文件引用，状态文件只计算摘要，不输出全文；Git 仅取 HEAD、分支及变更路径，不读取历史聊天、文件 diff 或配置值，不执行入口中的命令。

退出0表示支持范围内采集完成；1为输入/路径错误；2为显式文件缺失、基线无法核对/已变化，或链接缺失/超出项目范围等待核实项。无 Git 或默认根入口缺失只报告事实，不自动阻止工作。远端链接、章节锚点、动态路径及规则是否正确仍需人工核对。大结果仅筛选所需的 `files`、`git`、`issues`，不反复读全部输出。

工具不能判断历史结论仍有效、任务是否完成或 AI 上下文是否失真。没有实际 token usage 时不提供精确消耗、费用或固定切换阈值。技能版本见 VERSION，试用资格不代表已通过真实项目验收。
