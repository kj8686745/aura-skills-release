# AI 研发协作运用

本技能处理研发协作方式，适用于所有研发项目，不以使用 AURA 为前提。具体编码、技术设计、项目审查和能力接入交给对应任务；不自动启动其他技能。版本见 `VERSION`；仅追溯时检索[来源记录](references/source.json)。

## 任务选路

| 当前任务 | 直接选读与产物 |
| --- | --- |
| 初始化或补齐长期项目入口 | [初始化规范](references/standards/02-AI开发运用规范/02-AI工作入口初始化规范.md) INIT-001～007；优先补现有入口，只有确需持续复用才新建，不为一次小任务建空目录 |
| 续接或阶段收束 | [会话规范](references/standards/02-AI开发运用规范/03-AI会话运用机制规范.md) SESSION-002/004/006/007；核对目标文件、当前差异和验证，只有现有产物不能表达未完成状态时才补简短记录 |
| 上下文过载或结论漂移 | [上下文规范](references/standards/02-AI开发运用规范/04-AI上下文管理通用规范.md) CTX-GEN-003～008；停止无关扩展，核对最新目标与直接证据，纠正后继续，不能稳定恢复再切换会话 |
| AI 输出采纳、人工确认或具体研发协作 | 从[任务导航](references/任务导航.md)选命中一项；不把本技能变成全项目审查入口 |

不串行预读目录说明、矩阵、导航和全部规范。只读本次规则、正反例和必要项目证据；模板提示语不是要求使用者填写的表单。

## 执行

先核对当前任务、已加载或可定位的项目入口和目标事实，不每轮重复读取相同指令。历史状态只是定位线索：与文件、diff 或验证冲突时标明已失效结论；无状态文件、无 Git 或工具未提供 token 数均不妨碍继续可确认的工作。

初始化只写稳定导航：事实来源、任务选路、授权边界和真实验证入口；不复制完整规范，不把瞬时进度写入长期规则。收束优先更新结论本来的归属（接口文档、设计或现有任务记录），不另建重复“会话总结”。确需交接时只带当前目标、有效决定、目标文件、已完成及证据、未完成和下一步，不搬运全量聊天。

普通已授权修改和相称验证连续执行，不因文件是依赖、接口或迁移就重复确认。只读任务不实施修复；超出授权、关键事实/业务选择缺失、真实发布或难以恢复操作时，仅暂停受影响动作并提出具体缺口，其余独立工作继续。不要自行设定固定 token/轮数阈值；无实际 usage 数据时不估报精确费用。

## 只读辅助与交付

需要核对项目入口、续接文件或 Git 基线时，在技能目录执行（Python 3.9+ 标准库）：

```text
python -B -X utf8 scripts/inspect-ai-context.py --project <项目根> --json
# 仅在本次确有续接文件/已知基线时追加 --state docs/任务记录.md --baseline <提交>
```

脚本只返回选定文件摘要、Git 状态路径和入口的本地引用检查，不读取全部源码、历史或配置内容，不替你写交接记录。没有 Git 或根入口是事实，不自动判成阻断。退出0表示支持的静态采集完成，1为输入错误，2为指定资料缺失、基线变化或引用待核实；详见[使用说明](USAGE.md)。不必全文加载脚本。

交付实际改动或收束结果、关键依据、已运行验证和重要未完成项；简单问答不强制输出空栏目。不能用入口存在、文件较新或脚本通过证明任务已经完成。具体能力只在当前任务命中时由研发入口按公开索引选读，不因项目曾使用它而加载全部能力。

## 边界

不读取内部成本、技能构建或评分材料。会话切换、上下文收束、源码修改、Git 提交与发布分别看当前请求；本技能不自动创建新聊天、不安装技能，也不将“继续”理解为扩大授权。
