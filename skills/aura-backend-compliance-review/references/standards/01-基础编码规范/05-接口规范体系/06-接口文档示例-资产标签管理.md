# 接口文档示例：资产标签管理

> 本文是资产标签业务的接口契约编写示例，展示一个模块如何在同一份文档中维护多组相关接口。路径、错误码、数量限制和版本均为示例约定，不代表某个现行项目已经提供这些接口；实际项目应以其已实现、已联调的契约为准。

## 二、职责与调用边界

- 提供方负责：资产标签的租户隔离、权限校验、字段校验、重复名称校验、批量边界和标签关系事务处理。
- 调用方负责：参数组装、领域 API 封装、加载/空/失败状态、成功后的列表刷新和用户确认。
- 调用方不得依赖：数据库表、内部 Java 类、内部缓存、内部消息主题或服务内部地址。

## 三、统一请求上下文

```http
Authorization: Bearer <token>
TENANT-ID: <tenant-id>
Content-Type: application/json
请求标识: <按项目登记的请求标识传递方式>
```

- 租户从 AURA 请求上下文获取，不接受请求体中的 `tenantId` 覆盖。
- 权限由服务端执行，调用方不能用页面按钮或路由权限替代接口授权。
- 所有 HTTP 接口统一使用 `R<T>`，框架只读兼容字段 `ok` 不替代 `code` 和业务错误码；调用边界只改变认证方式和可公开字段。

## 接口逐项契约

以下明细仍属于同一份模块接口文档。每个接口都可以按编号独立查阅；认证、租户、响应外壳和公共错误响应继承本文件的统一约定，不在每个接口重复定义。真实项目填充时，必须把示例值替换为实际契约，并在实现和联调后更新状态。

### API-ASSET-TAG-001 新增标签

- **请求**：`POST /api/iotbus/asset/tags`，请求体使用 `groupCode`、`name`、`color`、`description`、`sortNum`；`name` 必填且最长 64 字符。
- **成功**：HTTP `200`，`data` 为标签公开模型（`id/groupCode/groupName/name/tagName/color/description/sortNum`）。
- **失败**：参数错误使用 `400/ASSET_TAG_INVALID_PARAM`；无权限使用 `403/ASSET_TAG_FORBIDDEN`；同租户名称重复使用 `409/ASSET_TAG_CONFLICT`；失败响应沿用第五节错误外壳。
- **调用方处理**：成功后使用返回标签更新或刷新标签列表；失败时按错误码提示，不自行重试冲突请求。

### API-ASSET-TAG-002 编辑标签

- **请求**：`PUT /api/iotbus/asset/tags/{id}`，路径 `id` 必填；请求体为完整标签编辑模型，字段规则与新增一致，未提供的可选字段按 `null` 或登记的默认值处理。
- **成功**：HTTP `200`，`data` 为更新后的标签公开模型。
- **失败**：`400/ASSET_TAG_INVALID_PARAM`、`403/ASSET_TAG_FORBIDDEN`、`404/ASSET_TAG_NOT_FOUND`、`409/ASSET_TAG_CONFLICT`。
- **并发**：本设计示例未给出版本字段或其他冲突条件，不能直接作为允许并发编辑的完整契约使用；实际项目须先确定条件更新或冲突拒绝方式，不得默默覆盖并发修改。

### API-ASSET-TAG-003 删除标签

- **请求**：`DELETE /api/iotbus/asset/tags/{id}`，不使用请求体。
- **成功**：HTTP `200`，`data=null`；同时清理标签关系，调用方不再额外调用关系清理接口。
- **失败**：`403/ASSET_TAG_FORBIDDEN`、`404/ASSET_TAG_NOT_FOUND`、`409/ASSET_TAG_CONFLICT`；删除中的并发冲突不得按成功处理。
- **调用方处理**：成功后刷新标签列表和当前资产列表；超时不得无条件重复删除。

### API-ASSET-TAG-004 查询标签分组

- **请求**：`GET /api/iotbus/asset/tags/groups`，无请求体和查询参数。
- **成功**：HTTP `200`，`data` 为分组数组，每项包含 `groupCode`、`groupName`、`sortNum`、`tagCount`；无分组时返回 `[]`。
- **失败**：认证、权限和服务故障分别使用第五节登记的统一错误码；调用方不得把错误当作空数组。

### API-ASSET-TAG-005 按分组查询标签

- **请求**：`GET /api/iotbus/asset/tags/list-group`，无请求体和查询参数。
- **成功**：HTTP `200`，`data` 为 `Record<string, AssetTag[]>`；对象键是分组名称，未分组归入“未分组”；无标签时返回 `{}`。
- **失败**：权限或服务故障按统一错误响应处理，不返回 `null` 代替集合。

### API-ASSET-TAG-006 查询全部标签

- **请求**：`GET /api/iotbus/asset/tags/list`，无请求体和查询参数；该接口只用于标签选择器和筛选下拉框。
- **成功**：HTTP `200`，`data` 为 `AssetTag[]`，无标签时返回 `[]`；该接口不分页，数据规模超过登记上限时应另行设计分页或选择器查询接口。
- **失败**：`403/ASSET_TAG_FORBIDDEN` 或依赖失败使用统一错误响应；前端保留加载失败状态，不显示为空数据。

### API-ASSET-TAG-007 批量设置标签

- **请求**：`POST /api/iotbus/asset/assets/tags/batch-set`，请求体为 `assetIds`（1～1000 个）、`tagIds`（最多 100 个）和 `mode`（`REPLACE`/`APPEND`）。
- **成功**：HTTP `200`，`data=null`；`REPLACE + tagIds=[]` 清空标签，`APPEND` 对已存在关系按幂等成功处理。
- **失败**：数量或枚举错误使用 `400/ASSET_TAG_INVALID_PARAM`；无权资产使用 `403/ASSET_TAG_FORBIDDEN`；资源或关系冲突使用 `404/ASSET_TAG_NOT_FOUND` 或 `409/ASSET_TAG_CONFLICT`。
- **调用方处理**：成功后重新请求资产分页；失败时不得根据部分本地状态推断服务端已完成全部更新。

### API-ASSET-TAG-008 批量移除标签

- **请求**：`POST /api/iotbus/asset/assets/tags/batch-remove`，请求体为 `assetIds`（1～5000 个）和单个 `tagId`。
- **成功**：HTTP `200`，`data=null`；不存在的关系按幂等成功处理。
- **失败**：参数、权限、资源不存在和依赖失败分别使用统一错误表；部分资产无权时必须按实际事务语义返回，不得由调用方猜测。
- **调用方处理**：成功后刷新受影响的资产列表或详情，不重复调用删除接口。

### API-ASSET-TAG-009 资产分页及标签过滤

- **请求**：`GET /api/iotbus/asset/assets`，查询字段、页码、页大小、排序、数据范围和越界结果见“九、资产分页和详情”。多个 `tagIds` 使用重复 Query 参数。
- **成功**：HTTP `200`，`data` 为 `PageResult<AssetResponse>`，字段为 `records/total/size/current/pages`；`records` 只包含公开资产模型。
- **失败**：`pageNum<1`、`pageSize` 不在 1～100 返回 `400/ASSET_TAG_INVALID_PARAM`；无权查询返回 `403/ASSET_TAG_FORBIDDEN`；依赖故障返回 `500/ASSET_TAG_SERVICE_FAILED`。
- **调用方处理**：第一页、最后一页和空页均按分页结构处理；超限是参数错误，不当作空页，也不自动截断。

### API-ASSET-TAG-010 资产详情（含标签）

- **请求**：`GET /api/iotbus/asset/assets/{id}`，路径 `id` 必填，无请求体。
- **成功**：HTTP `200`，`data` 为资产公开模型，`tags` 使用与分页记录相同的标签结构；没有标签返回 `[]`。
- **失败**：`403/ASSET_TAG_FORBIDDEN`、`404/ASSET_TAG_NOT_FOUND`、`500/ASSET_TAG_SERVICE_FAILED`。
- **调用方处理**：详情不存在时显示资源不可用并刷新列表，不使用缓存对象冒充成功结果。

### API-ASSET-TAG-011 删除资产并清理标签关系

- **请求**：`DELETE /api/iotbus/asset/assets/{id}`，不使用请求体。
- **成功**：HTTP `200`，`data=null`；资产删除和标签关系清理在同一事务语义下完成。
- **失败**：`403/ASSET_TAG_FORBIDDEN`、`404/ASSET_TAG_NOT_FOUND`、`409/ASSET_TAG_CONFLICT` 或 `500/ASSET_TAG_SERVICE_FAILED`；事务失败不得返回成功。
- **调用方处理**：成功后刷新资产分页和相关标签视图；超时先查询资产状态，不能仅因用户再次确认就重复删除。实际接口只有明确约定并验证删除幂等或前次未执行时，才允许重试。

## 五、公共响应和错误

统一成功响应使用：

```json
{
  "code": 200,
  "msg": "success",
  "data": {},
  "ok": true
}
```

`ok` 是框架序列化出的只读兼容字段，调用方必须使用 `code` 和业务错误码判断结果。

统一错误响应：

```json
{
  "code": 409,
  "msg": "资产标签状态已发生变化，请刷新后重试",
  "data": {
    "errorCode": "ASSET_TAG_CONFLICT",
    "requestId": "req-20260920-001",
    "retryable": false
  },
  "ok": false
}
```

| HTTP 状态 | 业务错误码 | 使用场景 | 可重试 | 调用方处理 |
| --- | --- | --- | --- | --- |
| 400 | `ASSET_TAG_INVALID_PARAM` | 字段格式、枚举或批量数量不合法 | 否 | 定位字段并提示修改 |
| 401 | `UNAUTHORIZED` | 未认证或令牌失效 | 否 | 重新认证 |
| 403 | `ASSET_TAG_FORBIDDEN` | 无资产标签操作权限或数据范围不足 | 否 | 提示无权限 |
| 404 | `ASSET_TAG_NOT_FOUND` | 标签或资产不存在 | 否 | 刷新列表或详情 |
| 409 | `ASSET_TAG_CONFLICT` | 名称重复、状态冲突或并发版本冲突 | 否 | 刷新后重新操作 |
| 429 | `ASSET_TAG_RATE_LIMITED` | 超出调用频率或批量配额 | 条件性 | 只读请求可按 `Retry-After` 延迟重试；写请求须先确认前次未执行或已有同键幂等保证 |
| 500 | `ASSET_TAG_SERVICE_FAILED` | 服务或依赖故障 | 条件性 | 写请求不能仅凭 `500` 判定未生效，先查询结果；仅按已登记的幂等契约重试 |

## 六、标签定义接口

### 6.1 新增和编辑标签

新增使用 `POST /api/iotbus/asset/tags`，编辑使用 `PUT /api/iotbus/asset/tags/{id}`。编辑是完整更新，不是局部更新。

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| `groupCode` | string/null | 否 | 标签分组字典值；空值表示未分组 |
| `name` | string | 是 | 非空，最长 64 字符；同一租户内有效名称不能重复 |
| `color` | string/null | 否 | 最长 16 字符；空白按 `null` 处理 |
| `description` | string/null | 否 | 最长 255 字符；空白按 `null` 处理 |
| `sortNum` | integer | 否 | 大于等于 0，默认 0 |

请求示例：

```json
{
  "groupCode": "asset_status",
  "name": "重点资产",
  "color": "#E34D59",
  "description": "需要重点关注的资产",
  "sortNum": 10
}
```

成功时 `data` 返回标签对象：

```json
{
  "id": "2100000000000000001",
  "groupCode": "asset_status",
  "groupName": "资产状态",
  "name": "重点资产",
  "tagName": "重点资产",
  "color": "#E34D59",
  "description": "需要重点关注的资产",
  "sortNum": 10
}
```

### 6.2 删除标签

`DELETE /api/iotbus/asset/tags/{id}`。删除成功时 `data=null`，同时清理该标签与资产的绑定关系。调用方刷新标签列表和当前资产分页，不重复调用关系清理接口。

## 七、标签查询接口

| 接口 | 返回内容 | 约定 |
| --- | --- | --- |
| `GET /api/iotbus/asset/tags/groups` | 分组数组 | 包含分组编码、名称、排序和标签数量；未分组编码固定为 `-1`，仅用于展示 |
| `GET /api/iotbus/asset/tags/list-group` | `Record<string, AssetTag[]>` | 对象键为分组名称，不是分组编码；未分组固定归入“未分组” |
| `GET /api/iotbus/asset/tags/list` | 标签数组 | 无分页，用于标签选择器和筛选下拉框 |

查询接口无请求体。标签不存在时返回空数组或空对象，不返回 `null` 作为集合结果。

## 八、资产标签关系接口

### 8.1 批量设置标签

`POST /api/iotbus/asset/assets/tags/batch-set`

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| `assetIds` | string[] | 是 | 1 至 1000 个资产 ID |
| `tagIds` | string[] | 是 | 最多 100 个标签 ID；`REPLACE` 可为空数组 |
| `mode` | enum | 是 | `REPLACE` 全量覆盖或 `APPEND` 增量新增 |

`REPLACE + tagIds=[]` 表示清空标签；`APPEND` 对已存在关系按幂等成功处理。成功时 `data=null`，调用方重新请求资产分页。

### 8.2 批量移除标签

`POST /api/iotbus/asset/assets/tags/batch-remove`

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| `assetIds` | string[] | 是 | 1 至 5000 个资产 ID |
| `tagId` | string | 是 | 单个标签 ID |

关系不存在时按幂等成功处理，成功时 `data=null`。

## 九、资产分页和详情

### 9.1 分页查询

`GET /api/iotbus/asset/assets`

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `keyword` | string | 无 | 模糊匹配名称或编号 |
| `assetTypeId` | string | 无 | 资产类型 ID |
| `groupId` | string | 无 | 资产分组 ID；`-1` 表示未分组 |
| `onlineStatus` | string | 无 | `1` 在线、`0` 离线、`2` 未激活 |
| `alarmStatus` | string | 无 | `1` 报警中、`0` 正常 |
| `tagIds` | string[] | 无 | 多个标签按任意一个命中过滤，使用重复 Query 参数 |
| `hasTags` | boolean | 无 | 是否至少存在一个有效标签 |
| `pageNum` | integer | 1 | 页码，最小 1 |
| `pageSize` | integer | 20 | 每页数量，允许 1～100；超出范围返回 `400/ASSET_TAG_INVALID_PARAM`，不自动截断 |

示例请求：`GET /api/iotbus/asset/assets?pageNum=1&pageSize=20&tagIds=2100000000000000001&tagIds=2100000000000000002`。不开放客户端自定义排序；结果按创建时间降序、资产 ID 降序稳定排序。查询范围限定为当前租户及调用方获授权的资产，过滤和排序均在该范围内执行。

分页 `data` 使用统一 `PageResult<AssetResponse>` 字段：`records`、`total`、`size`、`current`、`pages`。`records` 中只放可对调用方公开的资产字段和标签对象，不直接返回数据库实体。成功响应示例：

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "records": [
      {
        "id": "2100000000000000101",
        "name": "一号水泵",
        "tags": [
          { "id": "2100000000000000001", "name": "重点资产", "color": "#E34D59" }
        ]
      }
    ],
    "total": 1,
    "size": 20,
    "current": 1,
    "pages": 1
  },
  "ok": true
}
```

没有数据或页码超出最后一页时，`records=[]`、`total` 为当前过滤条件下的实际总数；`size` 和 `current` 保留本次请求的分页值，`pages` 按总数计算。`pageSize=0`、`pageSize=101` 或 `pageNum=0` 均返回 `400/ASSET_TAG_INVALID_PARAM`，错误响应沿用第五节结构，`data.errorCode` 为该错误码；调用方应修正参数，不按成功空页处理。

`tagIds` 与其他过滤条件按 AND 组合；多个 `tagIds` 内部按 OR 处理；同时传 `tagIds` 和 `hasTags` 时以 `tagIds` 为准。

### 9.2 资产详情

`GET /api/iotbus/asset/assets/{id}` 返回资产详情，`tags` 使用与分页记录完全相同的标签对象结构；没有标签时返回空数组。

### 9.3 删除资产

`DELETE /api/iotbus/asset/assets/{id}` 删除资产并在同一事务中清理标签关系。调用方不再额外调用批量移除接口。

## 十、幂等、超时与重试

| 场景 | 约定 |
| --- | --- |
| 标签名称重复 | 返回 `409/ASSET_TAG_CONFLICT`，不自动重试 |
| 批量追加 | 已存在关系按幂等成功处理 |
| 批量移除 | 不存在关系按幂等成功处理 |
| 新增标签响应丢失 | 先按同租户的名称唯一约束核对现有标签；仅发现同名记录不能证明本次请求已成功，无法核实时保留结果未知，不换请求直接重建 |
| 编辑、删除和批量覆盖响应丢失 | 先查询目标及关系状态；没有已验证的同键幂等或前次未执行证据时，不自动重放写请求，用户确认也不能代替结果核查 |
| `429` 或网络超时 | `Retry-After` 只规定等待时间，不证明写操作未执行；只读请求可按约定有限重试，写请求先核对结果与接口幂等条件 |
| 认证失败 | 不重试业务请求，先刷新认证上下文 |
| `5xx`/依赖失败 | 只读请求按项目公共客户端的有限重试策略处理；写请求先确认结果，未能确认时展示结果未知而非最终失败，不能由公共客户端无条件重试 |

## 十一、联调场景

| 场景 | 前置条件 | 预期结果 |
| --- | --- | --- |
| 新增标签 | 合法名称和分组 | 返回标签对象，刷新标签列表 |
| 名称重复 | 同一租户重复名称 | `409/ASSET_TAG_CONFLICT` |
| 无权限 | 无标签管理权限 | `403/ASSET_TAG_FORBIDDEN` |
| 跨租户访问 | 使用其他租户资产 ID | 不泄露资源，返回统一错误 |
| 批量清空 | `REPLACE + tagIds=[]` | 清理全部关系，分页返回空标签数组 |
| 重复追加 | 两次提交相同 `APPEND` 请求 | 不产生重复关系 |
| 分页无数据 | 超出最后一页 | `records=[]`，分页字段仍完整 |
| 分页参数越界 | `pageSize=101` 或 `pageNum=0` | `400/ASSET_TAG_INVALID_PARAM`，不查询数据库、不截断参数 |
| 标签过滤 | 传多个 `tagIds` | 任意一个标签命中 |
| 写接口响应丢失 | 前次请求可能已生效 | 先查询结果；没有已验证的同键幂等或前次未执行证据时不重放 |
| 只读查询超时 | 依赖服务不可用 | 按已登记的次数和总预算有限重试，不把失败当空结果 |

## 十三、前端类型与封装要求

前端通过领域 API 统一封装请求和类型，页面不得直接拼接接口地址。资产 ID、标签 ID 全程按 `string` 处理；多个 `tagIds` 使用重复 Query 参数传递；写接口成功后重新请求列表，不依赖写接口返回受影响数量。
