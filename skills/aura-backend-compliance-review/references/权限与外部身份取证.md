# 权限与外部身份取证

涉及应用范围、菜单权限、外部账号或目录同步时按需使用。依据 SEC-004～008、OBS-007、INTEG-002/003 及项目当前公开契约，在本项目授权与适配边界取证。

| 触发 | 取证 | 结论边界 |
| --- | --- | --- |
| 授权过滤与可见菜单 | 先区分未启用应用管理、未知应用、已配置但无绑定、已绑定但与用户授权无交集。追踪空结果是否被缓存、回退或后续查询放宽。反例为用户获准 A、应用仅允许 B，过滤后却返回原集合 A。明确约定的未启用兼容路径单独判断。 | 菜单返回过宽可静态确认。服务端接口越权须继续查实际鉴权链和访问证据。 |
| 外部目录类型同步 | 用项目实际枚举与类型谓词对照已知类型和未知值，检查创建、更新、删除或停用、系统记录与自定义副本是否按同一契约处理。反例为创建正确转换，更新分支却写入外部原值。 | 未知类型的拒绝、跳过或兼容以项目契约为准。删除/停用未提供约定时记录待补证。 |
| 首次外部身份登录 | 沿票据/签名验证、身份映射、默认角色、凭据存储和日志脱敏核查。只记录字段和流向，不落盘真实票据或签名。核对初次创建、后续更新及账号禁用是否使用实际授权策略。 | 看到默认角色只能证实赋权路径。角色是否越权要有部署映射、用户对象与授权契约，不假设全部外部用户都是普通用户。 |
| 外部会话失效 | 分别沿 access、refresh、外部票据及可替代登录入口查过期、注销/禁用和重新认证。某令牌到期而另一 grant 仍可登录是待核路径，确认其凭据、账户资格、Provider 和部署开关后再定性。 | 已看到默认口令或有效期不证明可绕过。确认外部凭据写入日志可按既有规则登记，真实生产泄露须另有证据。 |

可用自有夹具分别构造无交集/未配置、已知/未知类型、外部会话到期与替代登录是否可达。静态片段、替身测试、实际权限与生产运行证据分别记录。
