# 接口专项审查

仅在用户要求审查存量接口、统一响应/分页或接口兼容性时进入。读取[专项路由](references/任务路由.md)命中的规则和[接口取证补充](接口取证补充.md)，不自动扩大为全项目分层与工程审查。

按接口模块盘点提供方、网关路由和调用方，追踪 SDK 原始响应到 Controller 最终输出；核对统一响应、公共分页对象、错误、认证、权限、数据范围、幂等和兼容。对外 OpenAPI 额外检查 `/openapi` 路径、`@PlatfomApi` 登记、平台配置与自动上报证据；内部接口不因未使用该注解而扣分。调用方未知是补证项，不能直接据此修改接口。

与项目审查共用[六文件结果包](../../审查结果包模板.md)和[完成门槛](../../后端审查完成门槛.md)。项目审查同时命中本专项时，接口发现只进入同一结果包，不重复编号或计数。
