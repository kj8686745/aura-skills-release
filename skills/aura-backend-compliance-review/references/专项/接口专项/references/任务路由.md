仅在当前任务需要选择规范章节、交付格式或执行步骤时读取本文件。先按任务命中条目，再打开对应正文、正反例或清单；不要把本文件的路由表当成规范正文。

## 审查步骤

### 1. 建立存量接口清单

只读盘点并按模块记录：

- 路由、HTTP 方法、网关前缀、Controller 或事件入口；
- 请求 DTO、响应 DTO、`R<T>`、历史响应封装、裸 `Map`、实体直出和字段转换；
- `PageResult<T>`、`Page/IPage`、历史分页对象及分页字段；
- 异常处理器、HTTP 状态码、业务错误码、`requestId`、`retryable` 和错误消息；
- 认证、用户、租户、数据范围和高风险动作权限；
- 前端 API 封装、Feign/HTTP 客户端、SDK、网关路由、接口文档和示例；
- 写入副作用、幂等条件、超时、重试、异步受理与最终状态查询。

每项都标记来源路径、代码位置、版本和证据类型，不只记录“存在/不存在”。

### 2. 形成统一契约对照表

将实际实现与当前规范逐项对照，至少覆盖：

| 对照维度 | 必须判断 |
| --- | --- |
| 响应包络 | 分别追踪原始响应、适配层和 Controller 最终返回。公共 `R<T>` 的成功码以 `CommonConstants.SUCCESS=200` 为准；外部协议依据实际契约核对，不改变 AURA 响应码。记录真实路由、暴露条件、调用方及必要的兼容项，不把测试入口推断为正式公开接口。内外均按同一目标契约核对 `code`、`msg`、`data`、`ok` 及错误字段 |
| 业务数据 | 是否使用请求/响应 DTO；是否泄露持久化实体、内部字段、权限字段或未约定字段 |
| 分页 | 区分目标契约和当前实现：内部与对外接口最终使用同一公共 `PageResult<T>` 对象及 `records/total/size/current/pages` 字段；核对框架类型是否已落地、现存 `Page/IPage` 或 `OpenPage` 的实际返回与调用方，将未迁移项列入兼容计划，不宣称仅同字段的私有 DTO 已完成统一 |
| 错误 | HTTP 状态、业务 `errorCode`、安全消息、`requestId`、`retryable` 和调用方处理是否一致 |
| 路径与方法 | API 前缀、资源名、动作命名、方法语义和网关转发是否一致 |
| 身份权限 | 调用方身份、租户、数据范围和高风险动作是否都有代码或运行证据 |
| 兼容性 | 现有调用方是否能继续工作；是否有明确适配层、迁移窗口、版本标识和下线条件 |

不得把认证方式、数据范围或公开字段裁剪误判成另一套响应契约；只能记录为同一契约下的调用边界差异。

### 3. 识别调用方与影响范围

对每个差异追踪提供方、直接调用方、间接调用方和文档使用者。至少检查前端 API 层、Feign/HTTP 客户端、SDK、定时任务、消息消费者、网关和外部登记方。无法确认的调用方标记为“未知”，未知调用方不得直接进入破坏性迁移。

### 4. 分级并安排调整顺序

每条结果使用规则 ID、必要性、影响范围、证据和复核条件输出。优先级遵守[统一结果包模板](../../../审查结果包模板.md)的 P0/P1/P2/P3，不另设严重程度。未知调用方、无法确认的权限或运行契约属于未证实及迁移限制，不因缺少证据直接定为高优先级偏差。

建议顺序为：先补齐现状和契约文档，再建立适配层或兼容转换，随后迁移提供方和调用方，最后在调用方清零、运行证据齐全后移除旧实现。不得先删旧接口再寻找调用方。

### 5. 提交调整建议与复核条件

本审查保持只读。建议先更新模块接口文档和兼容矩阵，再调整 DTO、适配层、分页转换和异常映射；前端、SDK、网关或其他服务按同一迁移顺序安排。实际整改需要另行授权，交由对应开发任务执行，不在审查中直接改代码。兼容旧调用方须有登记的期限、入口和删除条件。

调整后分别核对静态代码、文档、构建、自测和真实请求结果。单次查询、编译通过或搜索命中不能证明所有调用方和运行时行为已经完成迁移。

## 交付格式

按[双模式模板](../../../审查结果包模板.md)输出报告：有界任务使用单报告，全量专项或明确要求结果包时用六文件；不另做重复报告。[接口取证补充](../接口取证补充.md)中的接口、调用方、契约和验证字段按模块填入相应证据章节与发现项。规则状态统一为通过、偏差、未证实、不适用，执行状态与项目质量分开；不为每个接口机械建文件。单报告的模块、候选、证据与整改同文件互引。

审查结果只描述实际观察到的代码、文档和运行证据；没有证据的字段写明未知，不虚构框架能力、调用方或接口行为。
