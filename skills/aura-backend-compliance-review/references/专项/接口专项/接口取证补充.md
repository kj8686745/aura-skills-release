# 接口取证补充

以下字段归入统一结果包的 `03-证据与执行记录.md`，按业务模块分节；偏差关联 `01-审查报告.md` 的 F-编号，不再另做一套接口报告。

| 清单 | 每项需记录 |
|---|---|
| 接口 | 模块、接口编号、HTTP 方法/路径或事件、网关前缀、入口文件及符号、请求/响应 DTO、响应与分页类型、错误入口、证据编号 |
| 调用方 | 名称、调用位置、方式、依赖字段和状态、提供方版本、确认程度、证据编号 |
| 响应与分页对照 | 规范契约、实际返回、SDK/适配层/Controller 层次、公开状态、字段差异、兼容方式、受影响调用方 |
| 错误与权限 | HTTP 状态、业务错误码、请求标识、重试语义、身份/租户/数据范围、实际证据与缺口 |
| 写入与兼容 | 副作用、幂等条件、超时/响应丢失处理、最终结果查询、版本或兼容窗口、下线条件 |
| 验证 | 正常、参数错误、认证/权限、重复请求、并发冲突、超时及兼容调用的预期、实际结果、环境和证据 |

实际整改顺序及每阶段前提、完成证据和停止条件归入 `04-整改与复核清单.md`。建议按现状固化、文档与适配、提供方调整、调用方迁移、旧契约下线组织；无调用方清单或运行证据时不能宣称可以下线。

以上是取证字段，不是新的技术规范。缺失字段记录未知；优先级、状态、证据类别和统计口径均使用统一模板，不保留旧报告的另一套枚举。
