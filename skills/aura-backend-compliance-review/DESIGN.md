# 设计说明

本技能是一次性审查编排器，把后端审查拆成“自动版本固定—规则路由—全量证据采集—候选归并—偏差判定—构建补证—报告交付—完整性复核”。这些是内部执行阶段，不是用户交互阶段；技能应连续完成可执行工作，最后一次性交付结果包。入口只保存任务边界和状态语义，具体规则通过规范入口和执行路由按需读取，避免把整套规范无条件加载进会话。

审查报告是技能的必要产物，不是附加说明。每个发现项必须能够回到一个正式规则 ID 和一份可定位证据；没有足够证据时保留为未证实项。缺少分支、规范版本、构建环境或运行环境时，技能记录阻断或未证实并继续，不把每个缺口变成一次问答。技能只负责发现和说明偏差，整改由项目责任人授权后另行执行；只有目标不可定位、只读边界需扩大或外部访问未授权时才允许一次前置询问。
