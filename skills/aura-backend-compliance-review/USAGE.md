# 后端与接口规范审查使用说明

提供项目位置或仓库地址，可补充分支、提交和范围；也可直接描述审查任务。未指定版本时读取本地当前版本或远程默认分支并记录，不自动切换或覆盖用户改动。

> 使用 $aura-backend-compliance-review 对指定项目执行完整后端规范审查，输出可追溯的结果包，不修改代码。

> 使用 $aura-backend-compliance-review 只审查设备模块的内部与对外接口，核对响应、分页、错误、鉴权和调用方兼容，不扩展为全项目审查。

一次执行自动完成盘点、扫描、候选归并、逐规则判定、可执行的补证和结果包复核。缺少运行环境或调用方时保留未证实项，不反复要求用户确认下一步。

两种范围均交付六文件：结果包说明、审查报告、规则核查矩阵、证据与执行记录、整改与复核清单、扫描候选与判定。接口专项按模块归并，保留接口及调用方清单；未知调用方不能据此直接做破坏性迁移。

本包已包含接口专项资料，不需另装接口审查技能。新接口设计、后端实现和审查技能建设分别使用对应入口。审查结果不等于真实联调或发布验收。
