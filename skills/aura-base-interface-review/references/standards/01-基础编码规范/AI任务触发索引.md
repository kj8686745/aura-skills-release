# AURA（天玑）基础编码规范 AI 任务触发索引

**规范版本**：`0.1.0-draft`

**用途**：供技能按任务选择需要读取的规范正文。本文只负责“任务 → 模块 → 正文入口”定位，不承载规则要求、正反例或验收结论。

## 使用方式

1. 先按任务关键词命中一个或多个模块。
2. 只打开命中模块列出的正文文件。
3. 在正文中搜索规则编号或规则标题，读取该规则、正例、反例和必要上下文。
4. 任务未涉及的模块不预加载；不得把本索引或完整矩阵当作规范正文。

## 与人工矩阵的关系

人工审阅时继续使用[规范矩阵](./规范矩阵.md)，查看完整模块关系、规则编号和必要性速查。技能执行时优先使用本索引，再按命中结果打开正文；两者发生不一致时，以规则正文为准，并将差异纳入规范维护。
