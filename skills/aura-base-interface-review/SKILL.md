# AURA 存量接口审查与调整

询问如何调用本技能时，阅读[使用说明](USAGE.md)。

本技能只用于已有系统的接口审查、契约收敛和迁移准备。新接口设计、模块接口文档编制使用 `aura-base-interface-development`；后端代码调整使用 `aura-base-backend-development`；规范治理、技能同步和发布检查使用 `aura-standard-maintainer`。本技能不因为发现差异就直接修改代码，也不把静态扫描结果写成运行时已验证。

本技能版本为 `1.0.2`，按随包快照适配 `0.1.0-draft` 基础编码规范。先在[AI任务触发索引](references/standards/01-基础编码规范/AI任务触发索引.md)定位适用模块，再在[审查路由与执行指南](references/任务路由.md)中检索本次审查类型对应的行，读取命中的规则与示例；人工审阅需要完整矩阵时再打开[规范矩阵](references/standards/01-基础编码规范/规范矩阵.md)，不批量加载全部规范或路由。

## 审查路由与执行指南

按[审查路由与执行指南](references/任务路由.md)收集范围和证据，再读取命中的规则、模板与示例。只打开本次审查涉及的资料，不批量加载全部规范；缺少项目、版本、调用方或运行证据时明确阻断项。
