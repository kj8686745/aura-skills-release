# 存量接口审查与调整技能使用说明

系统已经开发并运行一段时间，需要核对接口现状、调用方和统一契约时，提供项目根目录、分支或版本、接口模块范围以及可取得的代码/文档/运行证据；也可显式调用 `$aura-base-interface-review`。

示例：`$aura-base-interface-review 审查当前设备审核模块的存量接口，核对 R<T>、PageResult<T>、错误字段、权限和所有调用方，输出差异分级与迁移顺序；先不要修改代码。`

本技能默认只读审查，结果按随技能提供的[存量接口审查报告模板](templates/存量接口审查报告模板.md)输出。若需要落实调整，应在审查结果明确后再次授权，并说明允许修改的项目、模块和兼容范围。
