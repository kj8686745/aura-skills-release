# aura-cap-file-realtime-use 任务路由与执行指南

仅在当前任务命中本能力包时读取本文件。先确认项目版本、已启用模块和任务边界，再打开命中的能力条目；不要把整份能力包说明一次性加载。

## 开发时

1. 确定项目实际引入的模块和版本，只为命中的任务读取相应入口；不要把示例中的业务模型、类名或路径当成项目现成实现。
2. 单独上传、读取或删除文件时，转 `aura-cap-base-use` 并读取其[文件存储说明](standards/05-能力包/01-通用工具类/03-基础通用支撑能力包/08-文件存储能力说明.md)。Excel 与文件任务的组合仍需核对权限、租户、DTO/VO、文件元数据和失败反馈；`@RequestExcel` 用于参数，`@ResponseExcel` 用于方法。
3. 需要下载任务时，只按本包第 2 节核对当前模块状态。该模块尚无可照用的完整接入契约；目标项目若有独立且已验证的文件任务实现，按该项目契约处理，不从 `@ExportMonitor` 或 `IExportExcelService` 推断可直接接入。
4. SSE、WebSocket 或 Socket.IO 任务先按协议选入口，再核对握手/连接身份、消息级权限、接收目标、断线和多实例行为。Socket.IO 使用 `socket.io-client`；其 `broadcastEmbedded` 只覆盖当前实例的同租户嵌入式连接，不能当作按用户定向或跨实例可靠投递。单播返回或发送成功不等于客户端已处理消息，广播不能承载用户私有数据。
5. 完成后按命中的公开规范检查成功、失败、权限和边界结果；只报告项目实际验证过的行为。

## 边界

按周期运行的任务和 `aura-common-job` 执行器归任务与调度能力包；消息总线、物联和视频的领域消息归各自能力包。Socket.IO 的 `1.0.5-RELEASE` 入口已对照 `aura-core-common dev@0f94cdc` 源码，但未在目标项目运行；项目版本与随包规范不一致或入口缺失时，应说明缺口，不能自行补造框架 API 或宣称接入完成。本技能不修改公共模块内部实现，不包含内部治理和评分。
