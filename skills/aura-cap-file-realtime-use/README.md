## 使用入口

- [技能入口](SKILL.md)：按文件任务或实时交互场景分流。
- [使用说明](USAGE.md)：查看调用方式和任务输入。
- `references/研发任务导航.md`：定位 Excel、SSE、WebSocket、Socket.IO 和下载任务说明。
- `references/standards/`：安装后可独立查阅相关规范快照。

连接身份、消息级权限、断线、多实例和文件元数据必须按实际项目验证。
