# 文件与实时交互能力使用

询问如何调用本技能时，阅读[使用说明](USAGE.md)。

本技能版本为 `1.0.2`。先读[能力包总入口](references/standards/05-能力包/01-通用工具类/04-文件任务与实时交互能力包/总入口.md)和[能力清单](references/standards/05-能力包/01-通用工具类/04-文件任务与实时交互能力包/能力清单与边界.md)判断是否命中，再在[研发任务导航](references/研发任务导航.md)中检索文件、实时协议或能力编号，读取对应详细说明。不要全文加载导航或能力正文；能力事实只以这些同版规范和当前项目已安装的框架实现为准。

## 任务路由与执行指南

确认任务命中本能力包后，先在[任务路由与执行指南](references/任务路由.md)中检索能力名称或编号，再读取对应能力条目、前置条件和验证要求。只打开当前任务需要的说明，不整包加载路由或能力正文。

## 边界

项目版本、能力入口、关键配置或运行结果无法从规范和项目确定时，列出缺口并停止推断。本技能不修改公共模块内部实现，不把未验证的能力写成已启用。
