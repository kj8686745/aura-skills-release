# 文件与实时交互能力使用

询问如何调用本技能时，阅读[使用说明](USAGE.md)。

本技能是 `draft` 候选入口。先读[能力包总入口](references/standards/05-能力包/01-通用工具类/04-文件任务与实时交互能力包/总入口.md)和[能力清单](references/standards/05-能力包/01-通用工具类/04-文件任务与实时交互能力包/能力清单与边界.md)判断是否命中，再按[研发任务导航](references/研发任务导航.md)读取对应详细说明。能力事实只以这些同版规范和当前项目已安装的框架实现为准。

## 开发时

1. 确定项目实际引入的模块和版本，只为命中的任务读取相应入口；不要把示例中的业务模型、类名或路径当成项目现成实现。
2. 单独上传、读取或删除文件时，转 `aura-cap-base-use` 并读取其[文件存储说明](references/standards/05-能力包/01-通用工具类/03-基础通用支撑能力包/08-文件存储能力说明.md)。Excel 与文件任务的组合仍需核对权限、租户、DTO/VO、文件元数据和失败反馈；`@RequestExcel` 用于参数，`@ResponseExcel` 用于方法。
3. 需要下载任务时，只按本包第 2 节核对当前模块状态。该模块尚无可照用的完整接入契约；目标项目若有独立且已验证的文件任务实现，按该项目契约处理，不从 `@ExportMonitor` 或 `IExportExcelService` 推断可直接接入。
4. SSE 或 WebSocket 任务核对握手/连接身份、消息级权限、接收目标、断线和多实例行为。单播返回或发送成功不等于客户端已处理消息，广播不能承载用户私有数据。
5. 完成后按命中的公开规范检查成功、失败、权限和边界结果；只报告项目实际验证过的行为。

## 边界

按周期运行的任务和 `aura-common-job` 执行器归任务与调度能力包；消息总线、物联和视频的领域消息归各自能力包。项目版本与候选规范不一致或入口缺失时，应说明缺口，不能自行补造框架 API 或宣称接入完成。本技能不修改公共模块内部实现，不包含内部治理和评分。
