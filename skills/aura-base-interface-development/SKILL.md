# AURA 接口契约与联调

询问如何调用本技能时，阅读[使用说明](USAGE.md)。

本技能版本为 `1.0.2`，按随包快照适配 `0.1.0-draft` 基础编码规范。接口规则、模板要求和示例以规范正文为准；按任务读取，不批量加载全部示例。

跨模块任务先在[AI任务触发索引](references/standards/01-基础编码规范/AI任务触发索引.md)按关键词选模块，再按规则编号或主题词定位正文；人工审阅需要完整矩阵时再打开[规范矩阵](references/standards/01-基础编码规范/规范矩阵.md)。只读取命中的规则与示例，不整篇加载规范矩阵或全部规范。

先依据本次接口类型和交付物，在下表选资料；对较长的规范先定位目录、规则 ID 或章节标题，只读取命中条款至下一条标题及必要上下文。编写模块接口文档时优先读接口文档规范的核心规则与最小结构、模板中适用的章节；接口设计细节再查接口规范对应条款，身份或租户细节再查安全规范对应条款。不为一项任务整篇加载所有规范与模板。核对项目路径或网关前缀时，只查询相关配置键及相邻必要行，不整篇输出可能含凭据的配置文件；运行行为未验证时标明待核对。

## 任务路由与执行指南

先从本次接口类型和交付物确定实际涉及的 HTTP、实时事件、服务间调用、数据字段、权限或联调环节；先在[任务路由与执行指南](references/任务路由.md)中检索匹配关键词或任务行，再只读取命中的规则和示例。不要把路由文件全文加载到上下文。运行行为未核对时保留待验证状态；规范版本或项目事实无法确定时，列出缺口并停止推断。
