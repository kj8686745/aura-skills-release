# 接口文档示例：告警实时推送

> 本文是 WebSocket 实时通知与 HTTP 告警列表配合的设计示例，路径、事件、数量限制和版本均为示例约定，不代表现行项目已按本文发布或完成联调。实时连接只负责在线通知；HTTP 列表是其查询范围内的事实来源，不保证找回断线期间的每条事件。浏览器握手认证方式须由提供模块另行登记并实现，不能直接照搬连接地址投入使用。

## 接口逐项契约

### API-ALARM-STREAM-001 告警实时通知连接

- **请求**：浏览器连接 `wss://<gateway-host>/<public-prefix>/ws/info`；握手须由服务端按模块已登记、且不在 URL 中暴露登录 Token 的认证方式验证身份与租户。本示例不预设该认证能力已实现。
- **成功**：握手成功后建立一个页面级活动连接，服务端按第三节发送 `alarm.created` 事件；连接本身不返回 HTTP `R<T>` 响应体。
- **失败**：Token 缺失或失效时握手失败，不创建业务会话；租户或权限不满足时不得建立可接收告警的连接。失败原因只返回调用方可处理的握手结果，不泄露 Token 或内部异常。
- **调用方处理**：认证失败先按框架会话流程处理，不以网络错误方式无限重连；网络失败按第四节有限退避重连；退出登录、账号切换或页面销毁时关闭连接并清理心跳。

### API-ALARM-STREAM-002 告警列表断线恢复

- **请求**：`GET /api/iotbus/alarm-center/alarms/page?pageNum=1&pageSize=20`，使用当前身份上下文调用；`pageNum` 最小 1，`pageSize` 默认 20、允许 1～100，结果按发生时间降序和告警 ID 降序稳定排序。
- **成功**：HTTP `200`，使用统一 `R<PageResult<AlarmSummary>>`；`data` 至少包含 `records`、`total`、`size`、`current`、`pages`，无数据时 `records=[]`。
- **失败**：参数错误使用 `400/ALARM_INVALID_PARAM`，未认证使用 `401/UNAUTHORIZED`，无权限或数据范围不足使用 `403/ALARM_FORBIDDEN`，依赖故障使用 `500/ALARM_SERVICE_FAILED`；调用方不能把失败响应当作空列表。
- **调用方处理**：每次连接成功和重连成功都重新请求列表；只用与当前连接、筛选和分页条件匹配的最新响应更新页面。查询失败时保留上次已确认结果并提示恢复未完成；当前分页不能证明已找回断线期间的全部事件。

## 二、连接与认证

浏览器连接：

```text
wss://<gateway-host>/<public-prefix>/ws/info
```

- 生产环境使用 `wss://`，本地 HTTP 开发环境才使用 `ws://`。
- 浏览器原生 WebSocket 不能自定义 `Authorization` 请求头；提供模块必须登记浏览器可用的握手认证方式、服务端身份校验、凭证失效处理和失败结果。没有已实现的认证方式时，本连接不能作为可用接口交付。
- 不得把完整登录 Token 拼入连接 URL，也不得写入日志、截图、埋点或错误上报。
- 租户从服务端已验证的登录身份上下文获取，消息正文不得携带前端自定义 `tenantId`。
- 同一页面最多保持一个活动连接；退出登录或账号切换时必须关闭旧连接。

## 三、事件契约

本示例只定义新增告警事件 `alarm.created`；更新、确认、解除、删除和事务回滚不广播该事件。

```json
{
  "type": "alarm.created",
  "version": "v1",
  "messageId": "6b6318da-53c5-4ddd-b94c-9e99175ed429",
  "sentAt": "2026-08-27T15:30:00+08:00",
  "data": {
    "alarmId": "123",
    "alarmName": "SOS紧急求助",
    "severity": "critical",
    "alarmType": "device_alarm",
    "deviceId": "1001",
    "assetId": "2001",
    "content": "触发SOS求助",
    "occurTime": "2026-08-27T15:29:58",
    "status": 0
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `type` | string | 是 | 固定为 `alarm.created` |
| `version` | string | 是 | 事件契约版本，当前为 `v1` |
| `messageId` | string | 是 | 服务端生成的 UUID，用于短窗口去重，不是可靠序号 |
| `sentAt` | string | 是 | 发送瞬间，ISO-8601 格式并显式包含时区偏移量；示例为 `+08:00` |
| `data` | object | 是 | 告警公开投影，不是数据库实体 |
| `data.alarmId` | string | 是 | 告警 ID，按字符串传递 |
| `data.severity` | string/null | 否 | 严重级别编码，紧急判断使用 `critical` |
| `data.alarmType` | string/null | 否 | 告警类型编码 |
| `data.deviceId` | string/null | 否 | 设备 ID |
| `data.assetId` | string/null | 否 | 资产 ID |
| `data.content` | string/null | 否 | 告警内容 |
| `data.occurTime` | string/null | 否 | 告警业务发生时间；本示例为无偏移量的中国区本地时间，按 `Asia/Shanghai` 解释，不按浏览器本地时区猜测；实际格式由模块契约固定 |
| `data.status` | number/null | 否 | 当前告警状态 |

不得依赖数据库实体字段、原始设备报文、Token 或内部租户字段。

## 四、心跳、断线与恢复

客户端每 25 秒发送：

```json
{"type":"ping"}
```

服务端响应：

```json
{"type":"pong"}
```

连接状态必须遵循：

```text
open → 启动心跳 → 拉取当前告警列表
close/error → 停止心跳 → 指数退避重连
reopen → 重启心跳 → 再次拉取当前告警列表
```

- 连续约两个心跳周期没有 `pong` 时关闭连接并进入重连；
- 重连采用指数退避，最大等待 30 秒并加入随机抖动；
- 每次连接成功都重新请求告警列表；请求完成前到达的新事件须触发后续刷新或按已确认顺序合并，不能被较早发起的列表响应覆盖；
- WebSocket 不补发断线期间的消息，当前分页只能恢复该查询范围的列表视图；业务若要求找回全部遗漏事件，须另行登记并实现游标或时间范围等可校验的补拉入口，不能把实时连接当可靠消息队列；
- 去重使用 `messageId`，缓存最多保留 5 分钟或 500 条；
- 页面销毁、退出登录和账号切换时清理心跳、重连任务和去重缓存。

## 五、前端处理约定

收到未重复的 `alarm.created` 后，将其作为刷新当前列表和统计的信号；若选择本地更新，必须按当前筛选、排序和分页条件处理，并防止在途列表响应覆盖较新的事件。`severityName` 若由列表接口提供，只用于显示；紧急判断只使用 `severity` 编码。

## 六、联调场景

| 场景 | 前置条件 | 预期结果 |
| --- | --- | --- |
| 合法连接 | 模块已实现并登记浏览器握手认证，凭证有效且租户上下文可信 | 握手成功并建立独立会话 |
| 认证失败 | 握手凭证过期或缺失 | 握手失败，不创建业务会话；前端按会话流程处理，不无限重连 |
| 新增告警 | 告警事务成功提交 | 收到一次 `alarm.created` |
| 非新增变更 | 确认、解除或更新告警 | 不发送 `alarm.created` |
| 心跳 | 周期发送 `ping` | 返回 `pong` |
| 网络断开 | 连接关闭或错误 | 停止心跳，按退避重连 |
| 重连恢复 | 重新握手成功 | 重新拉取告警列表 |
| 补拉与事件并发 | 列表请求在途时收到新事件 | 较早发起的列表响应不覆盖较新的事件或页面状态 |
| 列表查询失败 | WebSocket 已重连、HTTP 列表查询失败 | 保留上次已确认结果，提示恢复未完成，不宣称断线数据已补齐 |
| 重复消息 | 相同 `messageId` 再次到达 | 页面只处理一次 |
| 跨租户 | 其他租户告警 | 不得收到消息 |
| 凭据泄露检查 | 查看连接 URL、日志和错误上报 | URL 不包含完整登录 Token，日志和错误上报不包含认证凭据 |
