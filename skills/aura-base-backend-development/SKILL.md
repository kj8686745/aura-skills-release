# AURA 后端基础编码开发

询问如何调用本技能时，阅读[使用说明](USAGE.md)。

本技能版本为 `1.0.2`，按随包快照适配 `0.1.0-draft` 基础编码规范。规则和正反例以规范正文为准；按任务读取，不批量加载全部规范。

跨模块任务先在[AI任务触发索引](references/standards/01-基础编码规范/AI任务触发索引.md)按关键词选模块，再按规则编号或主题词定位正文；人工审阅需要完整矩阵时再打开[规范矩阵](references/standards/01-基础编码规范/规范矩阵.md)。只读取命中的规则与示例，不整篇加载规范矩阵或全部规范。

需要参考完整开发场景时，先从[后端基础编码分类](references/standards/01-基础编码规范/总入口.md#三后端基础编码分类)找到示例所在文件，只读取当前场景及其关联规则；不因一个示例读完六份分类正文。

仅创建后端工程骨架时，先按规则标题定位 `AURA-BASE-BE-001/002` 和实际新增代码涉及的条款，只读取命中条款的规则、正反例与必要上下文；再按实际引入的依赖、配置和构建入口读取相应规范。尚无真实 HTTP、数据访问、异步副作用或长期运行资源时，不因未来的接入计划预读接口、数据、异步、运行时等整份规范；确定行为后再读取该行为对应的规则与正反例。

## 任务路由与执行指南

先从需求确定实际涉及的工程、接口、数据、权限、事务、异步或交付环节；先在[任务路由与执行指南](references/任务路由.md)中检索匹配关键词或任务行，再只读取命中的规则与正反例。不要把路由文件全文加载到上下文。框架公共能力的具体接入方式交给对应能力包技能；规范版本或项目事实无法确定时，列出缺口并停止推断。
