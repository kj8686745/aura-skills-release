# 后端交付验证检查

- [ ] 已检查正常、参数错误、认证/权限拒绝和资源不存在路径。
- [ ] 对写操作已检查重复提交、事务失败、外部超时或异步受理边界（若适用）。
- [ ] 已运行目标项目可用的静态检查、构建和研发自测，并记录命令与结果。
- [ ] 接口文档、调用方、适配层和代码行为一致。
- [ ] 未验证项标记为“未验证”，未用静态搜索或编译通过代替运行证据。
- [ ] 实际变更均有对应的规则和验证：升级依赖核对最终解析与消费者兼容；改共享缓存、连接或线程时核对创建、使用、失效、关闭的并发交互与失败路径，不以线程安全容器代替复合操作验证。不涉及的环节跳过。
- [ ] 删除测试或更换依赖后，现行测试集合、历史试验、文档完成声明和交付链接已重新核对；明确哪次结果对应当前代码，而非累加旧测试数量。
