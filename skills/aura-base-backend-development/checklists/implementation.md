# 后端实现检查

- [ ] Controller 只处理接口适配和输入校验，业务编排位于 Service 用例。
- [ ] 请求、响应模型与持久化实体边界明确，没有实体直出或第二套响应外壳。
- [ ] 数据访问、事务、缓存、异步和外部调用分别落在有真实职责的边界。
- [ ] 权限、租户、数据范围、审计和幂等按当前项目实际入口接入。
- [ ] 配置、依赖和 API 变更有版本及兼容说明。
- [ ] 公共能力来自项目实际依赖版本的公开 API，已追踪调用点；依赖存在不等于已复用。
- [ ] 已识别并应用本次相关公共处理：Service内共享留本类，模块跨Service稳定处理归模块 `XxxCommonUtil`；无消费者旧实现已在范围内收束，类/方法注释与实际调用一致，未把主流程事务堆入工具或扩成全仓重构。
- [ ] 接口契约变化已同步同一模块接口文档，包含请求、响应、错误、权限及兼容变化。
