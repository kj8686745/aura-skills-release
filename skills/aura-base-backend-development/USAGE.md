# 后端基础编码技能使用说明

新增或修改 AURA 后端业务代码时，直接描述业务目标、代码位置及现有接口和数据契约；也可显式调用 `$aura-base-backend-development`。

示例：`$aura-base-backend-development 依据当前订单模块的代码和接口契约实现状态更新，并核对权限、事务和失败结果。`

如果目标是已经运行一段时间的系统，先使用 `$aura-base-interface-review` 盘点接口现状和调用方，再将明确授权的后端调整交给本技能；不要直接把历史接口重写成新契约。

公共组件的具体接入另选命中的能力包技能；本技能按任务读取随包基础编码规范，不把未运行的自测写成通过。
