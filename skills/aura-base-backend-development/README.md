# AURA 后端基础编码开发技能

面向 AURA Java/Spring Boot 后端业务的新增、修改和重构，覆盖接口、分层、数据访问、权限、事务、异步、配置、日志和交付。

## 使用入口

- [技能入口](SKILL.md)：根据研发任务选择规则和能力包。
- [使用说明](USAGE.md)：查看调用前需要提供的项目事实。
- `checklists/`：开发前、实现中和交付验证清单。
- `references/standards/`：安装后可独立查阅的基础编码规范快照。

已运行系统的存量接口先使用接口审查技能；公共框架能力按命中场景使用对应能力包技能。
