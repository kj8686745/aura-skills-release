# 网关与流量治理研发任务导航

本表仅负责选读；依赖、正反例和完成判断以[能力详细说明](../../../standards/05-能力包/01-通用工具类/07-网关与流量治理能力包/能力详细说明.md)为准。

| 研发任务 | 选读章节 | 重点核对 |
| --- | --- | --- |
| 新增、调整、删除或回滚动态路由 | 第 1、6 节 | 实际使用的路由实现、受控写入、删除完成顺序、路径匹配与回滚 |
| 开启网关灰度 | 第 2、6 节 | `gray.rule.enabled`、可信 `VERSION`、实例元数据、无匹配回退 |
| Feign 或非 Web 任务传递版本 | 第 3、6 节 | 上下文来源、Nacos 实例类型、下游请求头、实例选择、`finally` 清理 |
| 为 Servlet 接口或 Feign 调用配置保护 | 第 4、6 节 | Sentinel 规则、阻断与回退结果、恢复行为 |
| 为网关路由配置限流 | 第 5、6 节 | 限流过滤器、可信 IP/Key、阈值和拒绝结果 |
| 对外 API 自动收录到平台 | 仅读能力详细说明第 2 节 | `aura-common-core` 依赖、`aura.platform-api` 配置、`@PlatfomApi` 的 `code/version/name/requestPath`、`/openapi` 实际路径和启动上报结果 |
