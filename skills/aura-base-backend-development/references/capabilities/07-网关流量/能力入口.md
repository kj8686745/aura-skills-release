# 网关与流量治理能力使用


先读[能力包入口](../../standards/05-能力包/01-通用工具类/07-网关与流量治理能力包/总入口.md)和[能力清单与边界](../../standards/05-能力包/01-通用工具类/07-网关与流量治理能力包/能力清单与边界.md)，再在[研发任务导航](references/研发任务导航.md)中检索网关、流量或能力编号，选读详细说明。同版公开规范与项目实际依赖、配置是能力事实源，不全文加载导航或能力正文。

## 任务路由与执行指南

确认任务命中本能力包后，先在[任务路由与执行指南](references/任务路由.md)中检索能力名称或编号，再读取对应能力条目、前置条件和验证要求。只打开当前任务需要的说明，不整包加载路由或能力正文。

## 边界

项目版本、能力入口、关键配置或运行结果无法从规范和项目确定时，列出缺口并停止推断。本使用模块不修改公共模块内部实现，不把未验证的能力写成已启用。


## 使用边界与输入


本模块按流量治理位置分为动态路由、灰度选择、Servlet/Feign 保护和网关限流四类。每类先确认真实实现与配置，再核对写入、回退、清理和运行结果，不把依赖存在视为能力启用。

业务授权、普通 CRUD 和严格版本隔离方案不属于本模块的默认职责。

涉及动态路由、灰度、服务保护或网关限流时，提供网关与服务版本、已有配置和目标流量规则；也可显式调用 `$aura-base-backend-development`。

示例：`$aura-base-backend-development 核对当前网关已有的限流能力，并设计订单查询入口的适用规则与验证方式。`

普通业务权限和 CRUD 不由本模块处理；部署前须核对真实路由、注册中心与运行结果。
