# 文件与实时交互任务路由

本表只负责按任务选读。具体调用、边界、正反例和完成判断以[能力详细说明](../../../standards/05-能力包/01-通用工具类/04-文件任务与实时交互能力包/能力详细说明.md)为准。

| 研发任务 | 命中能力 | 重点核对 |
| --- | --- | --- |
| 上传、读取或删除业务文件 | 转 `aura-base-backend-development` 的[文件存储说明](../../../standards/05-能力包/01-通用工具类/03-基础通用支撑能力包/08-文件存储能力说明.md) | `FileTemplate` 实现、对象键、业务归属、权限和租户 |
| 核对下载任务模块是否可接入 | 模块现状，第 2 节 | 当前无可照用的完整入口；目标项目若另有实现，需单独核对其契约 |
| 导入或导出表格 | Excel，第 3 节 | 参数级 `@RequestExcel`、方法级 `@ResponseExcel`、DTO/VO、失败行 |
| 服务端推送进度或通知 | SSE，第 4 节 | 连接身份、单播目标、租户、多实例、断线语义 |
| 双向实时消息或会话 | WebSocket，第 5 节 | 消息类型、握手与消息级权限、会话目标、重连 |
| Socket.IO 协议接入或按租户实时广播 | Socket.IO，第 6 节 | `1.0.5-RELEASE` 实际依赖、`socket.io-client`、Token 与租户、`path`/namespace、当前实例广播和断线补齐 |

组合场景见详细说明第 7 节。按时间统一调度或管理执行器的任务应转到任务与调度能力包，不在本模块内读取或实现。

文件或表格的业务实现先进入[文件与批处理开发](../../../文件与批处理开发.md)命中流程；默认Excel监听器累积有效行与错误，不能把收到的List当全文件校验结果，也不能据注解推断已流式分批。实时通知仅在需求明确需要时追加。

## 开发时

1. 确定项目实际引入的模块和版本，只为命中的任务读取相应入口；不要把示例中的业务模型、类名或路径当成项目现成实现。
2. 单独上传、读取或删除文件时，转 `aura-base-backend-development` 并读取其[文件存储说明](../../../standards/05-能力包/01-通用工具类/03-基础通用支撑能力包/08-文件存储能力说明.md)。Excel 与文件任务的组合仍需核对权限、租户、DTO/VO、文件元数据和失败反馈；`@RequestExcel` 用于参数，`@ResponseExcel` 用于方法。
3. 需要下载任务时，只按本包第 2 节核对当前模块状态。该模块尚无可照用的完整接入契约；目标项目若有独立且已验证的文件任务实现，按该项目契约处理，不从 `@ExportMonitor` 或 `IExportExcelService` 推断可直接接入。
4. SSE、WebSocket 或 Socket.IO 任务先按协议选入口，再核对握手/连接身份、消息级权限、接收目标、断线和多实例行为。Socket.IO 使用 `socket.io-client`；其 `broadcastEmbedded` 只覆盖当前实例的同租户嵌入式连接，不能当作按用户定向或跨实例可靠投递。单播返回或发送成功不等于客户端已处理消息，广播不能承载用户私有数据。
5. 完成后按命中的公开规范检查成功、失败、权限和边界结果；只报告项目实际验证过的行为。

## 边界

按周期运行的任务和 `aura-common-job` 执行器归任务与调度能力包；消息总线、物联和视频的领域消息归各自能力包。Socket.IO 的 `1.0.5-RELEASE` 入口已对照 `aura-core-common dev@0f94cdc` 源码，但未在目标项目运行；项目版本与随包规范不一致或入口缺失时，应说明缺口，不能自行补造框架 API 或宣称接入完成。本模块不修改公共模块内部实现，不包含内部治理和评分。
