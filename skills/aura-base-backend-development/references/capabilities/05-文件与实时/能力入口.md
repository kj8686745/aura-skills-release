# 文件与实时交互能力使用


先读[能力包总入口](../../standards/05-能力包/01-通用工具类/04-文件任务与实时交互能力包/总入口.md)和[能力清单](../../standards/05-能力包/01-通用工具类/04-文件任务与实时交互能力包/能力清单与边界.md)判断是否命中，再在[研发任务导航](references/研发任务导航.md)中检索文件、实时协议或能力编号，读取对应详细说明。不要全文加载导航或能力正文；能力事实只以这些同版规范和当前项目已安装的框架实现为准。

## 任务路由与执行指南

确认任务命中本能力包后，先在[任务路由与执行指南](references/任务路由.md)中检索能力名称或编号，再读取对应能力条目、前置条件和验证要求。只打开当前任务需要的说明，不整包加载路由或能力正文。

## 边界

项目版本、能力入口、关键配置或运行结果无法从规范和项目确定时，列出缺口并停止推断。本使用模块不修改公共模块内部实现，不把未验证的能力写成已启用。


## 使用边界与输入


本模块把文件任务与实时交互作为组合能力管理：文件存储负责对象生命周期，Excel 负责数据交换，SSE、原生 WebSocket 和 Socket.IO 分别处理命中的实时场景。Socket.IO 是独立协议入口，不能用原生 WebSocket 客户端替换；其当前实例按租户广播不自动具备用户定向、离线补发或跨实例分发。各自的契约分开读取，避免复制文件存储或调度能力的第二套定义。

技能不把下载任务中的实现线索自动升级为可接入能力；未确认的模块契约、权限和多实例行为必须停止并报告缺口。

业务需要 Excel、SSE、WebSocket、Socket.IO、组合文件任务，或核对下载任务模块的接入状态时，说明数据来源、规模和项目依赖；也可显式调用 `$aura-base-backend-development`。Socket.IO 请提供实际公共模块版本、应用对外路径、namespace、认证方式和部署实例数。单独文件存储接入使用 `$aura-base-backend-development`。

示例：`$aura-base-backend-development 为当前分组列表选择同步 Excel 导出方式，核对已有注解与权限边界。`

定时任务和调度器不属于本模块；不同文件和实时场景按任务读取对应资料。
