# 基础业务开发能力使用模块

需要业务闭环时直接在[基础业务任务路由](references/任务路由.md)按 CRUD、业务动作、事务或数据访问定位章节。能力事实来自[能力详细说明](../../standards/05-能力包/01-通用工具类/01-基础业务开发能力包/能力详细说明.md)，共同要求来自命中的基础编码规范。

对应基础功能必须核对并复用当前版本公开的响应、数据访问、实体及身份入口，不复制公共包内部实现。业务字段与职责仍按当前需求定义，不为凑层次生成无用 DTO、Mapper 或接口；普通本地事务不引入跨服务事务。缺少公开类型或版本证据时指出具体缺口，不按示例虚构 API。
