# 数据安全与内容防护能力使用


先读[能力包入口](../../standards/05-能力包/01-通用工具类/06-数据安全与内容防护能力包/总入口.md)和[能力清单](../../standards/05-能力包/01-通用工具类/06-数据安全与内容防护能力包/能力清单与边界.md)，再在[研发任务导航](references/研发任务导航.md)中检索能力名称或编号，选读命中的详细说明。同版公开规范与项目实际依赖是能力事实源，不全文加载导航或能力正文。

## 任务路由与执行指南

确认任务命中本能力包后，先在[任务路由与执行指南](references/任务路由.md)中检索能力名称或编号，再读取对应能力条目、前置条件和验证要求。只打开当前任务需要的说明，不整包加载路由或能力正文。

## 边界

项目版本、能力入口、关键配置或运行结果无法从规范和项目确定时，列出缺口并停止推断。本使用模块不修改公共模块内部实现，不把未验证的能力写成已启用。


## 使用边界与输入


本模块按展示、输入、数据库和 HTTP 报文四类保护位置分流。每类能力都要求核对实际配置、装配条件、输入输出链路和失败行为，不能只凭注解、依赖或配置项存在判断保护已生效。

安全能力的结果必须回到真实 DTO、序列化、持久化或协议验证中确认；技能不携带内部审查和评分规则。

处理字段脱敏、内容清理、字段保护或报文加密时，提供实际 DTO/VO、序列化路径及任务目标；也可显式调用 `$aura-base-backend-development`。

示例：`$aura-base-backend-development 核对用户列表与 Excel 导出中的手机号是否都经过当前框架的脱敏链路。`

认证、授权和租户主流程由对应基础规范或能力包处理；本模块只读取命中的保护能力资料。
