# 公共支撑能力使用模块

统一响应、用户、权限、租户、缓存、日志、Feign 和存储等功能，直接从[公共支撑任务导航](references/研发任务导航.md)选择当前能力及示例。公共支撑是对应功能的复用基线；没有该功能的任务不加载或强装全部模块。

依赖和启动前提定位[使用规范](../../standards/05-能力包/01-通用工具类/03-基础通用支撑能力包/04-基础能力使用规范.md)的 `AURA-CAP-BASE-001/002/017～020`。内外 HTTP 响应使用同一 `R<T>` 和公共分页目标；公开 DTO、认证和数据裁剪不另造响应外壳。`@Idempotent` 等注解存在不证明拦截已生效，沿调用点和运行结果核实。

文件存储按[接入检查](checklists/capability-integration.md)核对实现、服务端对象键、业务/租户关联、读删权限、流关闭、补偿及签名 URL。`/oss/*` 或可注入 `FileTemplate` 不等于公开可用；实时任务另选文件与实时模块。未公开入口、未知版本或失败语义不得猜测，构建和联调分别报告。
