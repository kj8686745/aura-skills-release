# 后端能力使用索引

基础业务与公共支撑是 AURA 业务开发的复用基线：任务涉及数据访问、响应、身份、租户等对应功能时，先核对当前版本公开入口并复用，不能自行重建同类基础实现；不要求没有该功能的项目强装全部依赖。其余五个专项模块按需求引入。下列均为本技能内资料，不是独立安装项；模块不替代规范，也不证明能力已经运行生效。

| 场景 | 读取模块 | 不要误用 |
|---|---|---|
| Controller、Service、Mapper、基础实体与本地事务组成业务闭环 | [基础业务任务路由](capabilities/01-基础业务/references/任务路由.md) | 普通本地事务不自动引入跨服务事务 |
| 统一响应、当前用户、权限、租户、缓存、日志、Feign、对象存储与签名 URL | [公共支撑任务导航](capabilities/02-公共支撑/references/研发任务导航.md) | 文件存储不是文件任务或实时推送 |
| 动态数据源、分布式编号、跨服务事务可接入性 | [数据基础设施](capabilities/03-数据基础设施/能力入口.md) | 源码有模块不等于已公开可用 |
| 脱敏、XSS、实体字段保护和报文加密 | [数据安全](capabilities/04-数据安全/能力入口.md) | 数据保护不替代认证授权 |
| Excel、SSE、WebSocket、Socket.IO、组合文件任务 | [文件与实时](capabilities/05-文件与实时/能力入口.md) | Socket.IO 与原生 WebSocket 不是同一协议 |
| XXL-JOB 执行器、定时任务和调度结果 | [任务调度](capabilities/06-任务调度/能力入口.md) | 普通请求和消息消费不默认使用调度 |
| API 网关路由、灰度、限流及 Servlet/Feign 保护 | [网关流量](capabilities/07-网关流量/能力入口.md) | 流量控制不代替业务权限 |

一个需求可命中多个模块，但每个模块只选实际需要的能力。未收录、未核验或候选能力不能凭相似名称使用；明确指出契约或版本缺口。模块的来源版本记录在本技能 `references/source.json`，承载技能版本不代替能力包版本。
