# 缓存操作模板

本模板属于后端开发技能的缓存模块，用于把缓存的键、事实来源、TTL、失效和降级约定结构化。脚本只生成缓存常量骨架，不生成业务 Service、不把缓存当作数据库事实，也不自动推断写入后的失效时机。

## 缓存契约输入

```json
[
  {
    "enabled": true,
    "category": "query",
    "name": "DEVICE_DETAIL",
    "queryName": "selectByTenantAndDevice",
    "scopeFields": ["tenant_id", "device_id"],
    "keyPrefix": "aura:device:detail:",
    "ttlSeconds": 300,
    "scope": "tenant+deviceId",
    "source": "device database",
    "sourceCost": "four-table join, repeated by multiple APIs",
    "benefit": "reduce database QPS and endpoint P95",
    "measure": "hitRate, fallbackRate, databaseQps, p95",
    "staleness": "60s",
    "refreshMode": "on-demand",
    "onMiss": "query database and rebuild",
    "onFailure": "bypass cache and query database",
    "invalidation": "after transaction commit on update/delete"
  }
]
```

字段要求：

- `enabled`：是否启用缓存；未确认收益时使用 `false`，不生成缓存代码；
- `category`：`query`、`projection`、`state`、`auth`、`temporary`、`coordination` 之一；
- `name`：大写下划线常量名；
- `queryName`：`category=query` 时，必须指向实际查询方法；
- `scopeFields`：`category=query` 时，必须完整列出租户、组织和业务主键的数据库字段；
- `keyPrefix`：稳定前缀，禁止直接使用用户输入作为完整键；
- `ttlSeconds`：正整数；
- `scope`：必须说明租户、组织、用户或业务主键范围；
- `source`：缓存 miss 后的事实来源；
- `sourceCost`：未使用缓存时被消除的查询、计算或远程调用成本；
- `benefit`：预期消除的成本和业务收益；
- `measure`：用于验证收益的指标；
- `staleness`：允许的陈旧范围；
- `refreshMode`：`on-demand`、`event`、`scheduled` 或 `hybrid`；
- `onMiss`：缓存不存在时的回源行为；
- `onFailure`：缓存服务不可用时的降级行为；
- `invalidation`：写入、更新、删除后的失效或延迟同步策略。

## 生成内容

```text
src/main/java/<package>/cache/<CacheClass>.java
```

生成的类只保存缓存名称、键前缀和 TTL 常量。业务代码仍须在明确的适配器或 Service 中实现读取、回源、写入和失效，并按数据库事务边界核对提交后时序。

## 命令

```powershell
./scripts/prepare-cache-module.ps1 `
  -ProjectPath '<项目根>' `
  -ModulePath 'device-service' `
  -PackageName 'com.example.device' `
  -CacheClass 'DeviceCacheContract' `
  -CacheJson '<临时目录>/cache.json' `
  -Mode Plan
```

确认契约后将 `Plan` 改为 `Apply`。脚本不会覆盖已有文件；内容冲突返回 `blocked`。

## 必须人工完成

- 缓存是否只是加速边界，还是独立短期状态存储；
- 回源查询是否受权限、租户和组织范围约束；
- 数据库提交与缓存失效的先后关系；
- 失效失败、缓存不可用和并发更新时的处理；
- 序列化格式、敏感字段和容量上限；
- 正常命中、miss、过期、失效失败和回源失败验证。
