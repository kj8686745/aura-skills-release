# 交付验证

- [ ] TypeScript 与生产构建通过，或记录既有阻塞。
- [ ] 单路/多路真实流可播放，空 Source 显示自定义 `emptyText`。
- [ ] 单路业务请求显示动态空态文本，多路业务请求只显示整墙 Element Plus loading。
- [ ] 请求失败和无 Source 没有额外 ElMessage、toast、Notification 或弹窗；多路各通道能显示自己的 `channel.emptyText`。
- [ ] 错误流最终进入 error，不永久停在连接中。
- [ ] 首次无画面时显示可配置 `loadingText`；有上一帧时重连保留画面，预期 `play()` 中断不重复触发错误或重连。
- [ ] `buffer`、`buffer-change` 和直播延迟追赶符合配置。
- [ ] 音量、暂停、重播、回放进度和倍速正常。
- [ ] 截图、真实 MP4 录像、画面缩放与全屏符合 features。
- [ ] 缩放短按单步、长按连续；画面平移有边界，缩回 `1×` 自动回中。
- [ ] PTZ 按下发具体 direction，松开发 stop，连续点击限频正确。
- [ ] FLV/MPEG-TS 的 CodecUnsupported 已区分音频与视频；未错误建议用浏览器插件或系统 Codec Pack 扩展 MSE。
- [ ] 无音频、`hasAudio: false` 或自动音频降级后，不显示音量按钮和滑杆。
- [ ] 1/4/6/9/16 分屏顺序稳定，六分屏主画面正确。
- [ ] 拖拽只触发 reorder，布局切换不重建仍可见播放器。
- [ ] 多路放大后 `pan/window` 模式互斥，切换模式不依赖标题显示且不会误触发窗口换位。
- [ ] 普通点击单选，Ctrl 点击追加/取消；删除快捷键只在视频墙区域生效。
- [ ] 指定通道删除、选中通道删除和零通道空槽正常。
- [ ] 响应式窄窗口无工具栏溢出，控制台无新增错误。
