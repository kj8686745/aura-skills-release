# 验证清单

## 依赖验证

- [ ] `package.json` 中存在 `@fxft/ui-plus`，或已说明缺失并取得用户授权后安装。
- [ ] 未授权时没有执行安装命令。
- [ ] 包管理器与目标项目一致。

## Resolver 验证

- [ ] `vite.config.ts` 中存在 `FxftUiPlusResolver`，或目标项目已采用全量注册。
- [ ] `Components` resolver 未覆盖已有配置。
- [ ] `AutoImport` resolver 未覆盖已有配置。

## 代码验证

- [ ] 单路页面使用 `FxftVideoPlayer`。
- [ ] 多路页面使用 `FxftMultiVideoPlayer`。
- [ ] 没有绕过组件库封装底层播放器。
- [ ] TypeScript 类型检查通过，或已如实记录失败原因。
- [ ] 构建通过，或已如实记录失败原因。

## 浏览器验证

按实际业务验证：

- [ ] 单路视频能正常播放。
- [ ] 多路视频能正常播放。
- [ ] 直播 FLV 播放稳定，没有因为默认配置导致频繁重连或明显卡顿。
- [ ] `url` 为空时空态正常。
- [ ] 播放失败时错误态正常。
- [ ] 销毁、切换流、切换回放片段时不显示 `JbPro is destroyed` / `is destroyed`。
- [ ] 手动播放或重试行为正常。
- [ ] 录像 `playback-timestamp` 正常触发。
- [ ] 录像 `playback-stats` 正常触发。
- [ ] 录像 `playback-seek` 正常触发。
- [ ] 点播 `playVodTime` 正常触发，录像 `playback-timestamp` 正常触发。
- [ ] 自定义时间轴调用 `setPlayProgress(seconds)` 后视频进度正常跳转。
- [ ] PTZ 控制事件正常触发。
- [ ] 单窗口全屏正常。
- [ ] 多路整体全屏正常。
- [ ] 多路选中窗口状态正常。
- [ ] 多路拖拽换位正常。
- [ ] 拖拽后 `uuid` 和业务通道映射仍正确。
- [ ] 多路初始化、切分屏、隐藏后显示或播放新窗口后，底层 `video` / `canvas` 没有跑到容器顶部或使用旧尺寸。
- [ ] 控制台无新增错误。

## 交付回复

交付时必须包含：

1. 完成内容。
2. 使用的技能资料。
3. 依赖检查结果。
4. 组件接入方式。
5. 视频实现说明。
6. 状态处理说明。
7. 验证结果。
8. 剩余风险。
