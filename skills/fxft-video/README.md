# fxft-video

面向 `@fxft/ui-plus >= 1.1.2` 新版 Web 视频组件的业务开发技能。

- 单路：`FxftWebVideo`
- 多路：`FxftWebMultiVideo`
- 协议：native、HLS、FLV/MPEG-TS、WebRTC WHEP
- 内容类型：live、playback、vod
- 能力：缓冲与重连、截图、MP4 录像、画面缩放和平移、PTZ、1/4/6/9/16 分屏、拖拽、多选、通道移除和整体全屏

入口见 `SKILL.md`，完整 API 见 `references/video-component-guide.md`，示例见 `templates/`。
