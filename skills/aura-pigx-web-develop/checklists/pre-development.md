## 需求与页面模式

- [ ] 已列出页面、字段、接口、权限、状态、路由/菜单和验收项
- [ ] 新建正式业务页面、菜单入口或操作按钮时，已从路由/组件路径和 `v-auth` 生成页面菜单与按钮权限清单；清单按权限编码去重并记录每个编码的全部源码引用位置
- [ ] 用户明确指定的权限编码已原样纳入清单；未指定项已按“业务标识 + 功能动作”生成并对齐相邻模块的大小写、分隔符和动作词，未使用缺少业务限定的通用动作编码

- [ ] 菜单权限流程命中时，已读取 `references/admin-menu-permission-workflow.md`；已确认是否具备明确授权、环境、Token、租户和父菜单定位信息
- [ ] 已选择查询表格、查询卡片、左树右表、弹窗表单、详情/抽屉、看板或 Teleport 页面模式

- [ ] 已划分弹窗数据所有权：详情、候选项和业务列表在弹窗 `open` 流程加载，父页面只准备本次操作上下文
