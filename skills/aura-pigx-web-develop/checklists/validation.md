# 验证与交付清单

## 命令验证

- [ ] 使用当前项目规定的 Node.js 和 pnpm 版本
- [ ] build/typecheck 成功
- [ ] lint 成功或已记录已有警告
- [ ] 已运行 `scripts/check-project-rules.ps1 -ProjectPath <项目路径>`
- [ ] 无业务代码直接导入 Element Plus Message/MessageBox
- [ ] 无错误 `@/` 别名、业务 axios 实例、凭证或部署前缀硬编码
- [ ] 已处理注释覆盖扫描告警，或已记录告警不适用原因
- [ ] 需要撑满剩余高度的表格已人工确认 Flex 高度链路、`min-height: 0`、`el-table--fit` 和 `flex: 1` 生效，且未使用 `100vh` 或固定像素表格高度
- [ ] 新增或修改的普通 `el-select` 可按关键字筛选；不适用项有明确原因

## 页面与交互

- [ ] 页面结构符合所选最新版页面模式
- [ ] 已人工复核路由入口职责；不存在两个及以上业务 Dialog/Drawer 内联在入口页，轻量单弹窗内联有明确理由
- [ ] 加载态、空态、错误态或明确不适用说明完整
- [ ] 查询、重置、分页、排序、刷新和导出行为正确
- [ ] 权限、表单校验、防重复提交、成功和失败反馈正确
- [ ] 父子组件自定义事件及访问组件 ref 的事件绑定具名方法，组件公开方法只在脚本中通过可选链访问
- [ ] 新业务菜单权限流程命中时，页面菜单和每个 `v-auth` 按钮权限已按路径、组件和权限编码精确复核；按钮父级为真实页面菜单 ID
- [ ] 条件齐全时已重新查询 API 核验幂等写入；条件不足时已交付待补环境、授权、凭据、租户或父菜单信息，且没有外部写入
- [ ] 消息提示和确认框样式、i18n、取消分支正确
- [ ] 仅变更操作的失败分支使用 `useMessage().error(...)`；字典、下拉、列表、详情等只读加载失败不弹消息
- [ ] 页面卸载后无残留定时器、监听器、地图或播放器实例
- [ ] 浏览器控制台无新增错误，Network 无关键 404

## 模块联邦与资源

- [ ] 独立运行正常
- [ ] 作为远程页面运行正常
- [ ] expose、i18n、Tailwind、页面 CSS 和组件样式正确加载
- [ ] 图片、字体、Worker、decoder 和视频资源指向资源提供方
- [ ] 首次加载、刷新、失败重试和版本更新符合任务范围
- [ ] 模块联邦配置已提供检查技能改前基线与改后复检结果

## 接口联调

- [ ] URL、Method、入参和响应结构与接口定义一致
- [ ] 分页列表和总数字段与 `useTable` 配置一致
- [ ] Apifox/真实请求成功；无法联调的接口已注明原因
- [ ] 未把真实 Token、Cookie 或密码写入代码和交付文档

## 注释与编码

- [ ] 已按 `references/code-comment-guidelines.md` 逐项检查
- [ ] 按页面模式逐项核对注释锚点；查询卡片页的实际查询/筛选、工具栏、卡片列表、空态、分页区块均已覆盖
- [ ] 关键 Why、契约、边界、副作用和清理时机有中文注释
- [ ] 复杂条件、事件阻断和 `:deep()` 覆盖均已说明业务边界或原因
- [ ] 修改逻辑时同步更新或删除旧注释
- [ ] 新增文本为 UTF-8 无 BOM，无乱码

## 交付

1. **完成内容**：新增和修改文件。
2. **规范依据**：使用的最新版正式规范和页面模式。
3. **项目适配**：真实 Hook、组件、API、路由、模块联邦和命名映射。
4. **消息检查**：统一 Hook 与扫描结果。
5. **注释验收**：按页面模式列出注释位置、覆盖的 Why/契约/边界及告警处理结果。
6. **联调与验证**：接口、命令、浏览器、独立/远程结果。
7. **剩余风险**：未验证接口、权限、远程环境、依赖或部署项。
