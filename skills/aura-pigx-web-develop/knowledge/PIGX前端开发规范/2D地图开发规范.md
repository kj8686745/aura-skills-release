# 2D 地图开发规范

## 一、强制规则

- 2D 地图统一使用 `@fxft/ui-plus` 的 `FxftMap`。
- 禁止业务自行引入高德、百度、Mapbox、OpenLayers等 SDK绕过组件库。
- 优先使用公开 Props、Events和Exposes；不得依赖底层地图私有字段。
- 坐标渲染前统一归一化为 `{ lon, lat }` 并过滤非法范围。
- 点位使用稳定业务 `id`，图层名必须有业务语义。

组件接入见[组件复用与公司 UI 规范](./组件复用与公司基础组件库规范.md)。

## 二、基础页面

```vue
<template>
	<div class="layout-padding">
		<div class="layout-padding-auto layout-padding-view map-page">
			<FxftMap
				ref="mapRef"
				:center="{ lon: 119.3052, lat: 26.07 }"
				:zoom="12"
				:show-layer-switcher="true"
				:show-map-tool="true"
				@load="onMapLoad"
				@map-click="onMapClick"
			/>
		</div>
	</div>
</template>

<script setup lang="ts">
const mapRef = ref<any>();

const onMapLoad = () => {
	// 地图已就绪后再渲染点位、轨迹或图形。
};

const onMapClick = (event: unknown) => {
	console.log('地图点击', event);
};
</script>

<style scoped>
.map-page {
	width: 100%;
	height: 100%;
	min-height: 480px;
}
</style>
```

地图父容器必须有明确高度。业务页位于综合端内容区时不要使用 `100vh`。

## 三、坐标归一化

```ts
const getNumberValue = (...values: unknown[]) => {
	const value = values.find((item) => Number.isFinite(Number(item)));
	return value === undefined ? undefined : Number(value);
};

const normalizeCoordinate = (item: any) => {
	const lon = getNumberValue(item.lon, item.lng, item.longitude);
	const lat = getNumberValue(item.lat, item.latitude);

	if (lon === undefined || lat === undefined) return null;
	if (lon < -180 || lon > 180 || lat < -90 || lat > 90) return null;
	return { lon, lat };
};
```

坐标顺序统一为经度、纬度。禁止把 `[lat, lon]` 直接传入地图。

## 四、点位和聚合

```ts
import deviceIconSource from '/@/assets/images/map/device.png';
import { getStaticResourceUrl } from '/@/hooks/moduleFederation';

const deviceMarkerLayer = 'deviceMarkerLayer';
const deviceIcon = getStaticResourceUrl(deviceIconSource);

const renderDevicePoints = (rows: any[], clear = true) => {
	const points = rows
		.map((item) => {
			const coordinate = normalizeCoordinate(item);
			return coordinate
				? {
					id: item.id,
					...coordinate,
					icon: deviceIcon,
					customData: item,
				}
				: null;
		})
		.filter(Boolean);

	mapRef.value?.addPoint?.(
		points,
		{
			cluster: true,
			clear,
			enableClick: true,
			maxClusterZoom: 16,
			markerWidth: 36,
			markerHeight: 36,
		},
		deviceMarkerLayer
	);
};

const removeDevicePoint = (id: string | number) => {
	mapRef.value?.clearPointById?.(id, deviceMarkerLayer);
};
```

- 单个或少量点位删除使用 `clearPointById`。
- 追加数据使用 `{ clear: false }`。
- 只有整体数据源或聚合配置变化时才使用 `{ clear: true }` 或 `clearLayer`。
- 不使用时间戳或随机数作为会变化的点位 ID。

## 五、轨迹回放

```ts
import movingIconSource from '/@/assets/images/map/vehicle.png';
import startIconSource from '/@/assets/images/map/track-start.png';
import endIconSource from '/@/assets/images/map/track-end.png';

const vehicleTrackLayer = 'vehicleTrackLayer';

const renderTrack = (rows: any[]) => {
	const points = rows
		.map((item) => {
			const coordinate = normalizeCoordinate(item);
			return coordinate ? { ...coordinate, time: item.time, speed: item.speed } : null;
		})
		.filter(Boolean);

	if (points.length < 2) {
		mapRef.value?.clearTrack?.();
		return;
	}

	mapRef.value?.playTrack?.(
		points,
		{
			playNow: false,
			fit: true,
			lineColor: '#409EFF',
			icon: getStaticResourceUrl(movingIconSource),
			startIcon: getStaticResourceUrl(startIconSource),
			endIcon: getStaticResourceUrl(endIconSource),
		},
		vehicleTrackLayer
	);
};

const showTrack = () => mapRef.value?.showTrackLayer?.();
const hideTrack = () => mapRef.value?.hideTrackLayer?.();
const seekTrack = (progress: number) => mapRef.value?.setTrackProgress?.(progress);
```

- 过滤后少于两个有效点时不调用 `playTrack`。
- 时间轴使用 `track-progress` 的 `currentTime`、`startTime`、`endTime`。
- 按距离控制使用 `distanceProgress` 和 `setTrackProgress(0~100)`。
- 显隐使用 `showTrackLayer`、`hideTrackLayer`，不要清空后重绘。
- 只切换采样点使用 `setTrackPointsVisible`。
- 必须显式传入业务图标，不依赖组件内部默认外部地址。

## 六、热力图

```ts
const alarmHeatLayer = 'alarmHeatLayer';

const heatPoints = rows
	.map((item) => {
		const coordinate = normalizeCoordinate(item);
		const value = getNumberValue(item.value, item.count, item.weight);
		return coordinate && value !== undefined
			? [coordinate.lon, coordinate.lat, value]
			: null;
	})
	.filter(Boolean);

if (heatPoints.length) {
	mapRef.value?.setHeat?.(heatPoints, { radius: 18, max: 100 }, alarmHeatLayer);
} else {
	mapRef.value?.clearLayer?.(alarmHeatLayer);
}
```

热力点必须同时有经度、纬度和数值权重；无有效数据时先清理并显示空态。

## 七、绘制、GeoJSON和图层定位

```ts
const fenceDrawLayer = 'fenceDrawLayer';
const districtGeoJSONLayer = 'districtGeoJSONLayer';

const startFenceDraw = () => mapRef.value?.startDraw?.('polygon', fenceDrawLayer);
const stopFenceDraw = () => mapRef.value?.stopDraw?.();
const resetFenceDraw = () => mapRef.value?.resetDraw?.();

const renderDistrict = (geojson: any) => {
	if (!geojson || typeof geojson.type !== 'string') return;
	mapRef.value?.renderGeoJSON?.(
		geojson,
		{ clear: true, fitView: true, flyTo: true },
		districtGeoJSONLayer
	);
};

const locateFence = () =>
	mapRef.value?.flyToLayer?.(fenceDrawLayer, { zoomOffset: -1, duration: 700 });

const exportMap = () => mapRef.value?.exportImage?.({ mimeType: 'image/png' });
```

- 交互绘制使用 `startDraw`，API绘制使用 `drawByType`。
- `stopDraw` 结束当前绘制；需要彻底丢弃 DrawTool状态时使用 `resetDraw`。
- 继续编辑已有 GeoJSON 使用 `initDraw`；只读展示使用 `renderGeoJSON`。
- GeoJSON 至少校验 `type`、坐标数组和 `[lon, lat]` 顺序。
- `fitLayer`、`flyToLayer` 在图层不存在或无有效范围时会返回 `false`。

## 八、故障排查

| 现象 | 优先检查 |
| --- | --- |
| 地图空白 | 父容器高度、组件库样式、地图资源请求、控制台错误 |
| 点位不显示 | 坐标范围、经纬度顺序、图标 URL、图层是否被隐藏 |
| 删除点位无效 | 删除 ID是否与添加时稳定 ID完全一致、图层名是否一致 |
| 轨迹无法创建 | 有效点是否不少于2个、时间和坐标是否可解析 |
| 远程页面图标404 | import 图标是否经过 `getStaticResourceUrl` |
| GeoJSON不显示 | `type`、coordinates、坐标顺序和目标图层 |
| 导出为空 | 地图是否加载完成、底图是否受跨域 Canvas限制 |

## 九、检查清单

- [ ] 已安装批准版本的 `@fxft/ui-plus` 并配置 resolver。
- [ ] 页面使用 `FxftMap`，未引入其他地图 SDK。
- [ ] 父容器高度有效，未使用 `100vh` 抢占布局。
- [ ] 坐标已归一化和过滤。
- [ ] 点位 ID稳定，图层名有业务语义。
- [ ] 单点删除未通过整层重绘实现。
- [ ] 轨迹至少两个点，图标已做远程资源转换。
- [ ] 热力点包含权重。
- [ ] GeoJSON渲染前已校验。
- [ ] 独立运行和远程运行均无资源404和样式缺失。
