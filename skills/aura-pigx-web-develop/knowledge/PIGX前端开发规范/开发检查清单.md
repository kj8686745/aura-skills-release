# PIGX 前端开发检查清单

## 一、公共检查

- [ ] Node.js、pnpm版本符合模板要求，使用 `pnpm install --frozen-lockfile`。
- [ ] 新项目已替换 `pigx-nexus`、`pigxNexus`，`remoteName`、`remoteEntryName`、`systemId` 唯一。
- [ ] 文件、变量和路由名称具有业务语义。
- [ ] 中文文档、注释、提示为 UTF-8 无 BOM，无乱码。
- [ ] 项目内部路径使用 `/@/`。
- [ ] 请求统一使用 `/@/utils/request`，没有业务 axios实例。
- [ ] 没有域名、IP、Token、Cookie、密码和部署前缀硬编码。
- [ ] Vue、Vue Router、Vue I18n、Pinia保持 Module Federation singleton。
- [ ] Element Plus作为本地依赖，未加入 Module Federation shared。

```bash
rg "pigx-nexus|pigxNexus" src .env* package.json vite.config.mts postcss.config.js README.md
rg "@originjs|top-level-await|axios\.create" package.json vite.config.mts src
```

## 二、页面检查

- [ ] 页面结构与对应页面模式一致。
- [ ] 路由页模板仅有一个真实元素根节点：根元素使用 `class="layout-padding"`，业务区域使用 `class="layout-padding-auto layout-padding-view"`；Dialog、Drawer 等弹窗可与业务区域并列置于根节点下；复用列表页组件时已确认其真实根元素遵循此结构。
- [ ] 加载态、空态、错误态完整。
- [ ] 按钮使用正确权限标识。
- [ ] 表单有校验、提交防重复、成功和失败反馈。
- [ ] 列表使用 `useTable`，绑定 `tableStyle`，按需配置 `tableAlign`。
- [ ] 查询、重置、分页、排序、刷新行为正确。
- [ ] 使用主题 CSS变量，无大面积硬编码主题色。
- [ ] Flex高度链路完整，子项滚动区域有 `min-height: 0`。
- [ ] 页面卸载后清理定时器、监听器和业务实例。

## 三、静态资源检查

- [ ] import图片、SVG、视频等使用 `getStaticResourceUrl`。
- [ ] public资源使用 `getPublicResourceUrl`。
- [ ] CSS `url()` 使用可由 Vite重写的相对路径，或改用动态样式。
- [ ] 没有硬编码 `/assets/`、`/pigxNexus` 等根路径。
- [ ] 独立运行和远程运行均无图片、字体、Worker、播放器资源404。

```bash
rg "from '/@/assets|/assets/|url\('/" src
```

## 四、模块联邦提供方

- [ ] `remoteName`、`remoteEntryName`、`systemId` 唯一且职责未混用。
- [ ] expose key与真实文件路径一致。
- [ ] 页面、组件、API和工具出现在 `mf-manifest.json`。
- [ ] 后端菜单等于 `remoteName + expose key + ?type=moduleFederation`。
- [ ] `i18nScanDirs` 覆盖对外业务语言包。
- [ ] `./i18n/langs` 和 `./styles/moduleFederationTailwind.ts` expose存在。
- [ ] Tailwind scope与 `remoteName` 一致，不污染宿主。
- [ ] `remoteEntry.js`、`mf-manifest.json`、JS和CSS产物完整。
- [ ] 首次加载、刷新、版本更新和失败重试均正常。

```bash
rg "views/order/list/index.vue|i18n/langs|moduleFederationTailwind" dist/mf-manifest.json
```

## 五、模块联邦消费方

- [ ] 远程名称已加入 `moduleFederationRemoteNames`。
- [ ] 入口已加入 `moduleFederationRemoteEntries`。
- [ ] 环境变量与真实部署地址一致。
- [ ] 开发代理前缀等于提供方 `remoteEntryName`。
- [ ] 菜单第一段等于提供方 `remoteName`。
- [ ] 动态菜单没有误加编译期 remote。
- [ ] 源码直接消费远程模块时，已增加编译期 remote 和 TypeScript 声明。
- [ ] 模板使用的远程 Vue 组件已通过 `defineAsyncComponent` 和动态 import 引入，没有静态默认导入。
- [ ] 远程 i18n、Tailwind和页面CSS加载成功。
- [ ] 加载失败只影响当前内容区，重试能刷新缓存。

Network应出现类似：

```text
/auraOrderWeb/mf-manifest.json
/auraOrderWeb/remoteEntry.js
/auraOrderWeb/assets/远程页面.js
/auraOrderWeb/assets/远程页面.css
```

## 六、公司基础组件库

- [ ] 已阅读[公司组件库下载与权限配置说明](./公司组件库下载说明/README.md)。
- [ ] `.npmrc` 位于项目根或用户目录，不只存在于文档目录。
- [ ] 项目根配置优先于用户级同名配置；已有文件采用合并而非覆盖。
- [ ] 公司私服 `.npmrc` 仅在内部项目和员工环境中使用，未对外分发。
- [ ] `pnpm config get @fxft:registry` 返回公司 `npm-public` 地址。
- [ ] `pnpm info @fxft/ui-plus` 或 `npm view @fxft/ui-plus` 查询成功。
- [ ] 使用批准的固定 `@fxft/ui-plus` 版本。
- [ ] resolver合并而非覆盖已有 Vite配置。
- [ ] 远程页面不只依赖 `main.ts` 全局注册。
- [ ] 组件样式随 expose加载。
- [ ] 只调用组件文档公开 API。
- [ ] 私有 registry只用于安装，不进入运行时代码。

## 七、2D 地图

- [ ] 使用 `FxftMap`，未自行接入其他地图 SDK。
- [ ] 地图容器有有效高度。
- [ ] 坐标归一化为 `{ lon, lat }` 并过滤非法值。
- [ ] 点位ID稳定，图层名有业务语义。
- [ ] 少量点位删除使用 `clearPointById`。
- [ ] 轨迹有效点不少于2个，显隐未通过清空重绘实现。
- [ ] 轨迹图标经过 `getStaticResourceUrl`。
- [ ] 热力点包含权重，GeoJSON渲染前已校验。
- [ ] 点位、轨迹、热力、绘制、导出按需求通过浏览器验证。

## 八、单路视频

- [ ] 使用 `FxftVideoPlayer`。
- [ ] `live`、`record`、`vod` 选择正确。
- [ ] script和decoder使用生产自托管路径，并经过 `getPublicResourceUrl`。
- [ ] URL为空时空态正常，失败时错误态和重试正常。
- [ ] PTZ事件只做轻量参数转发。
- [ ] 点播进度监听 `playVodTime`，录像监听 `playback-timestamp`。
- [ ] 主动跳转使用 `setPlayProgress`。
- [ ] 切换URL、模式、销毁和重建无旧实例错误。

## 九、多路视频

- [ ] 使用 `FxftMultiVideoPlayer`。
- [ ] 每个窗口有稳定 `uuid` 或业务ID。
- [ ] 拖拽业务未把 `index` 当长期稳定键。
- [ ] 单窗口错误不影响其他窗口。
- [ ] 单窗全屏和整体全屏已区分。
- [ ] 分屏使用 `arrangeWindow`，未操作内部DOM。
- [ ] 弹窗、标签页或折叠区显示后调用 `resize()`。
- [ ] 播放、暂停、拖拽、全屏、销毁和尺寸重算通过验证。
