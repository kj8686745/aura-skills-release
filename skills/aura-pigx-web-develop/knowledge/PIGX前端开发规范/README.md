## 规范优先级

发生冲突时按以下顺序执行：

1. 当前模块联邦（综合端）源码和类型定义。
2. 本目录专项规范。
3. 页面模式和参考样例。
4. 历史项目写法。

历史项目代码只能作为业务参考，不能覆盖新模板的模块联邦、静态资源、请求、主题和组件接入规则。

## 强制原则

- 新项目创建后必须替换 `pigx-nexus`、`pigxNexus`，且部署环境内名称不可重复。
- 业务请求统一使用 `/@/utils/request`，不得直接创建 axios 实例。
- 远程菜单路径第一段使用提供方 `remoteName`。
- import 静态资源使用 `getStaticResourceUrl`，public 资源使用 `getPublicResourceUrl`。
- 2D 地图使用 `FxftMap`；单路和多路视频分别使用 `FxftVideoPlayer`、`FxftMultiVideoPlayer`。
- 中文文档、注释和提示使用 UTF-8 无 BOM。
