# 样式、布局与静态资源规范

## 一、页面高度链路

业务页面处于 `aura-core` 布局内容区，禁止直接使用 `height: 100vh` 抢占整个浏览器高度。标准页面使用 Flex 占满路由内容区：

```vue
<template>
	<div class="page-container">
		<section class="query-panel">...</section>
		<section class="content-panel">
			<div class="toolbar">...</div>
			<div class="table-wrap">...</div>
			<Pagination v-bind="state.pagination" />
		</section>
	</div>
</template>

<style scoped lang="scss">
.page-container {
	display: flex;
	flex: 1;
	flex-direction: column;
	gap: 12px;
	width: 100%;
	height: 100%;
	min-height: 0;
}

.content-panel,
.table-wrap {
	display: flex;
	flex: 1;
	min-height: 0;
}

.content-panel {
	flex-direction: column;
}

.table-wrap :deep(.el-table) {
	flex: 1;
}
</style>
```

Flex 子项需要滚动时通常必须设置 `min-height: 0`；不要通过固定像素高度适配不同分辨率。

## 二、主题和颜色

使用 Element Plus 和模块联邦（综合端）主题变量：

```scss
.order-card {
	color: var(--el-text-color-primary);
	background: var(--el-bg-color);
	border: 1px solid var(--el-border-color-light);
}

.order-card:hover {
	border-color: var(--el-color-primary);
}
```

禁止把主题色、正文色、边框色大面积硬编码为 `#409eff`、`#333`、`#ddd`。业务状态色可按设计使用，但应集中定义并同时适配暗色背景。

## 三、表格统一样式

```ts
const state = reactive<BasicTableProps>({
	pageList: getOrderPage,
	tableAlign: {
		name: 'left',
		amount: 'right',
	},
});

const { tableStyle } = useTable(state);
```

```vue
<el-table
	:cell-style="tableStyle.cellStyle"
	:header-cell-style="tableStyle.headerCellStyle"
>
</el-table>
```

`useTable` 默认居中，`tableAlign` 以 `el-table-column` 的 `prop` 为键覆盖单列。不要在每个页面重复实现表头背景和对齐回调。

## 四、模块联邦样式

远程运行不会加载提供方 `index.html`，因此：

- 页面自身 CSS 必须随 expose 出现在 `mf-manifest.json`。
- Tailwind 通过标准 `./styles/moduleFederationTailwind.ts` expose 加载。
- PostCSS 和 Tailwind 根节点必须使用当前 `remoteName` 对应 scope。
- 宿主不扫描远程源码生成 Tailwind。
- 业务全局选择器必须谨慎，禁止无 scope 重置 `body`、`html`、`.el-*`。

订单综合端示例：

```js
const REMOTE_SCOPE = '.aura-mf-remote-scope.aura-mf-remote-aura-order-web';
```

```css
.aura-mf-remote-scope.aura-mf-remote-aura-order-web {
	width: 100%;
	height: 100%;
	min-height: 100%;
}
```

## 五、import 静态资源

图片、SVG、视频等 import 结果在用于模板、配置或动态样式前必须转换：

```ts
import orderBannerSource from '/@/assets/images/order/banner.png';
import { getStaticResourceUrl } from '/@/hooks/moduleFederation';

const orderBanner = getStaticResourceUrl(orderBannerSource);
```

```vue
<img :src="orderBanner" alt="订单中心" />
```

动态背景：

```ts
const bannerStyle = {
	backgroundImage: `url(${getStaticResourceUrl(orderBannerSource)})`,
};
```

错误：

```vue
<img src="/assets/images/order/banner.png" alt="订单中心" />
```

远程运行时错误写法会请求宿主 `/assets`，造成 404 或加载到同名错误资源。

## 六、public 资源

Worker、播放器脚本、decoder、独立字体等 public 根路径资源使用：

```ts
import { getPublicResourceUrl } from '/@/hooks/moduleFederation';

const workerUrl = getPublicResourceUrl('/workers/order-worker.js');
const decoderPath = getPublicResourceUrl('/jessibucaPro/decoder-pro-simd.js');
```

外部绝对 URL、`data:`、`blob:` 等特殊协议不会补远程前缀，但生产代码仍不得写死临时域名、IP或凭证。

CSS `url()` 优先使用可由 Vite 重写的相对资源；需要运行时远程前缀时改用组件动态样式。

## 七、常见容器

- 查询表格页：查询区固定、表格区 `flex: 1`、分页置底。
- 左树右表页：左右面板自身 `min-width: 0; min-height: 0`，避免内容撑破。
- 弹窗和抽屉：内容区滚动，底部操作区固定；不让整个页面背景滚动。
- 看板页：使用网格和比例布局，图表在容器尺寸变化后调用组件公开的 resize 能力。
- 地图和视频：父容器必须有明确可用高度，隐藏后显示的多路视频另见视频专项。

## 八、检查命令

```bash
rg "from '/@/assets|/assets/|url\('/" src
rg "pigxNexus|auraIotbusWeb|https?://[0-9]" src
```

第一条用于发现候选项；资源 import 本身允许存在，但展示位置必须经过转换。
