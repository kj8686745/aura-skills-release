# 页面模式：查询卡片页

> 本模式必须同时遵守[工程与代码生成规范](../工程与代码生成规范.md)、[样式布局与静态资源规范](../样式布局与静态资源规范.md)和[开发检查清单](../开发检查清单.md)。卡片图片和图标必须按模块联邦静态资源规则转换。

## 适用场景

- 顶部有筛选条件，主体为卡片列表（非表格）
- 卡片通常带状态标签、快捷操作按钮
- 适合展示应用列表、模板列表、资源卡片等

---

## 页面结构

```
layout-padding
└── layout-padding-auto layout-padding-view
    ├── 查询区（el-form inline）
    ├── 工具栏（新增按钮等）
    └── 卡片列表区
        └── el-row :gutter="20"
            └── el-col（循环）
                └── el-card
                    ├── 卡片头部（标题 + 状态标签）
                    ├── 卡片主体（关键信息字段）
                    └── 卡片底部（操作按钮）
分页（Pagination）或 loadmore
```

---

## 必须遵循

- 卡片数据仍然通过 `useTable` 管理（设置 `isPage: true` 配合 `Pagination`）
- 当数据量不大时，也可以设置 `isPage: false` 一次加载全部
- 卡片内按钮权限同样使用 `v-auth`
- 状态标签使用 `dict-tag` 或 `el-tag`，保持与表格列一致的风格

---

## 推荐写法

### 卡片列表区骨架

```vue
<template>
  <div class="layout-padding">
    <div class="layout-padding-auto layout-padding-view">
      <!-- 查询区 -->
      <el-row v-show="showSearch">
        <el-form :inline="true" :model="state.queryForm" @keyup.enter="getDataList">
          <el-form-item label="名称" prop="name">
            <el-input v-model="state.queryForm.name" style="max-width: 180px" />
          </el-form-item>
          <el-form-item>
            <el-button @click="getDataList" icon="search" type="primary">{{ $t('common.queryBtn') }}</el-button>
            <el-button @click="resetQuery" icon="Refresh">{{ $t('common.resetBtn') }}</el-button>
          </el-form-item>
        </el-form>
      </el-row>

      <!-- 工具栏 -->
      <div class="mb8 flex justify-between">
        <el-button v-auth="'xxx_add'" @click="formDialogRef.openDialog()" icon="folder-add" type="primary">
          {{ $t('common.addBtn') }}
        </el-button>
        <right-toolbar
          v-model:showSearch="showSearch"
          @queryTable="getDataList"
          style="margin-right: 20px"
        />
      </div>

      <!-- 卡片列表 -->
      <div v-loading="state.loading">
        <el-row :gutter="20">
          <el-col
            v-for="item in state.dataList"
            :key="item.id"
            :xs="24" :sm="12" :md="8" :lg="6"
            class="mb20"
          >
            <el-card shadow="hover" class="card-item">
              <template #header>
                <div class="card-header">
                  <span class="card-title">{{ item.name }}</span>
                  <dict-tag :options="status_dict" :value="item.status" />
                </div>
              </template>
              <div class="card-body">
                <div class="card-field">
                  <span class="label">创建时间：</span>
                  <span>{{ item.createTime }}</span>
                </div>
                <div class="card-field">
                  <span class="label">描述：</span>
                  <span>{{ item.remark }}</span>
                </div>
              </div>
              <template #footer>
                <div class="card-actions">
                  <el-button size="small" text type="primary" v-auth="'xxx_edit'"
                    @click="formDialogRef.openDialog(item.id)">编辑</el-button>
                  <el-button size="small" text type="danger" v-auth="'xxx_del'"
                    @click="handleDelete([item.id])">删除</el-button>
                </div>
              </template>
            </el-card>
          </el-col>
        </el-row>

        <!-- 空状态 -->
        <el-empty v-if="!state.loading && state.dataList?.length === 0" description="暂无数据" />
      </div>

      <!-- 分页 -->
      <pagination @current-change="currentChangeHandle" @size-change="sizeChangeHandle" v-bind="state.pagination" />
    </div>

    <form-dialog @refresh="getDataList()" ref="formDialogRef" />
  </div>
</template>

<script lang="ts" name="ModuleCardPage" setup>
import { BasicTableProps, useTable } from '/@/hooks/table';
import { fetchList, delObj } from '/@/api/module/xxx';
import { useMessage, useMessageBox } from '/@/hooks/message';
import { useDict } from '/@/hooks/dict';
import { useI18n } from 'vue-i18n';

const FormDialog = defineAsyncComponent(() => import('./form.vue'));
const { t } = useI18n();
const { status_dict } = useDict('status_dict');

const formDialogRef = ref();
const showSearch = ref(true);

const state: BasicTableProps = reactive<BasicTableProps>({
  queryForm: {},
  pageList: fetchList,
});

const { getDataList, currentChangeHandle, sizeChangeHandle, tableStyle } = useTable(state);

const resetQuery = () => getDataList();

const handleDelete = async (ids: string[]) => {
  try {
    await useMessageBox().confirm(t('common.delConfirmText'));
  } catch {
    return;
  }
  try {
    await delObj(ids);
    getDataList();
    useMessage().success(t('common.delSuccessText'));
  } catch (err: any) {
    useMessage().error(err.msg);
  }
};
</script>

<style scoped>
.card-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
.card-title {
  font-weight: bold;
  font-size: 14px;
}
.card-field {
  margin-bottom: 8px;
  font-size: 13px;
  color: var(--el-text-color-regular);
}
.card-field .label {
  color: var(--el-text-color-secondary);
}
.card-actions {
  display: flex;
  gap: 8px;
}
</style>
```

## 常见拆分方式

- `index.vue` — 卡片列表页主体
- `form.vue` — 新增/编辑弹窗（同弹窗表单规范）
- `api/xxx.ts` — 数据接口

---

## 生成提示输入建议

生成卡片页时需明确：

- 卡片内展示哪些字段
- 每行显示几列（`el-col` 响应式比例）
- 是否需要分页或无限滚动
- 卡片点击行为（打开弹窗/跳转详情）
