# 页面模式：左树右表页

> 本模式必须同时遵守[工程与代码生成规范](../工程与代码生成规范.md)、[样式布局与静态资源规范](../样式布局与静态资源规范.md)和[开发检查清单](../开发检查清单.md)。左右容器都需要 `min-width: 0`、`min-height: 0`，避免内容撑破综合端布局。

## 适用场景

- 页面左侧为树形结构（分类/组织/字典类型等），右侧为对应的表格或内容
- 点击树节点后，右侧内容跟随切换
- 典型业务：字典管理、机构管理、权限管理等

---

## 页面结构

```
layout-padding
└── splitpanes（水平分割）
    ├── pane（左侧，固定宽度 ~320px）
    │   └── layout-padding-auto layout-padding-view
    │       ├── 顶部操作按钮（新增/刷新缓存等）
    │       ├── el-scrollbar
    │       │   └── query-tree（树形查询组件）
    │       └── el-footer（导出/其他全局操作）
    └── pane（右侧，flex-1）
        ├── XxxDialog（新增/编辑弹窗）
        └── XxxList / XxxTable（右侧内容区）
```

---

## 必须遵循

- 布局使用 `Splitpanes` + `Pane` 组件（已全局注册，无需 import）
- 左侧树使用 `QueryTree` 全局组件（已全局注册）
- 左侧固定宽度用 `style="flex-basis: 320px"` 控制
- 右侧使用 `class="ml8 flex-1"` 保持自适应
- 树节点点击通过 `@node-click` 事件通知右侧组件刷新
- 右侧内容组件用 `ref` 控制，通过暴露方法（如 `open(data)`）接收左侧数据
- 弹窗（新增/编辑）放在右侧 pane 内，通过 `@refresh` 事件触发树刷新

## 推荐写法

### index.vue 完整骨架

```vue
<template>
  <div class="layout-padding">
    <splitpanes>
      <pane>
        <splitpanes>
          <!-- 左侧树 -->
          <pane style="flex-basis: 320px">
            <div class="layout-padding-auto layout-padding-view">
              <div class="flex justify-between">
                <el-button @click="dialogRef.openDialog()" icon="folder-add" type="primary">
                  {{ $t('common.addBtn') }}
                </el-button>
              </div>
              <el-scrollbar class="mt8">
                <query-tree
                  ref="treeRef"
                  :query="state.queryList"
                  @node-click="handleNodeClick"
                  placeholder="请输入搜索关键词"
                >
                  <template #default="{ data }">
                    <span class="custom-tree-node">
                      <span class="label">{{ data.name }}</span>
                      <span class="do">
                        <el-button-group>
                          <el-button icon="edit" size="small" @click.stop="dialogRef.openDialog(data.id)" />
                          <el-button icon="delete" size="small" @click.stop="handleDelete([data.id])" />
                        </el-button-group>
                      </span>
                    </span>
                  </template>
                </query-tree>
              </el-scrollbar>
            </div>
          </pane>

          <!-- 右侧内容 -->
          <pane class="ml8 flex-1">
            <xxx-dialog @refresh="handleRefreshTree" ref="dialogRef" />
            <xxx-list ref="listRef" />
          </pane>
        </splitpanes>
      </pane>
    </splitpanes>
  </div>
</template>

<script lang="ts" name="ModulePageName" setup>
import { delObj, fetchList } from '/@/api/module/xxx';
import { useMessage, useMessageBox } from '/@/hooks/message';
import { useI18n } from 'vue-i18n';

const XxxDialog = defineAsyncComponent(() => import('./form.vue'));
const XxxList = defineAsyncComponent(() => import('./list/index.vue'));

const { t } = useI18n();
const dialogRef = ref();
const treeRef = ref();
const listRef = ref();

const state = reactive({
  queryList: (keyword?: string) => fetchList({ name: keyword }),
});

// 点击树节点，通知右侧刷新
const handleNodeClick = (data: any) => {
  listRef.value?.open(data);
};

// 弹窗保存后刷新树（并重新选中当前节点）
const handleRefreshTree = async (data: any) => {
  await treeRef.value?.getdeptTree();
  handleNodeClick(data);
};

// 删除树节点
const handleDelete = async (ids: string[]) => {
  try {
    await useMessageBox().confirm(t('common.delConfirmText'));
  } catch {
    return;
  }
  try {
    await delObj(ids);
    useMessage().success(t('common.delSuccessText'));
    treeRef.value?.getdeptTree();
  } catch (err: any) {
    useMessage().error(err.msg);
  }
};
</script>

<style scoped>
.custom-tree-node {
  display: flex;
  flex: 1;
  align-items: center;
  justify-content: space-between;
  font-size: 14px;
  padding-right: 24px;
  height: 100%;
}
.custom-tree-node .do {
  display: none;
}
.custom-tree-node:hover .do {
  display: inline-block;
}
</style>
```

### QueryTree 组件接口

```typescript
// props
query: (keyword?: string) => Promise<any>   // 树数据加载函数

// events
@node-click="(data) => void"               // 节点点击回调

// methods (通过 ref 调用)
treeRef.value?.getdeptTree()               // 刷新树
```

## 常见拆分方式

- `index.vue` — 左树右布局容器
- `form.vue` — 新增/编辑弹窗（同弹窗表单规范）
- `list/index.vue` 或直接作为独立组件 — 右侧内容（可以是表格、卡片等）
- `api/xxx.ts` — 树数据和右侧内容的接口
