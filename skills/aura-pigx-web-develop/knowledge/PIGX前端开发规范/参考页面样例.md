# 参考页面样例

## 说明

本文档列出 PIGX 项目中已验证的页面模式，每个样例说明其页面类型和关键实现要点。

生成新页面时，找到与目标原型最相似的样例，按其关键要点对应的规范生成代码。

示例描述不能替代专项规范；实际代码必须以当前模块联邦（综合端）源码、组件类型和本目录检查清单为准。

---

## 样例 1：标准查询表格页（含弹窗表单）

**页面类型：** query-table + dialog-form

**关键要点：**

- 使用 `useTable` 管理分页查询
- `RightToolbar` 右侧工具栏（显示/隐藏搜索、导出）
- `DictTag` 渲染字典值
- `v-auth` 按钮权限控制
- `defineAsyncComponent` 异步引入弹窗
- `form.vue` 使用 `defineExpose({ openDialog })` + `emit('refresh')` 模式
- `el-collapse` 折叠高级属性区（可选）

---

## 样例 2：只读查询表格页（无编辑，仅删除）

**页面类型：** query-table（read-heavy）

**关键要点：**

- 无新增/编辑弹窗
- 使用 `sortChangeHandle` 支持列排序
- 批量删除使用 `selectObjs` + `multiple` 控制

---

## 样例 3：左树右表页

**页面类型：** left-tree-right-table

**关键要点：**

- `Splitpanes` + `Pane` 分割布局
- `QueryTree` 组件实现树形搜索
- 树节点点击通过 `@node-click` 事件通知右侧
- 右侧子组件通过 `ref` + 暴露方法接收数据
- 悬停显示操作按钮（`.do { display: none }` + `:hover .do { display: inline-block }`）

---

## 样例 4：复杂弹窗表单（含联动字段 + 折叠区）

**页面类型：** dialog-form（complex）

**关键要点：**

- `v-if` 控制联动字段显示（如 `v-if="form.authorizedGrantTypes.includes('authorization_code')"`）
- `el-collapse` 包裹高级/安全属性
- `el-input-number`、`el-radio-group`、`el-select` 多种表单控件混合使用
- `rule.overLength`、`rule.validatorLowercase` 等自定义校验器

---

## 样例 5：代码生成器页（含子组件拆分）

**页面类型：** complex-list（多子组件组合）

**关键要点：**

- 多个子组件按功能拆分
- `batchGenDialog.vue` 演示了复杂弹窗的分步操作

---

## 样例 6：模块联邦远程订单页

**页面类型：** module-federation-page

**关键映射：**

```text
remoteName:   aura-order-web
expose key:   ./views/order/list/index.vue
componentPath:
/aura-order-web/views/order/list/index.vue?type=moduleFederation
```

- 页面 expose、i18n、scoped Tailwind和静态资源必须形成闭环。
- 菜单第一段使用 `remoteName`，不能使用 `remoteEntryName`。
- 参考[模块联邦开发技术规范](./模块联邦开发技术规范.md)。

---

## 样例 7：设备点位和轨迹页

**页面类型：** map-page

- 使用 `FxftMap`，点位使用稳定设备ID和 `deviceMarkerLayer`。
- 坐标归一化为 `{ lon, lat }`。
- 轨迹图标经过 `getStaticResourceUrl`，显隐使用公开轨迹方法。
- 参考[2D 地图开发规范](./2D地图开发规范.md)。

---

## 样例 8：多路监控页

**页面类型：** multi-video-page

- 使用 `FxftMultiVideoPlayer`，每个窗口提供稳定 `uuid`。
- 播放器脚本和 decoder通过 `getPublicResourceUrl` 转换。
- 标签页或弹窗显示后调用 `resize()`。
- 参考[视频开发规范](./视频开发规范.md)。

---
