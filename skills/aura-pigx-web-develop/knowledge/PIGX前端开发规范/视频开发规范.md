# 视频开发规范

## 一、组件选型和强制规则

| 场景 | 组件 |
| --- | --- |
| 单路直播、录像、点播、PTZ | `FxftVideoPlayer` |
| 多路分屏、轮巡、拖拽换位 | `FxftMultiVideoPlayer` |

- 禁止业务直接 `new JessibucaPro` 或 `new JessibucaProMulti`。
- 只使用组件公开 Props、Events、Slots和Exposes。
- `live` 用于直播，`record` 用于录像流，`vod` 用于 MP4/HLS等点播文件。
- 空态、错误态、销毁重建和模式切换不能省略。

## 二、模块联邦资源配置

生产环境应自托管播放器脚本和 decoder。资源放在当前业务远程的 public目录时，必须补提供方前缀：

```ts
import { getPublicResourceUrl } from '/@/hooks/moduleFederation';

const scriptUrl = getPublicResourceUrl('/jessibucaPro/jessibuca-pro.js');
const multiScriptUrl = getPublicResourceUrl('/jessibucaPro/jessibuca-pro-multi.js');
const decoderPath = getPublicResourceUrl('/jessibucaPro/decoder-pro-simd.js');
```

禁止直接写：

```vue
<FxftVideoPlayer decoder-path="/jessibucaPro/decoder-pro-simd.js" />
```

远程运行时根路径属于宿主，未转换可能请求到宿主资源。路径应由公共常量统一维护，不散落临时 CDN、域名和IP。

## 三、单路直播

```vue
<template>
	<div class="video-panel">
		<FxftVideoPlayer
			ref="videoRef"
			name="东门监控"
			:url="videoUrl"
			:script-url="scriptUrl"
			:decoder-path="decoderPath"
			:autoplay="true"
			play-mode="live"
			:operate-buttons="operateButtons"
			@error="onError"
			@ptz="onPtz"
		/>
	</div>
</template>

<script setup lang="ts">
const videoRef = ref<any>();
const videoUrl = ref('');

const operateButtons = {
	play: true,
	fullscreen: true,
	screenshot: true,
	ptz: true,
	ptzClickType: 'mouseDownAndUp' as const,
};

const onError = (payload: any) => {
	console.error('视频播放异常', payload?.value?.message);
};

const onPtz = (payload: any) => {
	if (!payload?.type) return;
	// 调用独立业务方法或 API，不在事件中堆叠请求逻辑。
};
</script>
```

- `url` 为空时组件显示空态，不要用无效占位 URL触发错误。
- `@error` 至少记录或展示真实错误。
- 直播默认配置已经针对 MSE、加载和心跳超时优化，特殊流只通过 `options` 覆盖。
- 自定义空态和错误态使用 `empty`、`error` slots。

## 四、录像和点播

录像：

```vue
<FxftVideoPlayer
	ref="videoRef"
	:url="recordUrl"
	:script-url="scriptUrl"
	:decoder-path="decoderPath"
	play-mode="record"
	@playback-timestamp="onPlaybackTimestamp"
	@playback-seek="onPlaybackSeek"
/>
```

点播：

```vue
<FxftVideoPlayer
	ref="videoRef"
	:url="vodUrl"
	:script-url="scriptUrl"
	:decoder-path="decoderPath"
	play-mode="vod"
	@play-vod-time="onVodTime"
	@play-vod-ended="onVodEnded"
/>
```

主动跳转统一调用：

```ts
const seekTo = async (seconds: number) => {
	await videoRef.value?.setPlayProgress?.(seconds);
};
```

- `vod` 内部调用 `playVodSeek`，`record` 内部调用 `setPlaybackStartTime`。
- 点播进度监听 `playVodTime`，录像当前时间监听 `playback-timestamp`。
- 禁止操作 DOM `video.currentTime` 或底层播放器私有字段。

## 五、单路生命周期

- URL变为空时组件销毁播放器并回到空态。
- `playMode` 变化时组件销毁旧实例并重新初始化。
- 页面卸载时组件自动销毁。
- 重试调用公开 `play()`，不长期保存旧 `getInstance()` 返回值。
- 业务主动销毁后，不继续调用旧实例。

## 六、多路基础用法

```vue
<FxftMultiVideoPlayer
	ref="multiRef"
	:split="4"
	:videos="videos"
	:autoplay="true"
	:draggable="true"
	:multi-script-url="multiScriptUrl"
	:decoder-path="decoderPath"
	@selected="onSelected"
	@drop="onDrop"
	@error="onWindowError"
/>
```

```ts
const videos = ref([
	{ uuid: 'camera-001', id: 1, name: '东门', url: 'https://example.com/live/east.flv', playMode: 'live' },
	{ uuid: 'camera-002', id: 2, name: '西门', url: 'https://example.com/live/west.flv', playMode: 'live' },
]);

const onSelected = (payload: any) => {
	console.log('选中窗口', payload.uuid, payload.index);
};

const onDrop = () => {
	const states = multiRef.value?.getWindowStates?.() || [];
	const uuidOrder = states.map((item: any) => item.uuid).filter(Boolean);
	// 按 uuidOrder 同步业务顺序。
};
```

- 拖拽后 `index` 表示当前视觉位置，会变化。
- 设备、通道、录像状态必须绑定稳定 `uuid` 或业务 `id`。
- 单窗口错误只影响当前窗口，错误处理中优先读取 `uuid`。

## 七、多路控制

```ts
multiRef.value?.arrangeWindow?.('4-1');
multiRef.value?.playWindow?.('camera-001', nextUrl);
multiRef.value?.pauseWindow?.('camera-001');
multiRef.value?.destroyWindow?.('camera-001');
multiRef.value?.setFullscreenMulti?.(true);
multiRef.value?.toggleSingleWindowContainerFullscreen?.(true, 'camera-001');
```

使用 `arrangeWindow` 切分屏，不直接改底层 DOM。单窗全屏监听 `fullscreen`，整体全屏监听 `multi-fullscreen`。

## 八、隐藏后显示和尺寸重算

弹窗、标签页、折叠面板或 `v-show` 容器显示后：

```ts
const onPanelShown = async () => {
	await nextTick();
	multiRef.value?.resize?.();
};
```

不要直接修改内部 `video`、`canvas` 样式。切分屏或指定窗口异常时可调用 `resize(index?)`。

## 九、故障排查

| 现象 | 优先检查 |
| --- | --- |
| 独立运行正常、远程运行脚本404 | `scriptUrl`、`multiScriptUrl`、`decoderPath` 是否经过 `getPublicResourceUrl` |
| HTTPS页面无法播放 | 流或脚本是否为不安全 HTTP资源 |
| 点播不能拖动 | 是否使用 `vod`，是否调用 `setPlayProgress` |
| 录像时间不更新 | 是否监听 `playback-timestamp` |
| 拖拽后状态串窗 | 是否错误使用 `index` 作为稳定键 |
| 标签页显示后画面错位 | 显示后是否 `nextTick` 并调用 `resize()` |
| 一路错误影响全部 | 是否在业务状态中错误共享同一窗口键 |
| 销毁时报英文错误 | 确认使用组件公开销毁流程，不重复操作旧实例 |

## 十、检查清单

- [ ] 单路使用 `FxftVideoPlayer`，多路使用 `FxftMultiVideoPlayer`。
- [ ] 未直接创建或操作 JessibucaPro实例。
- [ ] 播放模式与业务一致。
- [ ] public播放器资源经过 `getPublicResourceUrl`。
- [ ] 生产资源自托管且没有临时域名、IP或凭证。
- [ ] 空态、错误态和重试已处理。
- [ ] 回放进度使用公开事件和 `setPlayProgress`。
- [ ] 多路拖拽使用稳定 `uuid`。
- [ ] 隐藏后显示调用 `resize()`。
- [ ] 独立运行和远程运行均通过播放、全屏、销毁和错误验证。
