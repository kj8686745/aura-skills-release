## 使用规则

1. 先读最新版总览、工程规范和开发检查清单。
2. 命中正式页面模式时直接使用正式模式，不复制旧模板。
3. 用当前项目源码、类型和相邻业务模块替换占位内容。
4. 所有消息反馈遵循 `references/message-feedback-guidelines.md`。
5. 所有新增或修改代码遵循 `references/code-comment-guidelines.md`。
