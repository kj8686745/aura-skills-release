# 外部技能依赖检查与安装提示

本流程适用于 `aura-pigx-web-develop` 准备调用的任何其它技能，不限于当前已知名单。

## 调用前检查

1. 从当前环境提供的可用技能列表中按技能名精确检查。
2. 只有技能存在时才读取其 `SKILL.md` 并执行；不得以本地旧目录、历史会话或文档提及代替可用性检查。
3. 同一任务需要多个技能时一次性列出已安装和缺失项，避免逐个打断用户。

当前常见依赖包括：

- `$frontend-design`：用户可见页面的视觉方向与自评；缺失时可降级。
- `fmap-2d`：2D 地图专项规范；缺失时可在用户拒绝安装后按 PIGX 地图规范降级。
- `fxft-video`：视频专项规范；缺失时可在用户拒绝安装后按 PIGX 视频规范降级。
- `aura-pigx-module-federation-check`：模块联邦改前基线与改后复检；属于模块联邦任务的必需技能。
- `vueuse-functions` 等参考资料按条件要求的技能：命中条件时同样检查。

## 缺失提示

发现缺失后立即提示用户：

> 当前任务需要 `$技能名` 来完成“用途”，但当前环境未安装或不可用。是否授权我安装该技能？安装会修改本机技能目录；若拒绝，当前任务将“降级方式或受阻范围”。

不得静默安装，不得把普通依赖安装授权视为技能安装授权。用户明确同意后，使用当前环境提供的技能安装流程；安装来源或作用域不明确时先补充确认。安装完成后重新检查可用技能列表，确认成功后才能调用。

## 拒绝或失败

- 可降级技能：继续执行 PIGX 本地规范，并在交付中列出缺失技能、用户选择和降级影响。
- 必需技能：只暂停受影响的专项分支，保留已完成的只读分析和其它不依赖该技能的工作；不得假称已完成专项检查。
