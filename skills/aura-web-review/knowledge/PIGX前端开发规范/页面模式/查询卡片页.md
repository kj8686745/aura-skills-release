## 场景输入与规则关系

已具备项目请求、组件 Resolver、i18n 和真实业务 API；按需求替换示例业务字段和权限码。遵守 FE-001～018 的共用边界及 FE-019、022、024～027 对应专项规则。骨架用于展示组织与调用方式，不声明业务接口已存在。

示例中私有组件的实际路径使用 `components/`；Element Plus 与公共组件接口按安装版本核对。

> 本模式必须同时遵守[工程与代码生成规范](../工程与代码生成规范.md)、[样式布局与静态资源规范](../样式布局与静态资源规范.md)和[开发检查清单](../开发检查清单.md)。卡片图片和图标必须按模块联邦静态资源规则转换。

## 适用场景

- 顶部有筛选条件，主体为卡片列表（非表格）
- 卡片通常带状态标签、快捷操作按钮
- 适合展示应用列表、模板列表、资源卡片等

---

## 页面结构

```
layout-padding
└── layout-padding-auto layout-padding-view
    ├── 查询区（el-form inline）
    ├── 工具栏（新增按钮等）
    └── 卡片列表区
        └── el-row :gutter="20"
            └── el-col（循环）
                └── el-card
                    ├── 卡片头部（标题 + 状态标签）
                    ├── 卡片主体（关键信息字段）
                    └── 卡片底部（操作按钮）
分页（AuraPagination）或 loadmore
```

---

## 必须遵循

- 卡片数据仍然通过 `useTable` 管理（设置 `isPage: true` 配合 `AuraPagination`）
- 当数据量不大时，也可以设置 `isPage: false` 一次加载全部
- 卡片内按钮权限同样使用 `v-auth`
- 卡片 footer 只承载受限操作时，使用 `permissions.any([...])` 按全部子操作权限控制整个 footer；所有操作均无权限时不渲染空白操作区
- 卡片还包含查看、展开等无权限操作时保留 footer，只将受限按钮拆入独立分组并控制该分组
- 状态标签使用 `aura-dict-tag` 或 `el-tag`，保持与表格列一致的风格

## 推荐写法

### 卡片列表区骨架

```vue
<template>
  <div class="layout-padding">
    <div class="layout-padding-auto layout-padding-view">
      <el-alert v-if="queryError" type="error" :closable="false" :title="$t('example.queryFailed')">
        <el-button @click="getDataList(false)">{{ $t('example.retry') }}</el-button>
      </el-alert>
      <!-- 查询区 -->
      <el-row v-show="showSearch">
        <el-form
          :inline="true"
          :model="state.queryForm"
          @keyup.enter="getDataList"
        >
          <el-form-item :label="$t('example.text01')" prop="name">
            <el-input v-model="state.queryForm.name" style="max-width: 180px"  :placeholder="$t('example.text07')" />
          </el-form-item>
          <el-form-item>
<el-button @click="getDataList" icon="search" type="primary">{{
              $t("common.queryBtn")
            }}</el-button>
</el-form-item>
<el-form-item>
<el-button @click="resetQuery" icon="Refresh">{{
              $t("common.resetBtn")
            }}</el-button>
</el-form-item>
        </el-form>
      </el-row>

      <!-- 工具栏 -->
      <div class="mb8 flex justify-between">
        <el-button
          v-auth="'xxx_add'"
          @click="handleAdd"
          icon="folder-add"
          type="primary"
        >
          {{ $t("common.addBtn") }}
        </el-button>
        <aura-right-toolbar
          v-model:showSearch="showSearch"
          @queryTable="getDataList"
          style="margin-right: 20px"
        />
      </div>

      <!-- 卡片列表 -->
      <div v-loading="state.loading">
        <el-row :gutter="20">
          <el-col
            v-for="item in state.dataList"
            :key="item.id"
            :xs="24"
            :sm="12"
            :md="8"
            :lg="6"
            class="mb20"
          >
            <el-card shadow="hover" class="card-item">
              <template #header>
                <div class="card-header">
                  <span class="card-title">{{ item.name }}</span>
                  <aura-dict-tag :options="status_dict" :value="item.status" />
                </div>
              </template>
              <div class="card-body">
                <div class="card-field">
                  <span class="label">{{ $t('example.text03') }}</span>
                  <span>{{ item.createTime }}</span>
                </div>
                <div class="card-field">
                  <span class="label">{{ $t('example.text04') }}</span>
                  <span>{{ item.remark }}</span>
                </div>
              </div>
              <template v-if="permissions.any(['xxx_edit', 'xxx_del'])" #footer>
                <div class="card-actions">
                  <el-button
                    size="small"
                    text
                    type="primary"
                    v-auth="'xxx_edit'"
                    @click="handleEdit(item.id)"
                    >{{ $t('example.text05') }}</el-button
                  >
                  <el-button
                    size="small"
                    text
                    type="danger"
                    v-auth="'xxx_del'"
                    @click="handleDelete([item.id])"
                    >{{ $t('example.text06') }}</el-button
                  >
                </div>
              </template>
            </el-card>
          </el-col>
        </el-row>

        <!-- 空状态 -->
        <el-empty
          v-if="!state.loading && !queryError && state.dataList?.length === 0"
          :description="$t('example.text02')"
        />
      </div>

      <!-- 分页 -->
      <aura-pagination
        @current-change="currentChangeHandle"
        @size-change="sizeChangeHandle"
        v-bind="state.pagination"
      />
    </div>

    <form-dialog @refresh="getDataList" ref="formDialogRef" />
  </div>
</template>

<script lang="ts" name="ModuleCardPage" setup>
import { useTable } from "/@/config/aura/index";
import type { BasicTableProps } from "@fxft/aura-web-kit/hooks/table";
import { fetchList, delObj } from "/@/api/module/xxx";
import { useMessage, useMessageBox } from "/@/config/aura/index";
import { useDict } from "/@/config/aura/index";
import { usePermissions } from "@fxft/aura-web-kit/hooks/permissions";
import { useI18n } from "vue-i18n";

const FormDialog = defineAsyncComponent(() => import("./components/order-form.vue"));
const { t } = useI18n();
const permissions = usePermissions();
const { status_dict } = useDict("status_dict");

const formDialogRef = ref();
const showSearch = ref(true);

const state: BasicTableProps = reactive<BasicTableProps>({
  queryForm: {},
  pageList: fetchList,
});

const { getDataList, currentChangeHandle, sizeChangeHandle, tableStyle, queryError } =
  useTable(state);

const handleAdd = () => formDialogRef.value?.openDialog();
const handleEdit = (id: string) => formDialogRef.value?.openDialog(id);

const resetQuery = () => { state.queryForm = {}; return getDataList(); };

const handleDelete = async (ids: string[]) => {
  try {
    await useMessageBox().confirm(t("common.delConfirmText"));
  } catch {
    return;
  }
  try {
    await delObj(ids);
    getDataList();
    useMessage().success(t("common.delSuccessText"));
  } catch (err: any) {
    useMessage().error(err.msg);
  }
};
</script>

<style scoped>
.card-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
.card-title {
  font-weight: bold;
  font-size: 14px;
}
.card-field {
  margin-bottom: 8px;
  font-size: 13px;
  color: var(--el-text-color-regular);
}
.card-field .label {
  color: var(--el-text-color-secondary);
}
.card-actions {
  display: flex;
  gap: 8px;
}
</style>
```

## 常见拆分方式

- `index.vue` — 卡片列表页主体
- `components/order-form.vue` — 新增/编辑弹窗（同弹窗表单规范）
- `src/api/<业务域>/index.ts` — 数据接口

## 生成提示输入建议

生成卡片页时需明确：

- 卡片内展示哪些字段
- 每行显示几列（`el-col` 响应式比例）
- 是否需要分页或无限滚动
- 卡片点击行为（打开弹窗/跳转详情）


## 验证步骤与预期结果

1. 按本文场景执行首次进入、目标切换及空/错状态，结果应与当前业务对象一致。
2. 检查加载完成、销毁、隐藏后显示及重新打开，无旧实例或过期响应影响。
3. 独立与远程模式分别检查资源、样式和公开方法；核对控制台与 Network。

**人工确认点**：业务字段、数据规模、权限和真实接口，以及目标版本实际支持的 Props、Events 与 Exposes。
