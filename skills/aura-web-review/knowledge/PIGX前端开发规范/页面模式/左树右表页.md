## 适用场景

- 页面左侧为树形结构（分类/组织/字典类型等），右侧为对应的表格或内容
- 点击树节点后，右侧内容跟随切换
- 典型业务：字典管理、机构管理、权限管理等

## 页面结构

```
layout-padding
└── splitpanes（水平分割）
    ├── pane（左侧，固定宽度 ~320px）
    │   └── layout-padding-auto layout-padding-view
    │       ├── 顶部操作按钮（新增/刷新缓存等）
    │       ├── AuraQueryTree（使用组件自身滚动能力）
    │       └── el-footer（导出/其他全局操作）
    └── pane（右侧，flex-1）
        ├── XxxDialog（新增/编辑弹窗）
        └── XxxList / XxxTable（右侧内容区）
```

---

## 必须遵循

- 布局使用 `Splitpanes` + `Pane` 组件（使用显式 import 或提供方编译期 Resolver，不依赖 main.ts 全局注册）
- 左侧树使用框架公共组件 `AuraQueryTree`，由 `AuraUIResolver` 注入代码与配套样式
- 左侧固定宽度用 `style="flex-basis: 320px"` 控制
- 右侧使用 `class="ml8 flex-1"` 保持自适应
- 树节点点击通过 `@node-click` 事件通知右侧组件刷新
- 右侧内容组件用 `ref` 控制，通过暴露方法（如 `open(data)`）接收左侧数据
- 弹窗（新增/编辑）放在右侧 pane 内，通过 `@refresh` 事件触发树刷新
- `refresh` 无需携带节点；父页面保存当前节点 ID，右侧组件的 `open({ id })` 按该 ID 重新加载数据。尚未选择节点时，只刷新树，不调用右侧组件。树的视觉选中恢复需按实际组件公开 API 另行实现，不能假定 `getdeptTree()` 已完成选中恢复。
- 新增、编辑、删除分别使用实际按钮权限码；受限操作容器按全部子操作权限并集显示。示例的 `xxx_add/xxx_edit/xxx_del` 必须替换为真实权限标识。

## 推荐写法

### index.vue 完整骨架

```vue
<template>
  <div class="layout-padding">
    <splitpanes>
      <pane>
        <splitpanes>
          <!-- 左侧树 -->
          <pane style="flex-basis: 320px">
            <div class="layout-padding-auto layout-padding-view">
              <div v-if="permissions.any(['xxx_add'])" class="flex justify-between">
                <el-button v-auth="'xxx_add'" @click="handleAdd" icon="folder-add" type="primary">
                  {{ $t('common.addBtn') }}
                </el-button>
              </div>
              <div class="mt8 tree-content">
                <aura-query-tree
                  ref="treeRef"
                  :query="state.queryList"
                  @node-click="handleNodeClick"
                  :placeholder="$t('example.text01')"
                >
                  <template #default="{ data }">
                    <span class="custom-tree-node">
                      <span class="label">{{ data.name }}</span>
                      <span v-if="permissions.any(['xxx_edit', 'xxx_del'])" class="do">
                        <el-button-group>
                          <el-button v-auth="'xxx_edit'" icon="edit" size="small" @click.stop="handleEdit(data.id)" />
                          <el-button v-auth="'xxx_del'" icon="delete" size="small" @click.stop="handleDelete([data.id])" />
                        </el-button-group>
                      </span>
                    </span>
                  </template>
                </aura-query-tree>
              </div>
            </div>
          </pane>

          <!-- 右侧内容 -->
          <pane class="ml8 flex-1">
            <xxx-dialog @refresh="handleRefreshTree" ref="dialogRef" />
            <xxx-list ref="listRef" />
          </pane>
        </splitpanes>
      </pane>
    </splitpanes>
  </div>
</template>

<script lang="ts" name="ModulePageName" setup>
import { delObj, fetchList } from '/@/api/module/xxx';
import { useMessage, useMessageBox } from '/@/config/aura/index';
import { useI18n } from 'vue-i18n';
import { usePermissions } from '@fxft/aura-web-kit/hooks/permissions';
import { Splitpanes, Pane } from 'splitpanes';
import 'splitpanes/dist/splitpanes.css';
// AuraQueryTree 由提供方 AuraUIResolver 注入代码与样式。

const XxxDialog = defineAsyncComponent(() => import('./components/order-form.vue'));
const XxxList = defineAsyncComponent(() => import('./components/order-list.vue'));

const { t } = useI18n();
const permissions = usePermissions();
const dialogRef = ref();
const treeRef = ref();
const listRef = ref();
const selectedNodeId = ref<string>();

const state = reactive({
  queryList: (keyword?: string) => fetchList({ name: keyword }),
});

const handleAdd = () => dialogRef.value?.openDialog();
const handleEdit = (id: string) => dialogRef.value?.openDialog(id);

// 点击树节点，通知右侧刷新
const handleNodeClick = (data: { id: string }) => {
  selectedNodeId.value = data.id;
  listRef.value?.open({ id: data.id });
};

// refresh 不携带参数；树与右侧内容分别刷新，不依赖事件返回节点。
const handleRefreshTree = () => {
  treeRef.value?.getdeptTree();
  if (selectedNodeId.value) listRef.value?.open({ id: selectedNodeId.value });
};

// 删除树节点
const handleDelete = async (ids: string[]) => {
  try {
    await useMessageBox().confirm(t('common.delConfirmText'));
  } catch {
    return;
  }
  try {
    await delObj(ids);
    useMessage().success(t('common.delSuccessText'));
    treeRef.value?.getdeptTree();
  } catch (err: any) {
    useMessage().error(err.msg);
  }
};
</script>

<style scoped>
.custom-tree-node {
  display: flex;
  flex: 1;
  align-items: center;
  justify-content: space-between;
  font-size: 14px;
  padding-right: 24px;
  height: 100%;
}
.custom-tree-node .do {
  display: none;
}
.custom-tree-node:hover .do {
  display: inline-block;
}
</style>
```

### AuraQueryTree 组件接口

```typescript
interface QueryTreeProps {
  query: (keyword?: string) => PromiseLike<{ data: Record<string, unknown>[] }>;
  placeholder?: string;
  showExpand?: boolean;
}
type QueryTreeEvents = { nodeClick: [item: Record<string, unknown>] };
type QueryTreeExpose = { getdeptTree: () => void };
```

模板通过 `@node-click="handleNodeClick"` 接收节点，通过 `treeRef.value?.getdeptTree()` 刷新。公开声明的 `getdeptTree` 返回 void，不把 await 该方法视为异步刷新已经完成的保证。

## 常见拆分方式

- `index.vue` — 左树右布局容器
- `components/order-form.vue` — 新增/编辑弹窗（同弹窗表单规范）
- `list/index.vue` 或直接作为独立组件 — 右侧内容（可以是表格、卡片等）
- `src/api/<业务域>/index.ts` — 树数据和右侧内容的接口

## 验证步骤与预期结果

1. 按本文场景执行首次进入、目标切换及空/错状态，结果应与当前业务对象一致。
2. 检查加载完成、销毁、隐藏后显示及重新打开，无旧实例或过期响应影响。
3. 独立与远程模式分别检查资源、样式和公开方法；核对控制台与 Network。

**人工确认点**：业务字段、数据规模、权限和真实接口，以及目标版本实际支持的 Props、Events 与 Exposes。
