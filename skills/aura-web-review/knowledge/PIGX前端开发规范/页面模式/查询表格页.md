## 适用场景

- 页面顶部有查询表单，中间有操作工具栏，主体是分页表格
- 常伴随新增/编辑弹窗（`components/order-form.vue`）
- 适用于标准分页管理类业务页

## 页面结构

```
layout-padding
└── layout-padding-auto layout-padding-view
    ├── 查询区（el-row + el-form，v-show="showSearch"）
    ├── 工具栏（el-row + 操作按钮 + right-toolbar）
    ├── 表格（el-table）
    └── 分页（AuraPagination 组件）
弹窗（form-dialog，放在最外层 layout-padding 内）
```

## 必须遵循

- 使用 `useTable(state)` hook 管理分页查询，不要手写分页逻辑
- `state.pageList` 必须指向 `api` 层的分页查询函数
- 删除操作必须先弹出确认框（`useMessageBox().confirm()`）
- 按钮权限使用 `v-auth="'permission_code'"` 指令
- 操作列只包含受限按钮时，使用 `permissions.any([...])` 汇总列内全部权限；用户没有任何一项操作权限时隐藏整列，按钮仍保留各自的 `v-auth`
- 选择列只服务于受限批量操作时随对应权限隐藏；若还支持无权限要求的选择业务则保留
- 弹窗组件使用 `defineAsyncComponent` 异步引入
- 多选删除使用 `selectObjs` + `multiple` 控制禁用状态
- 导出使用 `downBlobFile` 方法，路径从 `api` 层维护
- 表格必须传入 `useTable(state)` 返回的 `tableStyle`，保持表头和单元格样式统一
- 多选列和序号列必须设置固定宽度：`type="selection"` 使用 `width="40"`，`type="index"` 使用 `width="60"`（文案较长时可固定为 `80`）
- 普通数据列默认添加 `show-overflow-tooltip`，避免长文本撑开表格
- 需要自定义渲染的列统一使用 `<template #default="scope">`，通过 `scope.row.xxx` 读取行数据

## 表格细节规范

### el-table 基础属性

分页表格统一使用 `state.dataList`、`state.loading` 和 `tableStyle`：

```vue
<el-table
  :data="state.dataList"
  v-loading="state.loading"
  style="width: 100%"
  row-key="id"
  border
  @selection-change="handleSelectionChange"
  @sort-change="sortChangeHandle"
  :cell-style="tableStyle.cellStyle"
  :header-cell-style="tableStyle.headerCellStyle"
>
  <el-table-column v-if="permissions.any(['xxx_del'])" type="selection" width="40" align="center" />
  <el-table-column type="index" label="#" width="60" />
  <el-table-column prop="fieldName" :label="$t('example.text01')" show-overflow-tooltip />
  <el-table-column prop="status" :label="$t('example.text02')" show-overflow-tooltip>
    <template #default="scope">
      <aura-dict-tag :options="status_dict" :value="scope.row.status" />
    </template>
  </el-table-column>
</el-table>
```

### 列写法要求

- `type="selection"` 列固定写 `width="40"`，并设置 `align="center"`
- `type="index"` 列固定写 `width="60"`；如果国际化标题较长或页面已有固定视觉要求，可固定为 `width="80"`
- 普通文本列必须写 `show-overflow-tooltip`
- 字典、状态、时间格式化、操作按钮等自定义列也保留 `show-overflow-tooltip`，并使用 `#default="scope"`
- 不推荐使用 `#default="{ row }"` 作为生成默认写法，统一用 `scope.row`，便于复制和保持项目风格一致

### index.vue 完整骨架

```vue
<template>
  <div class="layout-padding">
    <div class="layout-padding-auto layout-padding-view">
      <el-alert v-if="queryError" type="error" :closable="false" :title="$t('example.queryFailed')">
        <el-button @click="getDataList(false)">{{ $t('example.retry') }}</el-button>
      </el-alert>
      <!-- 查询区 -->
      <el-row class="ml10" v-show="showSearch">
        <el-form
          :inline="true"
          :model="state.queryForm"
          @keyup.enter="getDataList"
          ref="queryRef"
        >
          <el-form-item :label="$t('example.text01')" prop="fieldName">
            <el-input
              v-model="state.queryForm.fieldName"
              style="max-width: 180px"
             :placeholder="$t('example.text05')" />
          </el-form-item>
          <el-form-item>
<el-button @click="getDataList" icon="search" type="primary">{{
              $t("common.queryBtn")
            }}</el-button>
</el-form-item>
<el-form-item>
<el-button @click="resetQuery" icon="Refresh">{{
              $t("common.resetBtn")
            }}</el-button>
</el-form-item>
        </el-form>
      </el-row>

      <!-- 工具栏 -->
      <el-row>
        <div class="mb8" style="width: 100%">
          <el-button
            v-auth="'xxx_add'"
            @click="handleAdd"
            class="ml10"
            icon="folder-add"
            type="primary"
          >
            {{ $t("common.addBtn") }}
          </el-button>

            v-auth="'xxx_del'"
            plain
            :disabled="multiple"
            @click="handleBatchDelete"
            class="ml10"
            icon="Delete"
            type="primary"
          >
            {{ $t("common.delBtn") }}
          </el-button>
          <aura-right-toolbar
            :export="'xxx_export'"
            @exportExcel="exportExcel"
            @queryTable="getDataList"
            class="ml10"
            style="float: right; margin-right: 20px"
            v-model:showSearch="showSearch"
          />
        </div>
      </el-row>

      <!-- 表格 -->
      <el-table
        :data="state.dataList"
        v-loading="state.loading"
        style="width: 100%"
        row-key="id"
        border
        @selection-change="handleSelectionChange"
        @sort-change="sortChangeHandle"
        :cell-style="tableStyle.cellStyle"
        :header-cell-style="tableStyle.headerCellStyle"
      >
        <el-table-column
          v-if="permissions.has('xxx_del')"
          type="selection"
          width="40"
          align="center"
        />
        <el-table-column type="index" label="#" width="60" />
        <el-table-column
          prop="fieldName"
          :label="$t('example.text01')"
          show-overflow-tooltip
        />
        <!-- 字典标签列 -->
        <el-table-column prop="status" :label="$t('example.text02')">
          <template #default="scope">
            <aura-dict-tag :options="status_dict" :value="scope.row.status" />
          </template>
        </el-table-column>
        <!-- 操作列 -->

          v-if="permissions.any(['xxx_edit', 'xxx_del'])"
          :label="$t('common.action')"

          <template #default="scope">
            <el-button
              icon="edit-pen"
              @click="handleEdit(scope.row.id)"
              text
              type="primary"
              v-auth="'xxx_edit'"
            >
              {{ $t("common.editBtn") }}
            </el-button>
            <el-button
              icon="delete"
              @click="handleDelete([scope.row.id])"
              text
              type="primary"
              v-auth="'xxx_del'"
            >

            </el-button>
          </template>
        </el-table-column>

        v-bind="state.pagination"

<script lang="ts" name="ModulePageName" setup>
import { useTable } from "/@/config/aura/index";
import type { BasicTableProps } from "@fxft/aura-web-kit/hooks/table";
import { fetchList, delObj } from "/@/api/module/xxx";
import { useMessage, useMessageBox } from "/@/config/aura/index";
import { useDict } from "/@/config/aura/index";
import { usePermissions } from "@fxft/aura-web-kit/hooks/permissions";
import { useI18n } from "vue-i18n";
import { useForm } from "@fxft/aura-web-kit/hooks/form";

const FormDialog = defineAsyncComponent(() => import("./components/order-form.vue"));
const { t } = useI18n();
const { resetForm } = useForm();
const permissions = usePermissions();

// 字典
const { status_dict } = useDict("status_dict");

// refs
const formDialogRef = ref();
const queryRef = ref();
const showSearch = ref(true);
const selectObjs = ref([]) as any;
const multiple = ref(true);

// 表格状态
const state: BasicTableProps = reactive<BasicTableProps>({
  queryForm: {},
  pageList: fetchList,
  orders: [{ column: "create_time", asc: false }],
});

const {
  getDataList,
  currentChangeHandle,
  sizeChangeHandle,
  sortChangeHandle,
  downBlobFile,
  tableStyle,
  queryError,
} = useTable(state);

const handleAdd = () => formDialogRef.value?.openDialog();
const handleEdit = (id: string) => formDialogRef.value?.openDialog(id);
const handleBatchDelete = () => handleDelete(selectObjs.value);

// 重置查询
const resetQuery = () => {
  resetForm(queryRef, state.queryForm, {});
  selectObjs.value = [];
  getDataList();
};

// 导出
const exportExcel = () => {
  downBlobFile(
    "/module/xxx/export",
    { ...state.queryForm, ids: selectObjs.value },
    "xxx.xlsx"
  );
};

// 多选
const handleSelectionChange = (objs: { id: string }[]) => {
  selectObjs.value = objs.map(({ id }) => id);
  multiple.value = !objs.length;
};

// 删除
const handleDelete = async (ids: string[]) => {
  try {
    await useMessageBox().confirm(t("common.delConfirmText"));
  } catch {
    return;
  }
  try {
    await delObj(ids);
    getDataList();
    useMessage().success(t("common.delSuccessText"));
  } catch (err: any) {
    useMessage().error(err.msg);
  }
};
</script>
```

## useTable 核心说明

`useTable(state)` 接收一个响应式对象，关键字段：

| 字段               | 类型       | 说明                                 |
| ------------------ | ---------- | ------------------------------------ |
| `pageList`         | `Function` | 分页查询 API 函数（必填）            |
| `queryForm`        | `object`   | 查询条件（会自动合并到请求参数）     |
| `pagination.current` | `number` | 当前页，从 1 开始，默认 1 |
| `pagination.size` | `number` | 每页条数，默认 10 |
| `orders` | `OrderItem[]` | 接口启用排序时使用，元素为 `{ column, asc }` |
| `isPage`           | `boolean`  | 是否分页，默认 true                  |
| `createdIsNeed`    | `boolean`  | 是否在组件创建时自动请求，默认 true  |

web-kit `1.6.18` 起分页契约统一如下，TypeScript 类型从 `@fxft/aura-web-kit/hooks/table` 的 `PageQuery`、`PageResult<T>`、`OrderItem` 引入：

| 字段 | 类型 | 含义 | 用途 |
|---|---|---|---|
| `current` | `long` | 当前页，从 **1** 开始 | 请求、返回 |
| `size` | `long` | 每页条数 | 请求、返回 |
| `total` | `long` | 符合条件的总记录数 | 返回 |
| `records` | `List<T>` | 当前页数据 | 返回 |
| `pages` | `long` | 总页数，根据 `total` 和 `size` 计算 | 返回，是否输出取决于序列化配置 |
| `orders` | `List<OrderItem>` | 排序信息，包含 `column`、`asc` | 按接口配置使用 |

公共 Hook 使用 `current/size` 请求和 `response.data.records/total` 响应，不使用 `pageNum/pageSize/pageNo/currentPage` 或 `descs/ascs` 作为公共契约。实际接口采用其他协议时，只在项目已有 API 适配边界按真实契约明确转换请求与响应，使 Hook 仍消费标准结构；不修改公共 Hook、不恢复 `props.item/props.totalCount`、不在页面维护多套分页状态或添加多字段兜底。`pageSizes`、`layout` 仅控制分页组件，返回专用字段不作为请求参数。

GET 排序参数由公共请求层序列化为 `orders[0].column`、`orders[0].asc`；POST JSON 使用 orders 对象数组。没有排序或取消全部排序时不发送 orders。`sortChangeHandle` 将列 prop 转为下划线 column；接口未开放排序字段时不配置该列的远程排序。

返回方法：

| 方法                                 | 说明                            |
| ------------------------------------ | ------------------------------- |
| `getDataList(refresh?)`              | 刷新数据（传 false 不回第一页） |
| `currentChangeHandle(val)`           | 翻页                            |
| `sizeChangeHandle(val)`              | 改每页条数                      |
| `sortChangeHandle(column)`           | 排序                            |
| `downBlobFile(url, query, fileName)` | 导出文件                        |
| `tableStyle`                         | 表格统一样式对象                |

常规查询表格页建议直接按以下顺序解构，后续模板、分页、排序和导出都复用这一组方法：

```typescript
const {
  getDataList,
  currentChangeHandle,
  sizeChangeHandle,
  sortChangeHandle,
  downBlobFile,
  tableStyle,
  queryError,
} = useTable(state);
```

- `getDataList`：查询按钮、重置后刷新、弹窗保存后刷新、右侧工具栏刷新都使用它
- `currentChangeHandle` / `sizeChangeHandle`：直接绑定到 `AuraPagination`
- `sortChangeHandle`：绑定到 `el-table` 的 `@sort-change`
- `downBlobFile`：导出 Excel 等文件时使用
- `tableStyle`：绑定到 `el-table` 的 `:cell-style` 和 `:header-cell-style`

## 分页源码核对

`useTable` 在 `state` 上补全默认值，不替换传入对象。`createdIsNeed` 默认为 true，在组件挂载时查询；弹窗专属列表应设为 false，打开时再调用。`getDataList()` 回第一页，`getDataList(false)` 保留当前页；翻页、修改条数和排序直接查询当前状态，业务需要排序后回第一页时应显式约定。

`queryError` 暴露最近一次查询错误，失败时不会把旧列表自动清空；页面必须展示局部错误及重试，不能把保留的旧结果显示成本次查询成功。请求序号防止旧响应覆盖新查询。`isPage: false` 时不发送 current/size，读取 response.data 数组；非空 orders 仍按接口支持情况发送。

前端公开分页契约使用 TypeScript `number` 与数组类型。`OrderItem.column` 为列名字符串，`asc` 为布尔值。前端使用公开的 `PageQuery`、`PageResult<T>` 与 `OrderItem`，不透传 total/records/pages 等返回字段。
