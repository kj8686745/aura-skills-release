## 适用场景

- 新增/编辑操作通过 `el-dialog` 弹窗完成
- 弹窗由父页面（通常是查询表格页）触发
- 项目中几乎所有列表页的增删改都使用此模式

---

## 页面结构

```
el-dialog（v-model="visible"）
└── el-form（ref="dataFormRef"，:rules="dataRules"）
    ├── el-row + el-col（表单字段网格布局）
    │   ├── el-form-item + el-input / el-select / el-radio-group 等
    │   └── ...
    └── el-collapse（可选，折叠高级属性）
footer 插槽
└── 取消按钮 + 确认按钮
```

---

## 必须遵循

- 弹窗通过 `defineExpose({ openDialog })` 暴露 `openDialog` 方法给父组件调用
- 仅新增/编辑二态表单可使用 `openDialog(id?)`；其他操作使用明确的操作上下文，例如 `{ id, action }`，不可把有 id 一律解释为编辑
- 需要已有对象详情时遵循按业务标识读取真实详情、隔离旧响应的数据加载约束：入口只传标识和必要上下文，弹窗按真实详情/初始化接口回填，不直接使用入口对象作为完整数据
- 仅供弹窗使用的详情、候选项、字典项和业务列表必须在 `openDialog` 中加载；不得由父页面预加载后长期通过 Props 注入，也不得在弹窗组件 `onMounted` 或 `immediate` 监听中提前请求
- 父页面只传入本次操作上下文，例如记录 ID、已选 ID 或限制条件。主页面自身也需要的列表可以按页面生命周期加载，但弹窗仍应在打开时初始化其时效性数据
- 提交成功后 `emit('refresh')` 通知父组件刷新列表
- 提交时设置 `loading` 防止重复点击，使用 `try/finally` 确保 loading 复位
- 业务表单必须使用 `@fxft/aura-web-kit/hooks/form` 的 `useForm`，并通过 `validateForm`、`resetForm`、`clearFormValidate` 统一完成校验、重置和历史校验清理；不得直接调用表单实例的 `validate/resetFields/clearValidate`
- 弹窗关闭时使用 `resetForm` 恢复初始值；弹窗打开并完成数据回填后使用 `clearFormValidate` 清除上一次操作残留的校验状态
- 只读加载使用弹窗内部的 `loading/error/empty` 状态并提供必要重试，不调用全局消息；提交等变更操作失败才按消息规范反馈
- 顶部或摘要工具栏已有新增等主操作时，空态只展示说明，不重复放置相同按钮；重试、授权或当前状态独有的恢复操作可以保留
- 字段校验规则在 `dataRules` 中定义，使用 `@fxft/aura-web-kit/utils/validate` 中的 `rule` 辅助工具

## 推荐写法

### form.vue 完整骨架

```vue
<template>
  <el-dialog
    :close-on-click-modal="false"
    :title="form.id ? $t('common.editBtn') : $t('common.addBtn')"
    draggable
    v-model="visible"
    :before-close="handleBeforeClose"
    @closed="handleClosed"
  >
    <el-alert v-if="detailFailed" type="error" :closable="false">
      <el-button @click="retryLoad">{{ $t('example.retry') }}</el-button>
    </el-alert>
    <el-form :model="form" :rules="dataRules" label-width="120px" ref="dataFormRef" v-loading="loading || detailLoading">
      <el-row :gutter="20">
        <el-col :span="12" class="mb20">
          <el-form-item :label="$t('example.text01')" prop="fieldName">
            <el-input v-model="form.fieldName" :placeholder="$t('example.text02')" />
          </el-form-item>
        </el-col>

        <!-- 字典下拉 -->
        <el-col :span="12" class="mb20">
          <el-form-item :label="$t('example.text03')" prop="status">
            <el-select v-model="form.status" :placeholder="$t('example.text05')">
              <el-option
                v-for="(item, index) in status_dict"
                :key="index"
                :label="item.label"
                :value="item.value"
              />
            </el-select>
          </el-form-item>
        </el-col>

        <!-- 单选组 -->
        <el-col :span="12" class="mb20">
          <el-form-item :label="$t('example.text04')" prop="type">
            <el-radio-group v-model="form.type">
              <el-radio
                v-for="(item, index) in type_dict"
                :key="index"
                :label="item.value"
                border
              >{{ item.label }}</el-radio>
            </el-radio-group>
          </el-form-item>
        </el-col>
      </el-row>
    </el-form>

    <template #footer>
      <span class="dialog-footer">
        <el-button @click="handleCancel" :disabled="loading">{{ $t('common.cancelButtonText') }}</el-button>
        <el-button @click="onSubmit" type="primary" :disabled="loading || validating || detailLoading || detailFailed">{{ $t('common.confirmButtonText') }}</el-button>
      </span>
    </template>
  </el-dialog>
</template>

<script lang="ts" name="ModuleFormDialog" setup>
import { useMessage } from '/@/config/aura/index';
import { useForm } from '@fxft/aura-web-kit/hooks/form';

import { addObj, getObj, putObj, getFormOptions } from '/@/api/module/xxx';
import { useI18n } from 'vue-i18n';
import { rule } from '@fxft/aura-web-kit/utils/validate';

const emit = defineEmits(['refresh']);
const { t } = useI18n();
const { clearFormValidate, resetForm, validateForm } = useForm();

const dataFormRef = ref();
const visible = ref(false);
const loading = ref(false);
const validating = ref(false);

// 字典
// 仅弹窗使用的字典和候选项在 openDialog 中加载。
const status_dict = ref<Array<{ label: string; value: string }>>([]);
const type_dict = ref<Array<{ label: string; value: string }>>([]);
const detailLoading = ref(false);
const detailFailed = ref(false);
let openSequence = 0;

// 表单数据（列出所有字段，id 为空字符串）
const initialForm = {
  id: '',
  fieldName: '',
  status: '',
  type: '',
};
const form = reactive({ ...initialForm });

const handleCancel = () => {
  if (loading.value) return;
  openSequence += 1;
  validating.value = false;
  visible.value = false;
};

// 关闭按钮与 Esc 使用同一关闭边界；请求提交中不允许关闭。
const handleBeforeClose = (done: () => void) => {
  if (loading.value) return;
  handleCancel();
  done();
};
const handleClosed = () => {
  // 旧关闭动画结束时，不能重置已经重新打开的表单。
  if (!visible.value) resetForm(dataFormRef, form, initialForm);
};

// 校验规则
const dataRules = ref({
  fieldName: [
    { validator: rule.overLength, trigger: 'blur' },
    { required: true, message: t('example.text06'), trigger: 'blur' },
  ],
  status: [{ required: true, message: t('example.text07'), trigger: 'blur' }],
});

// getFormOptions 是示例业务 API：返回 { data: { status: [], type: [] } }，按实际契约替换。
const openDialog = async (id?: string) => {
  if (loading.value) return;
  const sequence = ++openSequence;
  validating.value = false;
  Object.assign(form, initialForm, { id: id ?? "" });
  status_dict.value = [];
  type_dict.value = [];
  visible.value = true;
  detailLoading.value = true;
  detailFailed.value = false;
  try {
    const [detail, options] = await Promise.all([
      id ? getObj(id) : Promise.resolve({ data: initialForm }),
      getFormOptions(),
    ]);
    if (sequence !== openSequence || !visible.value) return;
    Object.assign(form, detail.data);
    status_dict.value = options.data.status;
    type_dict.value = options.data.type;
    await clearFormValidate(dataFormRef);
  } catch {
    if (sequence === openSequence && visible.value) detailFailed.value = true;
  } finally {
    if (sequence === openSequence) detailLoading.value = false;
  }
};
const retryLoad = () => openDialog(form.id || undefined);

// 提交
const onSubmit = async () => {
  if (!visible.value || loading.value || validating.value || detailLoading.value || detailFailed.value) return;
  const sequence = openSequence;
  validating.value = true;
  const valid = await validateForm(dataFormRef);
  if (sequence !== openSequence || !visible.value) return;
  validating.value = false;
  if (!valid || loading.value || detailLoading.value || detailFailed.value) return;
  const payload = { ...form };
  loading.value = true;
  try {
    payload.id ? await putObj(payload) : await addObj(payload);
    useMessage().success(t(payload.id ? 'common.editSuccessText' : 'common.addSuccessText'));
    visible.value = false;
    emit('refresh');
  } catch (err: any) {
    useMessage().error(err.msg);
  } finally {
    loading.value = false;
  }
};

defineExpose({ openDialog });
</script>
```

### 打开时加载弹窗专属数据

完整骨架将详情、字典与候选项合并到 `openDialog`，先重置旧数据再加载；请求序号保证过期响应不写入新目标。`getFormOptions()` 表示实际业务字典/候选项入口，并非框架固定 API。加载失败只呈现弹窗局部状态，禁止提交，支持重试；保存后仅刷新仍打开且需要刷新的关联弹窗。

### 父组件调用方式

```vue
<!-- index.vue 模板中 -->
<form-dialog @refresh="getDataList" ref="formDialogRef" />

<!-- 触发 -->
formDialogRef.value?.openDialog()        // 新增
formDialogRef.value?.openDialog(id)      // 编辑
```

## 验证步骤与预期结果

1. 按本文场景执行首次进入、目标切换及空/错状态，结果应与当前业务对象一致。
2. 检查加载完成、销毁、隐藏后显示及重新打开，无旧实例或过期响应影响。
3. 独立与远程模式分别检查资源、样式和公开方法；核对控制台与 Network。
4. 校验尚未返回时分别用取消、关闭按钮和 Esc 关闭；预期不发送保存请求。关闭后立即打开另一条记录，旧校验和旧关闭动画不能提交或重置新表单。
5. 保存请求进行中尝试关闭或切换记录，预期操作被阻止；当前请求完成前只能提交一次。

**人工确认点**：业务字段、数据规模、权限和真实接口，以及目标版本实际支持的 Props、Events 与 Exposes。
