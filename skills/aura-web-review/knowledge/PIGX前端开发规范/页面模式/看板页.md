## 场景输入与规则关系

已具备项目请求、组件 Resolver、i18n 和真实业务 API；按需求替换示例业务字段和权限码。遵守 FE-001～018 的共用边界及 FE-019、022、024～027 对应专项规则。骨架用于展示组织与调用方式，不声明业务接口已存在。

示例中私有组件的实际路径使用 `components/`；Element Plus 与公共组件接口按安装版本核对。

> 本模式必须同时遵守[样式布局与静态资源规范](../样式布局与静态资源规范.md)和[开发检查清单](../开发检查清单.md)。图表通过 useECharts 响应尺寸变化；地图和视频按各自公开 API 与可见性策略处理，不推断所有组件都提供 resize。

## 适用场景

- 首页/工作台/数据大盘
- 包含统计卡片、时间筛选、图表区、重点列表等多区块组合
- 数据以只读展示为主，不涉及复杂表单操作

---

## 页面结构

```
layout-padding
└── 时间筛选区（可选）
    ├── 统计卡片区（el-row + el-col，数值摘要卡）
    ├── 图表区（ECharts / D3 图表）
    ├── 快速跳转入口（快捷操作卡片）
    └── 告警/重点列表区（简化表格或卡片）
```

---

## 必须遵循

- 图表使用 `useECharts` hook，不直接操作 ECharts 实例
- 统计卡片数据通过独立 API 接口获取，不依赖 `useTable`
- 看板页通常不需要分页和表单，避免引入不必要的 hook
- 图表 DOM 引用通过 `ref` + `onMounted` 初始化
- 响应式布局使用 `el-col :xs :sm :md :lg` 断点适配不同屏幕

## 推荐写法

### 统计卡片区

```vue
<el-row :gutter="20" class="mb20">
  <el-col :xs="24" :sm="12" :md="6" v-for="stat in statCards" :key="stat.key">
    <el-card shadow="hover" class="stat-card">
      <div class="stat-value">{{ stat.value }}</div>
      <div class="stat-label">{{ stat.label }}</div>
    </el-card>
  </el-col>
</el-row>
```

### ECharts 图表使用

```vue
<template>
  <div ref="chartRef" style="height: 300px; width: 100%"></div>
</template>

<script lang="ts" name="DashboardPage" setup>
import { useECharts } from '/@/config/aura/echarts';

const chartRef = ref<HTMLDivElement>();
const { setOption } = useECharts(chartRef);

const loadChartData = async () => {
  const res = await fetchChartData();
  setOption({
    xAxis: { data: res.data.labels },
    series: [{ type: 'bar', data: res.data.values }],
  });
};

onMounted(() => {
  loadChartData();
});
</script>
```

### 看板页完整骨架

下面的 `fetchStats(query)` 与 `fetchRecentList(query)` 是示例业务 API，均接收 `{ startDate?: string; endDate?: string }`；字段名称和日期边界需替换为真实接口契约。统计响应 data 为 `{ total, labels, values, distribution }`，其中 distribution 为 `{ name, value }[]`；记录响应 data 为 `{ id, name, createTime }[]`。筛选快照传入两个请求，不从正在变化的 UI 状态异步读取参数。

```vue
<template>
  <div class="layout-padding">
    <div class="layout-padding-auto layout-padding-view" v-loading="loading">
      <el-alert v-if="loadFailed" :title="$t('example.loadFailed')" type="error" :closable="false">
        <el-button @click="loadAll">{{ $t('example.retry') }}</el-button>
      </el-alert>
      <!-- 时间筛选 -->
      <div class="mb20 flex justify-between">
        <span class="page-title">{{ $t('example.text09') }}</span>
        <el-date-picker v-model="dateRange" type="daterange" value-format="YYYY-MM-DD"
          :range-separator="$t('example.text03')" :start-placeholder="$t('example.startDate')"
          :end-placeholder="$t('example.endDate')" @change="loadAll" />
      </div>

      <!-- 统计卡片 -->
      <el-row :gutter="20" class="mb20">
        <el-col :xs="24" :sm="12" :md="6">
          <el-card shadow="hover">
            <div class="stat-value">{{ stats.total }}</div>
            <div class="stat-label">{{ $t('example.text10') }}</div>
          </el-card>
        </el-col>
        <!-- 更多统计卡 -->
      </el-row>

      <!-- 图表区 -->
      <el-row :gutter="20" class="mb20">
        <el-col :span="16">
          <el-card :header="$t('example.text04')">
            <div ref="trendChartRef" style="height: 300px" />
          </el-card>
        </el-col>
        <el-col :span="8">
          <el-card :header="$t('example.text05')">
            <div ref="pieChartRef" style="height: 300px" />
          </el-card>
        </el-col>
      </el-row>

      <!-- 重点列表 -->
      <el-card :header="$t('example.text06')">
        <el-table :data="recentList" border size="small"
          :cell-style="{ textAlign: 'center' }"
          :header-cell-style="{ textAlign: 'center', background: 'var(--el-table-row-hover-bg-color)' }">
          <el-table-column prop="name" :label="$t('example.text07')" />
          <el-table-column prop="createTime" :label="$t('example.text08')" width="180" />
        </el-table>
      </el-card>
    </div>
  </div>
</template>

<script lang="ts" name="DashboardPage" setup>
import { useECharts } from '/@/config/aura/echarts';
import { fetchStats, fetchRecentList } from '/@/api/module/dashboard';
import { onBeforeUnmount } from 'vue';

const trendChartRef = ref<HTMLDivElement>();
const pieChartRef = ref<HTMLDivElement>();
const { setOption: setTrendOption } = useECharts(trendChartRef);
const { setOption: setPieOption } = useECharts(pieChartRef);

const dateRange = ref<[string, string] | null>(null);
const stats = ref({ total: 0 });
const recentList = ref<Array<{ id: string; name: string; createTime: string }>>([]);
const loading = ref(false);
const loadFailed = ref(false);
let querySequence = 0;

const loadAll = async () => {
  const sequence = ++querySequence;
  const range = dateRange.value;
  const query = range ? { startDate: range[0], endDate: range[1] } : {};
  loading.value = true;
  loadFailed.value = false;
  try {
    const [statsRes, listRes] = await Promise.all([fetchStats(query), fetchRecentList(query)]);
    if (sequence !== querySequence) return;
    stats.value = { total: statsRes.data.total };
    recentList.value = listRes.data;
    setTrendOption({
      xAxis: { type: 'category', data: statsRes.data.labels },
      yAxis: { type: 'value' },
      series: [{ type: 'bar', data: statsRes.data.values }],
    }, true);
    setPieOption({ series: [{ type: 'pie', data: statsRes.data.distribution }] }, true);
  } catch {
    if (sequence === querySequence) loadFailed.value = true;
  } finally {
    if (sequence === querySequence) loading.value = false;
  }
};
onBeforeUnmount(() => { querySequence += 1; });

onMounted(() => {
  loadAll();
});
</script>
```

## 常见拆分方式

- `index.vue` — 看板主容器（组合各区块）
- `components/stat-card.vue` — 统计卡片（如多处复用）
- `components/trend-chart.vue` — 图表组件（如图表逻辑复杂）
- `src/api/<业务域>/dashboard.ts` — 看板各区块的数据接口

## 验证步骤与预期结果

1. 按本文场景执行首次进入、目标切换及空/错状态，结果应与当前业务对象一致。
2. 检查加载完成、销毁、隐藏后显示及重新打开，无旧实例或过期响应影响。
3. 连续切换两个时间范围并让旧请求后返回，预期两次请求均携带各自日期，页面保留最新筛选的数据与 loading；清空日期后发送无日期条件的查询。
4. 查询失败时显示局部错误与重试，不将保留的旧统计值解释为本次成功结果；卸载后返回的响应不能更新图表。
5. 独立与远程模式分别检查资源、样式和公开方法；核对控制台与 Network。

**人工确认点**：业务字段、数据规模、权限和真实接口，以及目标版本实际支持的 Props、Events 与 Exposes。
