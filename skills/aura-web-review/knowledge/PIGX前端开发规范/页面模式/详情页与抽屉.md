## 适用场景

- 只读详情展示，点击列表行/按钮触发
- 抽屉：从右侧滑出，不离开当前列表页
- 详情页：独立页面，通过路由跳转
- 常带"编辑""关闭""继续处理"等动作按钮

## 页面结构

### 抽屉模式

```
el-drawer（v-model="visible"，size="50%"）
└── 抽屉内容容器
    ├── 基本信息区（el-descriptions）
    ├── 关联数据区（嵌套简化表格）
    └── 操作区（底部按钮组）
```

### 独立详情页模式

```
layout-padding
└── layout-padding-auto layout-padding-view
    ├── 页面头部（面包屑 + 返回按钮）
    ├── 基本信息区（el-descriptions）
    ├── Tab 分组（el-tabs，可选）
    │   ├── Tab1：关联记录表格
    │   └── Tab2：操作历史
    └── 底部操作区
```

---

## 必须遵循

- 遵循按业务标识读取真实详情、隔离旧响应的数据加载约束：不论来自表格、卡片、树、地图还是路由，均按业务标识查询详情；独立页、复用抽屉和其他承载形式都要处理目标变化、局部加载失败及旧响应隔离
- 抽屉通过 `defineExpose({ openDrawer })` 暴露给父组件调用
- 只读信息优先使用 `el-descriptions`，不使用只读 `el-input`
- 抽屉尺寸建议 `size="50%"` 或 `size="600px"`，避免遮挡全部内容
- 独立详情页通过路由参数（`useRoute().params.id`）获取记录 id
- 内嵌关联表格使用简化版（不需要 `useTable`，直接 `ref([])` + API 调用）

## 推荐写法

### 抽屉组件（drawer.vue）

```vue
<template>
  <el-drawer
    v-model="visible"
    :title="$t('example.text07')"
    size="50%"
    :before-close="handleClose"
  >
    <div v-loading="loading" class="drawer-content">
      <el-alert v-if="loadFailed" type="error" :closable="false" :title="$t('example.loadFailed')">
        <el-button @click="retryLoad">{{ $t('example.retry') }}</el-button>
      </el-alert>
      <!-- 基本信息 -->
      <el-descriptions :column="2" border class="mb20">
        <el-descriptions-item :label="$t('example.text01')">{{ detail.name }}</el-descriptions-item>
        <el-descriptions-item :label="$t('example.text02')">
          <aura-dict-tag :options="status_dict" :value="detail.status" />
        </el-descriptions-item>
        <el-descriptions-item :label="$t('example.text03')">{{ detail.createTime }}</el-descriptions-item>
        <el-descriptions-item :label="$t('example.text04')">{{ detail.createBy }}</el-descriptions-item>
        <el-descriptions-item :label="$t('example.text05')" :span="2">{{ detail.remark }}</el-descriptions-item>
      </el-descriptions>

      <!-- 关联数据（可选） -->
      <div class="section-title mb8">{{ $t('example.text08') }}</div>
      <el-table :data="relatedList" border size="small"
        :cell-style="{ textAlign: 'center' }"
        :header-cell-style="{ textAlign: 'center' }">
        <el-table-column prop="name" :label="$t('example.text01')" />
        <el-table-column prop="createTime" :label="$t('example.text06')" />
      </el-table>
    </div>

    <template #footer>
      <div class="drawer-footer">
        <el-button v-auth="'xxx_edit'" type="primary" @click="handleEdit">{{ $t('example.text09') }}</el-button>
        <el-button @click="handleClose">{{ $t('example.text10') }}</el-button>
      </div>
    </template>
  </el-drawer>
</template>

<script lang="ts" name="ModuleDrawer" setup>
import { useDict } from '/@/config/aura/index';
import { getObj, fetchRelated } from '/@/api/module/xxx';

const emit = defineEmits(['edit']);

const { status_dict } = useDict('status_dict');
const visible = ref(false);
const loading = ref(false);
const detail = ref<any>({});
const relatedList = ref([]);
const loadFailed = ref(false);
let drawerSequence = 0;
const detailId = ref('');

const openDrawer = async (id: string) => {
  const sequence = ++drawerSequence;
  detailId.value = id;
  detail.value = {};
  relatedList.value = [];
  loadFailed.value = false;
  visible.value = true;
  loading.value = true;
  try {
    const [detailRes, relatedRes] = await Promise.all([
      getObj(id),
      fetchRelated(id),
    ]);
    if (sequence !== drawerSequence || !visible.value) return;
    detail.value = detailRes.data;
    relatedList.value = relatedRes.data;
  } catch {
    if (sequence === drawerSequence && visible.value) loadFailed.value = true;
  } finally {
    if (sequence === drawerSequence) loading.value = false;
  }
};

const handleEdit = () => {
  if (loading.value || loadFailed.value || !detail.value.id) return;
  visible.value = false;
  emit('edit', detail.value.id);
};

const handleClose = () => {
  drawerSequence += 1;
  visible.value = false;
};

const retryLoad = () => openDrawer(detailId.value);
defineExpose({ openDrawer });
</script>

<style scoped>
.drawer-content {
  padding: 0 16px;
}
.drawer-footer {
  display: flex;
  justify-content: flex-end;
  gap: 8px;
}
.section-title {
  font-weight: bold;
  font-size: 14px;
  color: var(--el-text-color-primary);
}
</style>
```

### 独立详情页（route 跳转）

```vue
<script lang="ts" name="ModuleDetail" setup>
import { useRoute, useRouter } from 'vue-router';
import { watch, onBeforeUnmount } from 'vue';
import { getObj } from '/@/api/module/xxx';

const route = useRoute();
const router = useRouter();
const detail = ref<Record<string, unknown>>({});
const detailLoading = ref(false);
const detailFailed = ref(false);
let requestSequence = 0;

watch(() => route.params.id, async (value) => {
  const sequence = ++requestSequence;
  detail.value = {};
  detailFailed.value = false;
  const id = Array.isArray(value) ? value[0] : value;
  if (!id) return;
  detailLoading.value = true;
  try {
    const res = await getObj(id);
    if (sequence === requestSequence) detail.value = res.data;
  } catch {
    if (sequence === requestSequence) detailFailed.value = true;
  } finally {
    if (sequence === requestSequence) detailLoading.value = false;
  }
}, { immediate: true });
onBeforeUnmount(() => { requestSequence += 1; });

const goBack = () => router.back();
</script>
```

## 验证步骤与预期结果

1. 按本文场景执行首次进入、目标切换及空/错状态，结果应与当前业务对象一致。
2. 检查加载完成、销毁、隐藏后显示及重新打开，无旧实例或过期响应影响。
3. 独立与远程模式分别检查资源、样式和公开方法；核对控制台与 Network。

**人工确认点**：业务字段、数据规模、权限和真实接口，以及目标版本实际支持的 Props、Events 与 Exposes。
