# 前端审查规则路由

完整原规则 ID、必要性与正文位置见 [rules.json](rules.json)。正式审查保留全部 27 条及结果矩阵；[变更审查](change-review.md)与[开发自检](development-self-check.md)按限定范围和必要上下文选择命中规则，不逐条枚举或重复已确认链路，不要求六文件矩阵。用户明确全项目/完整规范审查时走正式模式；开发闭环明确自检的，仍在自检内覆盖其所请求规则。下表为三种模式共用的选读和取证路由，不另造技术要求。

仅选择目标前端项目的源码、配置、依赖与已有产物。接口字段使用公开契约或已有脱敏响应；没有材料时保留未证实，不查找其他领域代码补证。规范副本为前端审查视图，开发示例不构成修改或安装授权。

FE-001～004、019、024 命中组织问题时，读取[统一职责决策表](../knowledge/PIGX前端开发规范/文件组织与职责拆分.md)，从状态/资源所有者、实际消费者与导入方向取证。确认偏差指出具体职责混杂、重复状态、反向依赖或样式污染；长度、无 Hook、未外置 CSS 仅提示评估。少量私有 TS/SCSS 同级、单一内聚大文件和有理由保留的大样式不机械判偏差；纯注释不增加结构整改。

| 规则 | 检查对象 | 取证关系与边界 |
| --- | --- | --- |
| FE-001～005 | 页面、私有组件、共享组件、Store、状态视图 | 追踪职责与状态来源，逐项检查加载/空/失败/权限等适用状态；截图不证明全部交互 |
| FE-006～008、010～012 | 页面调用、领域API、请求适配、Mock、路由和权限 | 页面→API→统一请求，字段适配→展示；请求适配层允许封装，仅检查前端可见性与权限上下文，接口实际授权不在结论范围 |
| FE-009、013～018 | 表单校验、提交、弹窗、并发请求、分页、文件、时间枚举 | 操作发起→校验→提交→反馈/取消/销毁；检查旧响应与重复操作，缺运行环境时保留未证实 |
| FE-019 | 工程、命名、页面模式、字典与国际化、表单Hook | 对照生成与页面模式查真实职责；字典筛选/表单 Select 与展示 Tag/Text 消费关联 FE-025 并执行下述共用取证；方法名命中不证明业务层重复实现 |
| FE-020～021 | 框架保护区、config/aura、web-kit公开入口与版本 | 先核对安装包exports和类型，再判断是否复制公共能力；源码新版本不能代替项目已安装能力 |
| FE-022 | 菜单、路由、remote身份和实际入口 | 菜单响应/路由→页面/expose，必要菜单字段或配置材料缺失时未证实，不虚构菜单与权限码 |
| FE-023 | Vite、依赖、exposes、shared、runtime、manifest与产物 | 采用1.23.5/1.9.0与TS5.9.3配套；配置→最终发现报告/optimizeDeps→独立/宿主加载；不依赖另一个技能安装 |
| FE-024 | scope根节点、主题、CSS、import/public资源 | 挂载范围→样式/资源URL→提供方产物；字符串扫描只是候选 |
| FE-025 | 组件公开入口、实际resolver与ui-plus | 纳入 AuraDictTag / AuraDictText / AuraDictSelect 的依赖、公开导出/类型、注册/import 与展示消费，其余 aura-ui 排除；ui-plus 正常核对 FxftMap、FxftWebVideo、FxftWebMultiVideo 的依赖/导出/resolver/调用；只判纳入子项 |
| FE-026 | 系统字体源、Iconfont配置与加载 | 配置→初始化→CSS/字体请求；无运行证据不宣称冲突校验成功 |
| FE-027 | 类型、lint、构建、产物、独立和远程运行 | 读取项目真实scripts并检查副作用；TS/ESLint配套、专用配置检查和业务全量检查结论分开 |

## 规范选读

正式审查或首次确认项目边界时读 [前端总览](../knowledge/PIGX前端开发规范/PIGX前端开发总览.md)；已确认项目的局部审查直接按 rules.json 命中的 standard 路径读取正文和必要正反例。完整 27 条是本版前端规则集合，不要求局部任务全读，不延伸到其他领域。范围外要求单列边界，不把自己的建议写成正式规则。

本轮只读盘点脚本不替代模块联邦专项审计。需要使用专项工具时先确认可用；其error/warning/manual仍作为取证输入复核，不能直接换算为本结果包的规则状态。完整的冷启动、首次菜单与往返证据按模块联邦正文获取；静态配置通过不能代替运行验证。

## 判定

通过要求全部纳入适用对象有符合证据；偏差关联确认发现；未证实说明缺少什么证据及补证办法；不适用要有项目事实、范围和规则条件支持。多模块按对象保留分项，整体偏差优先，其次未证实。候选、规则、发现和对象各自统计。

## 表单生命周期取证

正式审查、变更审查和功能开发自检中，范围涉及业务表单即按同版 [FE-013 正文](../knowledge/PIGX前端开发规范/03-表单异步与资源反馈.md)及[工程规范](../knowledge/PIGX前端开发规范/工程与代码生成规范.md)检查；页面、Dialog、Drawer、内嵌编辑和私有组件均纳入相应范围。查询表单按实际校验/重置操作检查；只作排版、无生命周期操作的只读区域不要求空导入。非 Element Plus 表单核对真实适配契约，无法覆盖时记缺口并保留真实组件校验协议，不强行接入布尔适配器或虚构 Hook 能力。

先核对已安装 `@fxft/aura-web-kit/hooks/form` 导出和声明，再沿“表单 ref/模型 → 校验/提交、重置、打开回填 → 实际方法”追踪到公共 `useForm`。真实适用方法为 `validateForm/resetForm/clearFormValidate`；不要求无对应操作的表单全部解构。仅导入、仅重置用 Hook 而校验仍直调实例，或业务属性恰好名为 `useForm`，均不能证明完整接入。别名和私有 Composable 继续追踪最终调用；业务内复制公共实现仍属偏差。

字段联动/分步校验还须核对公共 `validateFormFields` 与 `FormFieldPaths`：支持版本中业务直接调用实例 `validateField` 属绕过；包缺方法时记缺口并给出升级或补证要求，不能凭同名局部函数判接入。空路径、未挂载、缺能力及校验失败不得放行；字段名、点路径/分段路径需与实际 FormItem prop、规则和挂载一致，局部校验不能替代业务要求的整表提交校验。

web-kit 提交 `df7206233306299fdb4d327a22f5d34c8177faed` 同时补充了 VueUse 初值克隆和字段校验。旧版已发布 1.9.0/1.9.1 不能凭版本号推定有这些能力；以项目实际公开声明及包内容取证，缺支持不能虚构 API，既有框架基线不在审查中自动提升。新重置保持模型身份和缺省字段置 undefined；核对嵌套初值不被编辑污染、反复重置恢复、特殊类型保持约定含义，以及不支持值在修改前失败。来源状态见[维护记录](form-hook-source.json)。

核对异步校验前防重、校验为 false/未挂载时不发送请求、关闭或换目标后旧校验不提交新对象，以及重置初值和复用后的历史校验清理。直接 `validate/resetFields/clearValidate` 需确认对象确为业务表单实例；公共包内部、其他对象同名方法不能机械报错。按实际证据判偏差或未证实，静态通过不冒充运行验证。

在所选模式已有报告/记录中简记各纳入表单的调用位置或符号、适用生命周期和结论，不新增六文件或逐字段机器矩阵。限定任务不扩为全项目迁移；纯注释检查保持原范围，明确要求完整规范检查时才报告相应既有功能偏差，审查始终不修改业务实现。

## 字典展示共用取证（FE-019 / FE-025）

三组件的 Props、选项字段、入口、空值及方法/插槽先读随包 [组件库入口](../knowledge/PIGX前端开发规范/aura-ui组件库/README.md)，不要求跨技能安装。

本节适用于三种模式中命中的字典范围；为本轮用户授权的本地规则补充，来源见[本地变更记录](readability-source.json)。

有字典或业务枚举的前端展示必须使用 `@fxft/aura-ui` 公开的 `AuraDictTag` / `AuraDictText`：标签展示使用前者，纯文本展示使用后者，覆盖表格、详情、嵌套组件及历史记录。筛选和表单继续使用 `AuraDictSelect` 或项目字典选项。禁止业务层以 `map/find/switch`、三元表达式、`getLabel`、手工 `el-tag`、硬编码映射或对应 `*Name` 快照替代展示组件；无字典的真实名称、数字单位格式化及状态机/权限等非展示编码判断不在此禁令内。Mock 可提供字典选项，不得在业务页面硬编码选项伪装字典。

沿“接口枚举/`dictKey` → 消费字段 → 页面/私有组件 → 展示”取证，不能只看组件名出现或零扫描命中。核对实际依赖/锁定版本、已安装 exports/types、显式 import 或自动导入/Resolver 注册及真实使用；只检查公开契约，不开展 SDK 底层审计。组件或依赖缺失按证据记偏差或缺证，不自动升级，也不转为手写映射。源码仓库名 `aura-web-sdk` 的 UI 包公开名为 `@fxft/aura-ui`；不得虚构 `@fxft/aura-web-sdk` 包名或把 `DictTag` / `DictText` 当作已核实的公开导出。

筛选/表单使用 AuraDictSelect 时，FE-019 / FE-025 核对选项真实来源、modelValue 与 valueKey 类型一致性、multiple 数组、labelKey、placeholder、公开 change/update:modelValue 事件及远程加载条件；不用其他展示组件的 String 匹配规则替代 Select 取证。filterable 属 ElSelect 透传能力，未暴露的方法或插槽不能虚构。

组件默认行为仅是公开契约事实，不意味着业务必须自行增加兜底。fallback 或未知值展示按真实需求配置；未经要求不新增转换、硬编码或覆盖值，不用自设 fallback 掩盖字典类型、选项来源或编码匹配错误。说明当前用途时写具体业务语义，不把组件默认行为描述成业务额外实现。 审查需区分未传 fallback 时 SDK 默认显示原值与业务自写兜底，不能凭原值显示推定页面新增转换；仍沿真实字典与编码取证。
