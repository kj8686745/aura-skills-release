# 审查交付核对

按入口先选模式：限定日常变更按[变更审查](../references/change-review.md)核对单报告的真实版本、范围、适用规则、问题证据、未覆盖项和建议，不调用 Collect/Check，不建全 27 条矩阵；开发闭环按[开发自检](../references/development-self-check.md)核对轻量记录。两者复用有效证据，不每个子块或代理完成就全套复查。下列六文件、全规则与 Check 项仅用于 `formal-review`；末尾可读性等条目仅在相应范围命中时使用，不因本清单扩展范围。纯补注释默认不进入审查或本清单。

- [ ] 目标、范围、提交、未提交状态、文件指纹和规范来源可复核；报告目录已排除出被审资产。
- [ ] aura-ui 仅纳入 AuraDictTag / AuraDictText / AuraDictSelect，其余排除，ui-plus 正常审查；公共能力摘要分两行，FE-025 明确纳入子项；未使用 ui-plus 有实际依赖/调用盘点依据。
- [ ] 全部可静态检查项已连续完成；未证实只留真实缺证及补法，尚未检查只在部分完成过程包保留。
- [ ] 01 第5节含中文规则名+ID、要求、实际检查、结论/缺证分类、证据及补法；02首列包含中文名称，不以编号代替解释。
- [ ] 检索只形成候选；确认、排除、待补证有上下文，候选归并保留全部位置及原编号。
- [ ] 发现关联规范、证据、真实影响与关闭条件；严重性和证据级别分别记录。
- [ ] 六文件及字段沿用原模板，规则/候选/发现/文件统计独立，零发现不等于通过。
- [ ] 构建、类型检查、lint 和浏览器结果分别记录；未执行写原因，不沿用其他版本证据。
- [ ] 已运行 Check 或说明环境缺失；检查仅证明结构。Agent 已核对原模板全部字段、规则/候选统计闭合，以及 F↔规则、C→F、全部 E 引用与证据含义一致。
- [ ] 对比被审版本和资产增删改，旧 E 保留原版本；变更涉及的对象已重新取证。附件有包内链接且未覆盖旧材料。
- [ ] 已关闭发现具有新证据、整改提交及关闭条件验收，历史发现保留编号；当前规则状态和当前/历史发现统计明确区分。
- [ ] 未读取或打印 npmrc/env/认证值；输出材料已脱敏，读取失败与暂缓项未伪装为通过或不适用。
- [ ] 源码未改，复核历史和实体 ID 保留；未提交、已提交、推送、发布和实际验收状态分别说明。
